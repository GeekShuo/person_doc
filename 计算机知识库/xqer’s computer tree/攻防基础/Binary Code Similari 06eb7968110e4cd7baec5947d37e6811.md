# Binary Code Similari

Owner: xqer

一、选题背景

二进制代码相似性检测（BCSD）在漏洞检测、软件组件分析和逆向工程等各个领域都有重要的应用。识别两个二进制代码片段之间的相似程度是一种基本技术，可用于广泛的应用场景，包括已知漏洞发现、恶意软件检测 和软件聚类， 软件抄袭检测 ，补丁分析和软件供应链分析。鉴于二进制进程的数量不断增加以及二进制分析任务的广泛性，显然需要开发更具可扩展性和准确性的 BCSD 解决方案。

二、数据集介绍

BCSD可以应用于多个领域。因此缺乏一个共同的大型基准，每个研究都创建了自己的数据集，通常来自GNUtils，coreutils和openssl等小型存储库。这些小数据集具有相似的代码模式，因此缺乏多样性，这反过来又可能导致模型过度拟合和高性能的错误印象。此外，对现有解决方案的评估通常不能反映实际用例。大多数研究没有对大量候选函数进行实验，这在现实世界中很常见。在更现实的条件下，许多SOTA解决方案的性能会显着下降。出于以上考量，为了使我的研究更有通用性，我选择了一个名为BinaryCorp的数据集。该数据集是由清华信息科学与技术国家研究中心提供的，对于该任务，BinaryCorp是迄今为止最多样化的，它可以显著缓解之前模型的过拟合问题。该数据集基于archlinux官方仓库和开源社区，包含了包括编辑器、即时通讯进程、HTTP 服务器、Web 浏览器、编译器、图形库、加密库等应用包。

该数据集有大规模与小规模两个版本，由于内存限制与算力限制，我选择使用小规模数据集完成此次实验。小规模数据集有1612个项目，每个项目中有经过不同编译优化方式的代码。我们认为同一份代码经过不同类型的编译优化得到的代码是相似的。不同项目的代码是不相似的。

三、算法原理

基本算法

为了研究此问题，我阅读了《软件加密与解密》第十章的部分，学习了代码相似性检测的传统方法，比如k-grams算法，比较两个文档的k-gram集合是一种很流行的比较文档相似性的方法。这一思想可以用在对文本文档或源代码的剽窃检测、软件作者辨识以及二进制可执行文件的“胎记”检测中。算法原理如下：

对于两个字符串A和B，分别为yabbadabbadoo和doobeedoobeedoo的，我们在字符串上滑动一个大小为3的窗口，就得到了其对应的3-gram的集合。

A: yab abb bba bad ada dab add bba bad ado doo

B: doo oob obe bee eed edo doo oob obe bee eed edo doo

每一个长度为k的元素称为shingle，我们比较ABshingle的差异判断其相似性。为了简化操作与存储空间，我们使用字符串哈希的方法将shingle转化为数字。由于比较所有的shingle计算量太过庞大，且意义不大。我们可以只保留一部分的shingle，使其能够比较即可。可以只保留对于某个指定的p，模p为0的hash。

我们找到有最多公共shingle的代码对，即认为其有最高的相似度。

进阶算法

基于nlp方法的相似度检测算法。

bert是一种预训练的自然语言处理模型，具有革命性的影响力。我们可以基于bert模型得到文本的向量表示，当该向量可以很好地表示文本的时候，我们就可以通过计算向量之间的相似度来获得代码之间的相似度。

BERT模型的原理可以分为两个主要部分：预训练和微调。

1. 预训练（Pretraining）：
    
    BERT模型首先进行大规模的无监督预训练，使用海量的未标记文本数据来训练模型。为了实现我们的BCSD目标，这一阶段使用两个任务：
    
    - 掩码语言建模（Masked Language Modeling，MLM）：在输入序列中随机掩盖一些词，并用特殊的标记"[MASK]"替代，模型需要预测这些掩盖词的原始词。
    - 跳转目标预测（Jump Target Prediction，JTP）：给定一个随机选择的跳转源地址，我们的模型需要预测其相应的目标地址
    
    预训练过程使用Transformer架构进行编码，它是一种基于自注意力机制的深度神经网络结构。我们可以给跳转语句的源地址和目的地址同样的注意力参数，这样可以将程序控制信息加入到词向量的表示中。预训练完成后，BERT模型可以生成丰富的上下文相关的词向量表示。
    
2. 微调（Fine-tuning）：
    
    在预训练阶段，BERT模型已经学习到了丰富的语言表示，接下来将使用少量标记的任务特定数据对模型进行微调。在这个阶段，我使用如下的Triplet_COS_Loss损失函数：
    
    设 F 和 G 是一组二进制函数，对于任何查询函数 f ∈ F，设 g+ ∈ G 是一个类似于 f 的函数（例如，从相同的源代码编译）。此外，设 g− ∈ G 是一个任意函数，与 f 无关。我们将函数 f 的embedding表示为 Ef。最后，计算f与这两个函数之间的余弦相似度，如果cos（f，g+）-cos（f，g+）> x则认为判断成功，x的取值可以根据我们的筛选标准调整，如果要尽量找到所有的相似函数而不在乎误报率，则可以x取小点，反之取大点。
    

四、实现过程

基础算法

数据集已经给出了函数的二进制字符串表示，我们把读取数据集的功能抽象为一个类，并用torch的dataloader类继承该父类。读取数据集的时候每次迭代获得一个待查询函数，相似函数，不相似函数。对函数进行简化。然后用一个向量代表文本块的摘要向量。向量的下标代表对应shingle的hash值，向量的值代表该shingle的数量。将两个文本的摘要向量计算余弦相似度，即可很好代表二者的相似程度。

进阶算法

调用预训练好的bert模型，选择Triplet_COS_Loss作为损失函数，将数据分为多个批次，每一个批次得到一个loss，然后反向传播得到模型参数的梯度，进行更新。代码实现过程可以直接调用pytorch提供的model.train，loss.backward()，optimizer.step()来训练。
