就是将一个图像分成不同大小的patch，轮流展示出。 2. 书写一个简单而又深刻的图像处理程序：显著目标检测；

将该程序转写成一个函数，并实现调用；

```
DimS = 3;
ImgD = imresize(im2double(imread('5.png')),1.0);
figure;
subplot(1,2,1);
imshow(ImgD);
subplot(1,2,2);
imshow(remarkablesub(ImgD,DimS));
colormap(jet);

remarkablesub.m:
function output=remarkablesub(input,DimS)
[Hei Wid Dim] = size(input)
output = zeros(Hei, Wid);%生成与原图大小相同的 0 图像
ImgYUV = rgb2hsv(input); %转换颜色空间RGB -》HSV，与人类感官相似
inputD = ImgYUV(:,:,DimS);%取出某个维度的二维矩阵
output = abs(inputD - mean(inputD(:))); %计算每个像素值与二维矩阵均值的差

output = output / max(output(:)); %归一化到 0-1

```

原理：将rgb图像转化为hsv,h代表颜色,s代表对比度，v代表亮度。生成 图像与平均亮度的差值的数组，将该数组绘出，亮度比较显著的区域就会显现出来。修改dim的值，可以变为检测颜色差异大或者对比度差异大的区域。
