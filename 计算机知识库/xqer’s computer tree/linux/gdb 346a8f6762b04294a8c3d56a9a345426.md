# gdb

Owner: xqer

gdb attach 调试正在运行的进程

n s单步执行

r 运行

continue 继续执行

watch 监控变量

set variable <变量> = 要赋的值 改变变量的值

set disassembly-flavor intel 设置为intel型汇编

disassemble main 反汇编

info proc mappings 进程地址映射表

command 在断点处执行一系列高级动作

bt 显示帧栈

bt full 显示帧栈和局部变量

print 变量 显示变量内容 p{var1,var2,var3} 一行监控多个变量

display {var1,var2,var3} 跟踪自动显示

info reg 显示寄存器内容

p $寄存器

p/x $寄存器 十六进制显示寄存器内容

set pagination off 禁止分页

layout asm 显示汇编代码

jump *(main+ ...) 跳过某一步

where 程序出错位置
