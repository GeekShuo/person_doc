# 开启ssh服务

vi /etc/ssh/sshd_config

![image.png](ssh/image.png)

/etc/init.d/ssh restart 重启 或者 service ssh start 重启 /etc/init.d/ssh status 状态是否正常运行 或者 service ssh status 状态是否正常运行

update-rc.d ssh enable 开机启动
