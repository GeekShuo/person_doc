 修改挂载映射

  1. 临时挂载

  # 挂载磁盘到目录
  sudo mount /dev/sdb1 /mnt/data

  # 卸载
  sudo umount /mnt/data

  2. 永久挂载（重启后生效）

  # 编辑 fstab 文件
  sudo vim /etc/fstab

  # 添加行（格式：设备 挂载点 文件系统 选项 0 0）
  /dev/sdb1    /mnt/data    ext4    defaults    0    0
  # 或使用UUID（推荐）
  UUID=xxxx-xxxx    /mnt/data    ext4    defaults    0    0

  3. 常用挂载选项

  # 读写挂载
  sudo mount -o rw /dev/sdb1 /mnt/data

  # 只读挂载
  sudo mount -o ro /dev/sdb1 /mnt/data

  # 自动挂载
  sudo mount -o auto /dev/sdb1 /mnt/data

  # 指定文件系统
  sudo mount -t ext4 /dev/sdb1 /mnt/data

  4. 查看磁盘UUID

  sudo blkid
  ls -l /dev/disk/by-uuid/

  5. 卸载强制选项

  # 强制卸载
  sudo umount -f /mnt/data

  # 懒惰卸载（设备忙碌时）
  sudo umount -l /mnt/data

	子目录会覆盖根目录的挂载，即/目录如果初始的时候挂载了sdb1 /home 挂载了sdb2，那么访问/home的时候就会找sdb2 其他路径就会找sdb1
	如果有多个目录挂载了同一个设备，那么访问这几个目录访问到的是同一份文件
