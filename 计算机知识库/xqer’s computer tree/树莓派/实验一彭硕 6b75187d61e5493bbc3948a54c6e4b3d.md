# 物联网应用场景畅想

当下，物联网技术在交通运输，农业，工业控制，医疗等行业都有了一定的技术雏形，将要或正在对原有行业形成变革。我对其在未来几年的发展前景有着广袤的畅想。

首先，在交通运输业，随着电动汽车和无人驾驶的普及，有可能将改变出租车的模式与人们的出行方式。对与出租车公司，使用无人驾驶会大大降低运营成本，不用给出租车司机发工资。同时可以通过高性能调配在不同地区配置合适的数量，并在运营时动态平衡，可以减去出租车司机休息时间和等订单的时间，提高汽车利用率。另外，随着技术的发展，所有车辆互联，车辆路径可以达到精确控制，车辆与车辆之间可以间隔很小而不会出事故，因为路径都是已经规划好的。这样能大大提高道路利用率，红绿灯或许不再需要，车辆可以井井有条地穿插经过。

另外，为了进一步提高能源利用率，和降低用户使用成本，可能出现共享出租。乘客可以在手机上预定用车时间，出发地和目的地，这样再由所有车辆互联形成的网络，进行接驳，然后寻找顺路乘客一起拼车。如今出租车的价格大约为每公里2~3块，电动车的普及将能源费用降低了三四倍，再加上无人驾驶取消司机成本，每公里价格可能到1块，再加上共享出租均摊费用，之后的出租车可能每公里费用只有几毛钱。人们的出行金钱成本和时间成本都将大大降低。

此外，我们知道汽车能源的消耗很大一部分来自空气阻力。汽车以60公里的速度前进时，有60%的动力是用来克服空气阻力。当汽车进入互联时代，前后车的跟车距离可以达到二十厘米而不发生碰撞，这样后车的空气阻力将大大减小，在高速公路上可以实现群车形成一条直线行走，这样的能源消耗会更低，快递运输等行业会更加蓬勃发展。

以上是我对物联网应用在交通运输业的场景构想。此外，物联网对我们的日常生活也有很大帮助，比如我们可以取消手机的存在，将打电话和聊天等功能集成到一块小芯片里，挂在耳朵上面，将拍照功能和投影功能集成到眼镜当中，随时随地进行抓拍，播放视频。控制系统可以用chatgpt等聊天机器人，可以很好理解人类语言，还可以与之聊天，练习口语等等。
