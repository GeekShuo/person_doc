一、掌握核心快捷键 
Mac的快捷键系统非常高效，关键是要记住这些修饰键的符号： 
Command(⌘) - 相当于Windows的Ctrl键
Option(⌥) - 相当于Windows的Alt键
Shift(⇧) - 大小写切换键 Control(⌃) - 控制键
日常快捷键： Command + C - 复制 
Command + V - 粘贴 Command + X - 剪切 Command + Z - 撤销 Command + Space - 打开聚焦搜索 Command + Tab - 切换应用程序 Command + Q - 退出当前应用 Command + W - 关闭当前窗口 三、触控板神技能 基础手势： 单指轻点 - 选择/点击 两指轻点 - 右键菜单 两指滚动 - 上下浏览页面 两指捏合 - 放大缩小 进阶手势： 三指向上轻扫 - 打开调度中心 四指向内捏合 - 打开启动台 四指向外张开 - 显示桌面 三指拖移 - 移动文件和窗口

四、文件管理神器 - 访达 Command + N - 新建访达窗口 Command + Shift + N - 新建文件夹 Command + Delete - 删除文件到废纸篓

Conmmand + Shift + G 到达指定的路径 空格-快速预览

资源库文件默认是隐藏的，需要手动在选项栏里设置为可见，应用程序数据往往在这个文件夹下 七、实用小技巧 截图功能： Command + Shift + 3 - 全屏截图 Command + Shift + 4 - 区域截图 Command + Shift + 5 - 打开截图工具 快速搜索： 使用Command + Space打开聚焦搜索（spotlight），可以搜索文件、应用、进行计算等 应用管理： 安装应用：从App Store或官网下载.dmg文件 卸载应用：拖拽到废纸篓即可 强制退出：Option + Command + Esc

分屏功能 ： 奇怪，mac在分屏的时候选择分辨率大小和选择字体大小是绑定的，分辨率越大，字体越小。

十、从Windows过渡对照 Windows的Ctrl → Mac的Command Windows的Alt → Mac的Option Windows的文件管理器 → Mac的访达 Windows的开始菜单 → Mac的启动台 小结 Mac上手并不难，关键是要： 熟悉基本界面布局 掌握核心快捷键 学会触控板手势 多练习，养成使用习惯 记住，Mac是为了提高工作效率而生的，一旦习惯了它的操作逻辑，你会发现它比Windows更加高效优雅！

1.查询芯片指令集架构是arm还是intel

方法一：通过终端命令快速查询‌

打开终端（通过Spotlight搜索或路径应用程序 > 实用工具 > 终端）。

输入命令 uname -m 并回车：

‌方法二：通过系统设置查

点击屏幕左上角苹果菜单（），选择“关于本机”。

查看“芯片”或“处理器”信息：

显示“Apple M1/M2”等为ARM架构。‌‌

显示“Intel Core i5/i7”等为x86架构

芯片架构主要分两种 x86和arm 。x86是intel推出的，后由amd拓展为64位 叫做amd64或者x86-64。如今传统的x86已经少见，都是64位的amd64。amd64兼容32位的x86的软件，但是arm和x86系列不兼容）M1 M2为arm架构，其主要特点是功耗低。所以macbook续航这么高。但是amd64性能更高。

当然 即使架构一样 比如linux amd64 和macos amd64 二者都是amd64。但是使用的库不同 也无法兼容使用
