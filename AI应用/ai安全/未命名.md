# 一、困局与突破-大模型防御大模型

## （一） 防御围栏难点

**1、审核黄金时间-你的可用时间有限：**

业务给安全团队留下的“可用时间”不是分钟、不是秒，而是**毫秒级死线**：

**2、审核标准的弹性变化：**

- 监管细则、平台公约、舆情热度、地域文化，像四条同时发力的“弹力机”；
- 不同的应用场景，不同的时期，不同态势，不同的区域，审核差异性大，存在规则冲突；

**3、风险持续的对抗**

- 攻击手段的演变；
- 黑盒与白盒攻击并存；

## （二） 小模型的困境：

1、**上下文“短视症”——窗口受限，逻辑断档**

- 小模型通常仅支持512～2k token级别输入，超长对话、篇章级隐喻、跨段落指代一旦超出窗口即被截断，导致关键证据丢失。
- 大模型生成的“链式诱导”攻击（多轮铺垫+突然触发）恰好利用这一盲区，使小模型在最后一轮才“恍然大悟”，却为时已晚。

**2、语义“迷宫”——复杂语言现象难以建模**

- 反讽、隐喻、黑话、文化梗需要深层次的常识与背景知识，小模型参数规模不足，隐空间表示稀疏，极易把“高级黑”错判为“正常吐槽”。
- 大模型可轻松生成“表面正能量、实则负面”的阴阳文本，对小模型形成降维打击。

**3、对抗“变脸”——高对抗样本迭代快、花样多**

- 同音替换、拆字、混合语种、Unicode隐形字符、Markdown渲染陷阱……大模型自身就是“最强对抗样本生成器”，可毫秒级输出成千上万种变形。
- 小模型缺乏持续蒸馏与动态扩容机制；

**4、标准“漂移”——审核口径与风险理解能力滞后**

- 监管要求、平台规则、社会舆情三者实时变动，小模型训练语料往往截止于数月前，对“最新红线”无感。
- 大模型可通过Few-shot Prompt即时对齐最新政策，生成“擦边但不越线”的内容；小模型却因无法动态刷新“政策向量”，把合规内容误杀、把违规内容放行，导致Precision/Recall双降。

## （三）突围

- **纵深防御：大小模型结合，事前、事中、事后协防；**
- **大模型防御大模型；**
- **审核粒度细化；**

- 风险类型：11 大类（涉政、涉黄、暴恐、毒品、赌博、违禁、辱骂、歧视、虚假消息、商业违规、恶意代码）→ 130 细类；
- 提示词注入手法：50+ 主流手法（忽略前置、系统伪装、间接诱导、重复扰动、分段编码等）逐条标注，支持手法-风险二维联合采样；
- 语种：中、英、西、德、日、法、韩、俄、阿、葡、意、土 12 种主流语言，语料占比与全球互联网母语人口对齐；
- 对话类型：单轮、多轮、角色扮演、任务型、开放式五类（后续会补充agent类型的任务）；
- 轮数：1–15 轮均匀分段，长对话（≥8 轮）额外采用滑动窗口采样，保证上下文连贯性。

### **2、数据合成生成Pipline**

**（1）Step 1 恶意 Query 生成：**

构建专用蓝军大模型，以“不安全种子”为起点，通过角色扮演、场景模拟与风格克隆技术，批量生成高逼真、多轮次恶意 Query。集成 DeepResearch Agent，可实时检索公开情报并自动融合至 Prompt，实现“搜索-生成”闭环，显著提升合成 Query 的复杂度与隐蔽性。

**（2）Step 2 恶意 Query 变异增强** 对 Step 1 生成的 Query 进行双维度强化变异：

- 危害程度维度：采用递进式毒性放大策略，持续抬升内容风险等级；
- 攻击手法维度：系统注入最新越狱技巧（如忽略前置、系统伪装、间接诱导、重复扰动、格式隐藏等），快速扩展攻击覆盖面与成功率。

**（3）Step 3 不安全对话采集**

- 将变异后的 Query 投喂至“未做安全对齐”的 Base 模型以及基于base模型基础上未加入安全对齐SFT对话模型（开源权重 + LoRA 继续训练，去除了 RLHF 与安全过滤），批量诱导其输出有害 Response，形成“Query-Response”会话对，确保数据分布覆盖各类高危场景。
- 将变异后的 Query 批量请求各厂商开源大模型，获得多样化的对话样本；

**（4）Step 4 多轮对抗会话合成**：

以 Step 3 单轮对为基础，利用蓝军模型扮演“攻击者”、靶场模型扮演“受害者”，通过以下机制自动扩展为多轮对话： a. 状态记忆：每轮保留角色立场与攻击目标； b. 策略演进：根据上一轮 Response 动态切换注入手法（ jailbreak、target-hijack、content-inject 等）； c. 风险递进：若某轮安全机制触发，则启用“混淆-分段-编码”组合逃逸策略，持续压低触发率直至生成成功。

输出格式统一为 OpenAI 对话日志，含系统级、用户级、助手级三级字段，后续可扩展至function-call、too-use、deepsearch等场景安全审核；

**（5）Step 5 多样性评估筛选+蒸馏+人工复核获取高质量审核评估样本**

1）多维打标：对 Step1-4 生成的 Query 与多轮对话同步标注：

- 对话类型（单轮/多轮/角色扮演等）
- 角色属性（攻击者/受害者/旁观者）
- 风险领域（涉政、涉黄、暴恐、毒品、赌博等 11 大类，130种小类）

‑ 攻击手法（忽略前置、系统伪装、间接诱导、重复扰动、格式隐藏等 50+ 子类）

‑ 语义层聚类（Sentence-BERT 1024 维向量 + HDBSCAN，自动去重并保留边界样本）；

2）分层采样

采用“密度-距离”混合策略，优先保留低密度区（高危且罕见）与高争议区（模型置信度 40-60%）样本，确保分布覆盖长尾风险。

3）答案蒸馏：

- 通过prompt工程+通用大模型、开源guard模型作为教师模型，使用一致性投票，生成输出“风险标签、三级子类、处置建议与完整推理链”审核结果；
- 采用一致性投票以及llm as judge 的方式筛选高可用的审核结果。

4）人工复核：

- 标注员→质检员→安全专家，逐条校验风险标签、处置建议与推理链；
- 一致性指标：Krippendorff’s α ≥0.81，争议样本由安全专家委员会仲裁；
- ‑质量门禁：通过率在 98% 以上方可入库，未通过样本附带修改意见回流至蒸馏环节，实现闭环迭代。

经“多维采样—蒸馏—人工”三重校验流程，沉淀出高置信、高对抗、高多样性的审核样本集，可直接服务于安全对齐、红队评测及 Guard 模型训练。

## （三）训练技巧及经验

**1、“由易到难”（****Curriculum Learning****）**

- 难度量化双指标： a. 语义困惑度：利用教师模型计算 1−p(y|x) 的 token 级平均 perplexity，数值越高样本越难； b. 攻击手法复杂度：对 Prompt-Injection、Jailbreak 等 20+ 类手法按 CVSS-style 评分（0–10），综合手法层级、隐蔽性、多轮依赖给出权重； 最终难度分 = 0.7×norm(perplexity) + 0.3×norm(攻击手法分)，映射到 D1–D5 五段离散等级。
- 课程表设计：

D1→D2→D3→D4→D5，每级 4k steps，共 20 k steps；

- 动态扩容&梯度震荡处置

通过验证集合的F1提升来决策是否进行课程升级。进入新难度后，按5%- 10% 比例回放上一阶段最高 perplexity 样本，防止灾难性遗忘，保持梯度平滑过渡。

**2、“由短到长”上下文拓展，**

- 样本上下文长度整体按照 1k->4K->8K->16K->32K 进行分组；
- 实际训练的时候，按照8K、16K、32K，3个阶段进行训练；
- 记忆刷新：每换长度立即回放 10% 上一长度最难样本，巩固长程依赖。

**3、多语种混合**

- 语种配比：中英西德日法韩等 12 语种，中文 36%，英文 28%，其余 4–6%，除增多了中文的语料外，其余语种按母语互联网语料真实占比加权，其余语种采用翻译模型获取；
- 语种混合：随机 15% 样本在对话中插入跨语种用户提问的跨语种、对话的跨语种，包括，提升模型对混合语种场景的鲁棒性；

**4、RL：**

采用GSPO进行强化学习，通过精细化的奖励函数设计，解决奖励信号的稀疏化问题；

# 三、guard大模型应用场景：

1. 知识蒸馏「师」 把 guard 大模型蒸馏成 1/10 参数的“小警卫”，精度不降、延迟减半，端侧也能跑。
2. 线上实时防御「盾」

作为实时安全防御的最后一道防线，处理长文本、对抗强、复杂文本、高危文本，bert检测置信度较低的样本。处理线上最难、风险最高

1. 人审提效「加速器」 先过 guard 模型，人工只需复核 5% 高危样本，审核人日节省 70%。
2. 近线审计「回马枪」 离线流量回放 + 模型自迭代，T+1 小时完成策略升级，让新型攻击一出现即被“反杀”。
