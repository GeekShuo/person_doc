|   |   |
|---|---|
|**维度**|**判断标准**|
|贴片文本准确性（红色文本和黄色文本）|- 红色文本是贴片，必须保证文本全部准确，不然则为不可用<br>- 黄色文本需要区分是否是符号或背景被误识别为文字，如果是误识别，不需要打勾，如果不是误识别，则按红色文本判断，准确则需要在number中打勾保留。错误则只可标到不可用。（若黄色文本是商品上的文本请按绿色文本判断）|
|主体商品上的文本准确性（绿色文本）|- 绿色文本是商品上或背景里的文字，（若是文字贴片请按红色字体判断），较大的文本必须保留且按红色文本判断，较小的文本若清晰可见且抽取准确，可以选择保留，对于保留的文本需要在选择相应序号保留。绿色文本涉及文本取舍的情况请标到可用。<br>- 如果出现商品上微小文字未被识别出来或者因识别错误但可接受舍弃而未保留，标到可用；商品上的误识别，不保留且可标到优质|
|未识别文本|- 如果有未被识别的文字贴片或者商品上的醒目大字未被识别，则不可用。<br>- 如果是倒立文本未识别或识别错误，可不保留并标到可用。|

|                                           |                                                                    |
| ----------------------------------------- | ------------------------------------------------------------------ |
| 标签                                        | 介绍（颜色只做为提示参考，不作为判断依据）                                              |
| 优质                                        | 贴片文本全部识别出来且正确，所有可辨识的非贴片文本都被识别出来且正确，误识别（将图案误识别为文本，该情况需与识别错误区分）情况可忽略 |
| 可用                                        | 贴片文本全部识别出来且正确，较大较清晰的非贴片文本都被识别出来且正确，较小较模糊的非贴片文本或倒立文本未被识别或识别错误，可不保留  |
| 不可用                                       | 贴片文本未被识别或识别错误，或者较大较清晰的非贴片文本未被识别或识别错误                               |

| 最下面一行，“送”字不能同时给两边用<br><br>优质->不可用         |                                                                    |
| 东方龙，酒瓶上是繁体字，不可以识别成简体字，算不可用<br><br>可用->不可用 |                                                                    |
