# 研究定位

## 基模发展方向

受到Gemini系列、Deepseek、Sora模型的启发，过去一年国内基模发展的两个主要方向都围绕“统一”展开：

1. 以 Emu3.5、Kimi K2.5、Qwen3.5 为代表的**原生多模态MLLM，统一各种模态的输入**
2. 以 Janus、BAGEL、Qwen-Image-1.0/2.0 为代表的**生成理解统一模型**

- 此外LLM领域持续探索 Math、Coding、Agent 落地的能力
- 生成模型领域持续探索 GRPO-style 后训练、视频生成和世界模型能力
- 以及audio、depth、motion、3D等更多模态的理解和生成

## 统一模型目前的Research Gap

站在理解辅助生成的角度，生成辅助理解目前是比较academic的问题

1. 由于LLM AR模式和Diffusion模式的差异，开源领域依然无法用一个完全统一的结构同时达到理解和生成的SOTA

2. 尽管也有Diffusion LLM和VQGAN，但是这两个效果都一般

3. 目前多数工作关注 t2i 和 editing，较少关注多图生成、结构化生成

4. 多图生成包括：n宫格漫画生成、图层分解、可能是视频生成/分镜生成的基础
5. 结构化生成包括：RGBA多图层、PSD、SVG、PPT/PDF 生成

6. 长期来看，统一模型也需要cover各种condition生成和可控编辑能力，RGBA多图层是一个比较可行的切入点

## Qwen-Image-layered

- 2025.12, 阿里, [https://qwen.ai/blog?id=qwen-image-layered](https://qwen.ai/blog?id=qwen-image-layered)
- 能力：

- t2i: 生成RGBA图像
- i2i分层分解: 对RGB图片分解为多层RGBA，图层数量可变，可以递归分解；便于进行更可控的edit

![](https://apijoyspace.jd.com/v1/files/loIin9WCHspLHGY8FFKQ/link)![](https://apijoyspace.jd.com/v1/files/orJsbYeeNLhCUCNd2AjR/link)

- 模型结构

- RGBA-VAE, VAE卷积层扩展为4通道 follow **Alpha-VAE**。

- 重建损失、感知损失、正则化损失

- VLD-MMDiT，分解为任意数量的图层 (最大20层)。

- Flow Matching、Layer3D RoPE

- sequential alpha blending:

![](https://apijoyspace.jd.com/v1/files/NJ2Wt4OsJ9HIlfrwqOoT/link)

- training

- 阶段 1：从文本到 RGB 生成适配为文本到 RGBA 生成，让模型学会生成带透明度的图像；
- 阶段 2：从单张 RGBA 生成升级为文本到多层 RGBA 生成，训练模型同时预测合成图像与对应透明图层，得到 Qwen-Image-Layered-T2I；follow ART
- 阶段 3：加入图像输入，实现图像到多层 RGBA 分解（核心 I2L 模块），完成最终模型训练，得到 Qwen-Image-Layered-I2I。

- 闭源数据集

- 针对高质量多层训练图像稀缺的问题，论文搭建了从 Photoshop 文档（PSD）提取并标注多层图像的流水线：
- 用 psd-tools 提取 PSD 文件的所有图层，过滤含异常模糊元素、无贡献的图层；
- 合并空间不重叠的图层以减少图层数量（<=20），降低模型复杂度；
- 借助 Qwen2.5-VL 为合成图像生成文本描述，支撑文本到多层 RGBA 的生成任务。

## AlphaVAE: e2e RGBA 图像重建

- 2025.7, 清华, [https://github.com/o0o0o00o0/AlphaVAE](https://github.com/o0o0o00o0/AlphaVAE)
- 模型结构

![](https://apijoyspace.jd.com/v1/files/FZTEtgnQC5M6NBfMpPgL/link)

- 基于RGB VAE (SDXL, FLUX.1 dev), 扩展为4通道增加alpha透明度
- 保持原有参数，alpha通道参数初始化w=0, b=1初始化为不透明

- 训练目标

|   |   |   |   |
|---|---|---|---|
|损失类型|核心作用|计算逻辑|公式|
|**Alpha-Blending MSE（ABMSE）**|保证 Alpha 混合后的 RGB 保真度|基于 ImageNet 背景统计，计算混合后重构图与原图的 L2 损失|![](https://apijoyspace.jd.com/v1/files/gx5JC7raLyvAWmYXGEUL/link)|
|**感知损失（LPIPS）**|提升视觉一致性|对黑白背景混合后的图像，用预训练 LPIPS 模型计算感知差异|![](https://apijoyspace.jd.com/v1/files/HJ1ExAxdyAW3E5oQ9LHh/link)|
|**双 KL 约束**|规范 latent 空间分布|1. 标准 KL：约束编码器输出符合 N (0,I)； 2. 参考 KL：对齐与原 RGB VAE 的 latent 分布|![](https://apijoyspace.jd.com/v1/files/TiDDlqcCf6NGJ7RWSEuS/link)|
|**GAN 损失**|提升生成真实性|采用 patch 判别器，自适应调整损失权重|![](https://apijoyspace.jd.com/v1/files/niurLA00dXYA2AQqBe4x/link)|

# 总结

领域发展迅速，目前最厉害的开源模型还是Qwen-Image-Layered，只能做图层分解等基础任务。

拓展更加强大的多图层能力到下游任务，甚至多图+多图层能力是一个潜在的研究方向。
