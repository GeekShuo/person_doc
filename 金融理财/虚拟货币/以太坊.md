  概念区分

  以太坊的三个层面

  1. 以太坊（区块链网络） - 基础设施
  2. ETH（以太币） - 原生代币
  3. 其他代币 - 基于以太坊网络发行的应用代币

  基于以太坊的代币生态

  ERC-20代币（标准代币）

  著名例子：
  USDT (泰达币) - 稳定币
  USDC (美元币) - 稳定币
  SHIB (柴犬币) - Meme币
  LINK (Chainlink) - 预言机
  UNI (Uniswap) - DEX治理代币
  AAVE (Aave) - 借贷协议代币

  特点：
  - 遵循ERC-20标准
  - 基于以太坊智能合约
  - 转账需要ETH作为gas费

  ERC-721代币（NFT）

  著名例子：
  CryptoPunks - 最早的NFT
  Bored Ape Yacht Club - 知名头像NFT
  Azuki - 日本风格NFT
  Doodles - 可爱风格NFT

  特点：
  - 每个代币独一无二
  - 代表数字艺术品
  - 转移记录在以太坊上

  交易费用机制

  Gas费用的作用

  所有交易都需要ETH支付Gas费：
  1. ETH转账 → 支付ETH作为Gas费
  2. USDT转账 → 支付ETH作为Gas费
  3. NFT转移 → 支付ETH作为Gas费
  4. 智能合约交互 → 支付ETH作为Gas费

  费用计算：
  基础费用 + 优先费用 = 总Gas费
  例如：转账USDT需要0.01 ETH作为手续费

  以太坊 vs 比特币的区别

  比特币区块链

  只记录：
  ┌─────────────────┐
  │ 比特币转账交易    │
  │ BTC → BTC       │
  │ (简单账本)       │
  └─────────────────┘

  以太坊区块链

  记录所有类型交易：
  ┌─────────────────┐
  │ ETH转账交易      │
  │ 智能合约执行     │
  │ 其他代币转账     │
  │ NFT交易         │
  │ DeFi交互        │
  │ (智能合约平台)   │
  └─────────────────┘

  生态系统规模

  以太坊上的资产统计

  ETH原生资产：
  - 供应量：约1.2亿ETH
  - 市值：约$4,000亿

  基于以太坊的代币：
  - ERC-20代币：约600,000种
  - ERC-721 NFT：数百万个
  - 总锁仓价值(TVL)：约$300亿

  日交易量：
  - ETH交易：约100万笔
  - 其他代币交易：约300万笔
  - 总计：约400万笔/天

  总结

  以太坊区块链是一个多功能的平台，不仅仅记录ETH转账，还记录：
  1. ETH本身的转账
  2. 成千上万种其他代币的转账
  3. 智能合约的执行
  4. NFT的交易
  5. 各种DeFi协议的交互

  可以把以太坊理解为**"数字经济操作系统"，ETH是这个系统的原生货币/燃料**，而其他代币是基于这个系
  统运行的各种应用程序。
