1. 工作量证明（PoW）机制 - 比特币

  发行规则（代码约定，无人为控制）

  比特币发行规则：
  - 每10分钟产生1个区块
  - 初始奖励：50 BTC/区块
  - 每21万个区块减半（约4年）
  - 2009年：50 BTC
  - 2012年：25 BTC
  - 2016年：12.5 BTC
  - 2020年：6.25 BTC
  - 2024年：3.125 BTC
  - 总量上限：2,100万 BTC

  发行者：矿工通过"挖矿"获得

  挖矿过程

  矿工工作：
  1. 验证交易，打包成区块
  2. 竞争解决数学难题（SHA-256哈希）
  3. 第一个解决者获得奖励
  4. 新比特币作为奖励进入流通

  自动运行特点：
  ✅ 无中央机构控制
  ✅ 规则写入代码，不可更改
  ✅ 完全去中心化
  ❌ 消耗大量能源

  2. 权益证明（PoS）机制 - 以太坊

  发行规则（验证者质押获得）

  以太坊发行规则：
  - 质押32 ETH成为验证者
  - 验证区块获得奖励
  - 年增发率：约0.5-1%
  - 无总量上限（但有销毁机制）
  - 交易手续费部分销毁

  发行者：网络验证者

  质押过程

  验证者工作：
  1. 质押32 ETH作为保证金
  2. 验证交易，提议区块
  3. 获得区块奖励 + 交易费
  4. 作恶将被罚没质押金

  特点：
  ✅ 节能环保
  ✅ 参与门槛相对较低
  ✅ 经济激励更好
  ❌ 中心化风险（大户优势）

难度调整公式

  目标：保持10分钟出块

  // 正确的计算方式
  难度调整系数 = 预期时间 / 实际时间
  新难度 = 旧难度 × 难度调整系数

  具体逻辑：
  - 如果实际时间 < 预期时间（出块太快）→ 系数 > 1 → 难度增加
  - 如果实际时间 > 预期时间（出块太慢）→ 系数 < 1 → 难度降低

  修正后的例子

  例子1：全网算力暴增，出块太快
  - 实际用时：7天（比预期快7天）
  - 系数：20160/10080 = 2.0
  - 新难度：旧难度 × 2.0（难度翻倍）
  - 目标：让挖矿变难，把出块时间拉回10分钟

  例子2：矿场断电，出块太慢
  - 实际用时：21天（比预期慢7天）
  - 系数：20160/30240 = 0.67
  - 新难度：旧难度 × 0.67（难度降低33%）
  - 目标：让挖矿变容易，把出块时间缩短到10分钟

  为什么这样设计？

  负反馈机制

  负反馈回路：
  算力增加 → 出块加快 → 难度自动提高 → 出块速度恢复正常
  算力减少 → 出块变慢 → 难度自动降低 → 出块速度恢复正常

  目的：
  - 维护网络稳定性
  - 保证10分钟出块间隔
  - 防止恶意算力攻击

  2021年5月：中国打击挖矿
