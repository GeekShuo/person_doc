## 掌握等级

| 等级 | 判断依据 |
| --- | --- |
| 未评估 | 尚无足够信息判断 |
| 接触 | 看过或听过，但暂不能独立复述 |
| 理解 | 能用自己的话解释主要内容 |
| 应用 | 能独立做题、输出或用于实际任务 |
| 熟练 | 间隔一段时间仍能稳定应用 |

等级根据你报告的表现或可见产出更新；不因单纯花费时间而自动提高。
