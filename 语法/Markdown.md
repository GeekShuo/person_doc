## 16. 最佳实践

1. **保持一致性**：在整个文档中使用一致的格式
2. **适当的标题层级**：不要跳级使用标题
3. **代码块指定语言**：为代码块指定语言以获得语法高亮
4. **有意义的链接文本**：使用描述性的链接文本而不是原始URL
5. **图片替代文本**：为图片提供有意义的替代文本
6. **适当使用列表**：用列表组织相关内容
7. **表格格式化**：保持表格的整洁和可读性

## 17. 常见错误避免

- 标题后的空格
- 链接和图片的路径正确性
- 表格的竖线对齐
- 代码块的正确转义
- HTML 标签的正确关闭
