# [3] 无重复字符的最长子串 (Longest Substring Without Repeating Characters)

## 题目描述
给定一个字符串 `s` ，请你找出其中不含有重复字符的 最长子串 的长度。

## 解题思路
- **滑动窗口（双指针）**：这道题是经典的滑动窗口问题。
- 我们使用两个指针 `left` 和 `right` 表示滑动窗口的左右边界，使用一个哈希集合或哈希表（这里用字典存字符对应的最新索引更佳）来记录窗口内出现过的字符。
- 右指针 `right` 不断向右移动，并将对应字符加入集合。
- 如果遇到重复字符，并且该重复字符的索引在 `left` 或 `left` 的右边，我们就将 `left` 直接移动到重复字符上一次出现位置的下一个位置，从而保证窗口内没有重复字符。
- 每次移动时，更新最大长度 `max_len = max(max_len, right - left + 1)`。

## 代码模版 (Python)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        char_index_map = {}
        left = 0
        max_len = 0
        
        for right, char in enumerate(s):
            # 如果字符出现过，且其索引在 left 或其右边，更新 left
            if char in char_index_map and char_index_map[char] >= left:
                left = char_index_map[char] + 1
            
            # 更新字符最新的索引
            char_index_map[char] = right
            # 更新最大长度
            max_len = max(max_len, right - left + 1)
            
        return max_len
```

## 边界条件与易错点
1. **更新 `left` 的条件**：哈希表里有这个字符不代表就要缩减窗口，只有当该字符上一次出现的索引 `>= left`（即在当前窗口内）时，才需要把 `left` 移动到它的右边。
2. **空字符串**：如果 `s` 是空字符串，应返回 0。我们的代码 `for` 循环不执行，直接返回 `max_len` 的初始值 0，刚好满足要求。
3. **全是相同字符**（如 `"bbbbb"`）或**完全无重复字符**（如 `"abc"`），滑动窗口依然可以一次遍历准确算出结果。
