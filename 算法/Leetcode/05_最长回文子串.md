# [5] 最长回文子串 (Longest Palindromic Substring)

## 题目描述
给你一个字符串 `s`，找到 `s` 中最长的回文子串。
如果字符串的反序与原始字符串相同，则该字符串称为回文字符串。

## 解题思路
- **中心扩展法 (O(n^2))**：回文串一定是对称的。我们可以遍历字符串每个位置，将其视为回文串的中心点，向两边扩展。由于回文串长度可能是奇数也可能是偶数，所以共有 $2n-1$ 个中心点（包含夹在两字符中间的点）。
- 每次扩展更新目前找到的最长回文子串。
- （进阶：Manacher 算法时间复杂度可达 O(n)，但在面试中 O(n^2) 中心扩展法是首选且最易懂的代码。）

## 代码模版 (Python)

```python
class Solution:
    def longestPalindrome(self, s: str) -> str:
        if not s:
            return ""
            
        start = 0
        max_len = 0
        
        # 辅助函数：从中心向两边散开找回文长度
        def expand_around_center(left: int, right: int) -> int:
            while left >= 0 and right < len(s) and s[left] == s[right]:
                left -= 1
                right += 1
            # 退出循环时，说明 s[left] 已经不等于 s[right]（或者越界了）
            # 回文串的实际长度为 (right - 1) - (left + 1) + 1 = right - left - 1
            return right - left - 1
            
        for i in range(len(s)):
            # 奇数长度回文：以 i 这一单个字符为中心
            len1 = expand_around_center(i, i)
            # 偶数长度回文：以 i 和 i+1 中间空位为中心
            len2 = expand_around_center(i, i + 1)
            
            # 取最长的一种
            cur_max = max(len1, len2)
            
            # 如果比全局找的最大长，我们更新 start 和 max_len
            if cur_max > max_len:
                max_len = cur_max
                # 计算 start 位置：
                # 如果是奇数长度，左边界是 i - (cur_max - 1) // 2
                # 如果是偶数长度，左边界也是 i - (cur_max - 1) // 2 （Python 中地板除刚好适用两者）
                start = i - (cur_max - 1) // 2
                
        return s[start: start + max_len]
```

## 边界条件与易错点
1. **如何正确计算 `start` 位置**：这是中心扩展法最容易写错的地方！无论是奇数长度还是偶数长度 `cur_max`，由于我们循环走到 `i` 时相当于靠左侧的中心点，利用公式 `start = i - (cur_max - 1) // 2` 这个巧妙的地板除法可以完美兼容奇数和偶数的长度。
2. **中心扩展函数的返回值**：退出 `while` 循环时，`left` 和 `right` 处在失配的位置。真正的回文只包含 `[left + 1, right - 1]` 这一段。因此长度是 `right - left - 1`，不是 `right - left + 1`！
3. **空字符串处理**：传入空字符串应当返回 `""`，代码开始应先特判。
