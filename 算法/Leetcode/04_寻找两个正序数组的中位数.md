# [4] 寻找两个正序数组的中位数 (Median of Two Sorted Arrays)

## 题目描述
给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。
算法的时间复杂度应该为 `O(log (m+n))` 。

## 解题思路
- **二分查找 (O(log(min(m,n))))**：此题常规的合并数组再找中位数会达到 O(m+n) 的复杂度，不满足题目要求的 log 级别。为了达到 O(log(m+n))，我们需要直接在数组上做二分查找。
- 该问题可以转化为：**在两个有序数组中寻找第 `k` 小的数**。由于是寻找中位数，如果总长度 `total` 是奇数，中位数是第 `total // 2 + 1` 小的数；如果是偶数，则是第 `total // 2` 和 `total // 2 + 1` 小的数的平均值。
- 每次比较两个数组中第 `k // 2` 个元素，将较小的一边所在的这一段（及之前的部分）丢弃，从而使得查找范围迅速缩小一半。

## 代码模版 (Python)

```python
class Solution:
    def findMedianSortedArrays(self, nums1: list[int], nums2: list[int]) -> float:
        total = len(nums1) + len(nums2)
        
        # 辅助函数：找第 k 小的元素，k 是第几小，从 1 开始
        def get_kth(k: int, idx1: int, idx2: int) -> int:
            # 边界情况1：如果 nums1 已经遍历完了（idx1 越界），说明第 k 个元素全部在 nums2 中
            if idx1 == len(nums1):
                return nums2[idx2 + k - 1]
            # 边界情况2：同理，nums2 遍历完了
            if idx2 == len(nums2):
                return nums1[idx1 + k - 1]
            # 边界情况3：排除到只剩最后一个元素，直接对比两边的开始元素取最小
            if k == 1:
                return min(nums1[idx1], nums2[idx2])
            
            # 常规二分：我们要找两边各一半的长度
            half = k // 2
            # 计算对比的索引下标。注意不要越界
            new_idx1 = min(idx1 + half, len(nums1)) - 1
            new_idx2 = min(idx2 + half, len(nums2)) - 1
            
            pivot1, pivot2 = nums1[new_idx1], nums2[new_idx2]
            if pivot1 <= pivot2:
                # 排除 nums1 这边到 new_idx1 的部分（因为它们绝不可能是第 k 小）
                # 扣除掉排除的元素个数：new_idx1 - idx1 + 1
                return get_kth(k - (new_idx1 - idx1 + 1), new_idx1 + 1, idx2)
            else:
                # 排除 nums2 这边的部分
                return get_kth(k - (new_idx2 - idx2 + 1), idx1, new_idx2 + 1)
                
        if total % 2 == 1:
            return float(get_kth(total // 2 + 1, 0, 0))
        else:
            return (get_kth(total // 2, 0, 0) + get_kth(total // 2 + 1, 0, 0)) / 2.0
```

## 边界条件与易错点
1. **越界处理**：在取 `k // 2` 长度的时候，很可能会超出某个数组的实际长度。因此 `new_idx1` 取 `min(idx1 + half, len(nums1)) - 1`，确保不越界。
2. **退出条件**：`k=1` 或者某个数组为空的时候必须退出，否则后续 `half = 0` 会陷入死循环或者异常。
3. **排除数量的计算**：减去的 k 不一定是 `k//2`，因为可能遇到了越界被截断了，所以减去的应该是**实际排除掉的元素个数**（即 `new_idx - idx + 1`）。
