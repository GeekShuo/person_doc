# [242] 有效的字母异位词 (Valid Anagram)

## 题目描述
给定两个字符串 `s` 和 `t` ，编写一个函数来判断 `t` 是否是 `s` 的字母异位词。
**注意**：若 `s` 和 `t` 中每个字符出现的次数都相同，则称 `s` 和 `t` 互为字母异位词。

## 解题思路
- **哈希表计数**：这题和【383. 赎金信】非常相似，区别在于这题要求两个字符串的**字母频率完全一致**。
- 如果两个字符串长度不同，显然不是字母异位词，直接返回 `False`。
- 然后统计 `s` 中所有字符的出现次数，接着遍历 `t` 对计数减一。如果出现任何小于 0 的情况，说明不匹配；最后遍历完必然全抵消为 0（因为长度一致）。

## 代码模版 (Python)

```python
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        # 长度不同，绝对不可能
        if len(s) != len(t):
            return False
            
        from collections import Counter
        # 统计 s 中的字符
        count = Counter(s)
        
        # 遍历 t 开始抵消
        for char in t:
            count[char] -= 1
            if count[char] < 0:
                return False
                
        return True
```
*注：Python 直接 `return Counter(s) == Counter(t)` 或 `return sorted(s) == sorted(t)` 均可 AC，手写 Counter 是面试标准做法。*

## 边界条件与易错点
1. **长度校验**：这是优化复杂度的关键第一步。
2. **数组替代哈希**：这题题目写明了只包含小写字母，所以在底层可以使用 `int[] record = new int[26];` 来代替字典可以进一步提速（尤其对于 C++/Java），但在 Python 中自带的 `dict` / `Counter` 已经足够快。
