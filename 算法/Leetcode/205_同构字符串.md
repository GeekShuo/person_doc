# [205] 同构字符串 (Isomorphic Strings)

## 题目描述
给定两个字符串 `s` 和 `t` ，判断它们是否是同构的。
如果 `s` 中的字符可以按某种映射关系替换得到 `t` ，那么这两个字符串是同构的。
每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。**不同字符不能映射到同一个字符上**，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

## 解题思路
- **双向哈希映射**：为了保证一一对应关系，我们需要同时保证 `s` 到 `t` 的映射，以及 `t` 到 `s` 的映射。
- 构建两个字典 `s_to_t` 和 `t_to_s`。
- 遍历字符串时：
  - 如果 `s[i]` 在 `s_to_t` 中，对应的被映射字符必须是 `t[i]`，否则返回 `False`。
  - 同理，如果 `t[i]` 在 `t_to_s` 中，对应被映射字符必须是 `s[i]`，否则返回 `False`。
  - 如果都不在，说明是新遇到的对应关系，把它们成对存入两个字典。

## 代码模版 (Python)

```python
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        # 长度不同一定不是同构的（虽然本题保证了长度相等，加上更严谨）
        if len(s) != len(t):
            return False
            
        s_to_t = {}
        t_to_s = {}
        
        for char_s, char_t in zip(s, t):
            # 检查正向映射是否一致
            if char_s in s_to_t and s_to_t[char_s] != char_t:
                return False
            # 检查反向映射是否一致
            if char_t in t_to_s and t_to_s[char_t] != char_s:
                return False
                
            # 建立新的映射
            s_to_t[char_s] = char_t
            t_to_s[char_t] = char_s
            
        return True
```
*注：Python 中其实有一行黑科技：`return len(set(s)) == len(set(t)) == len(set(zip(s, t)))`。但从理解双向绑定的角度，手写字典更合面试要求。*

## 边界条件与易错点
1. **只使用单个哈希表**：只验证 `s -> t` 如果 `s="badc"`，`t="baba"`，`b->b` 和 `a->a`，到 `d` 的时候想映射给 `b`，但由于没有记录反向绑定，你不知道 `b` 已经被 `b` 抢占了！这就是为什么必须双向验证（不同字符不能映射到同一个字符上）。
2. **字符集**：题目允许任何 ASCII 字符，不仅仅是小写字母，因此不要预设为 26 长度的数组，使用哈希表最稳妥。
