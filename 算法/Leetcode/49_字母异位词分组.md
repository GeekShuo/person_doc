# [49] 字母异位词分组 (Group Anagrams)

## 题目描述
给你一个字符串数组 `strs` ，请你将 **字母异位词** 组合在一起。可以按任意顺序返回结果列表。
**字母异位词** 是由重新排列源单词的所有字母得到的一个新单词。（即包含的字母种类和数量完全相同的单词）。

## 解题思路
- **排序作为哈希表键值**：因为字母异位词无论内部怎么重排，它们**内部字符排完序后的结果是一模一样的**。如果 `eat`, `tea`, `ate` 排序后都是 `"aet"`。
- 我们可以遍历字符串数组，将每个字符串排序后作为字典的键（Key），将原始字符串本身加入该键对应的列表（Value）中。
- 最后将字典所有的 Value 取出即可。
- （进阶思路：如果不希望每次都 O(K log K) 排序，可以把 `a-z` 这 26 个字母的出现频次统计成一个 tuple 作为键，这样将时间复杂度降为 O(N*K)）。

## 代码模版 (Python)

```python
class Solution:
    def groupAnagrams(self, strs: list[str]) -> list[list[str]]:
        from collections import defaultdict
        
        # 利用 defaultdict，如果键不存在默认创建一个空列表
        anagram_map = defaultdict(list)
        
        for string in strs:
            # 题眼：将字符串排序转换回字符串作为特征键
            # string 是 'eat' -> sorted 变成 ['a', 'e', 't'] -> join 成 'aet'
            sorted_key = "".join(sorted(string))
            
            # 或者按照进阶思路，用各个字母出现次数当 key，避免 O(klogk) 排序：
            # counts = [0] * 26
            # for char in string:
            #     counts[ord(char) - ord('a')] += 1
            # sorted_key = tuple(counts) 
            
            anagram_map[sorted_key].append(string)
            
        return list(anagram_map.values())
```

## 边界条件与易错点
1. **字典的键必须可哈希**：在 Python 中，不仅列表不可以做键，`sorted(s)` 返回的是一个 `list`，所以不能直接用 `sorted(s)` 当字典的建，必须把它 `" ".join()` 变回不可变字符串，或者转为 `tuple`。如果不先转换直接作为字典键，会报错 TypeError: unhashable type: 'list'。
2. **使用 defaultdict**：普通字典 `dict` 在 append 之前需要判断 key 是否已存在：`if key not in dic: dic[key] = []`，使用 `defaultdict(list)` 能让代码更加简洁优雅。
