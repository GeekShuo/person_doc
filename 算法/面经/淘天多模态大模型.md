3.介绍Transformer，编码器和解码器的注意力有什么区别
**解答**：Transformer 的核心就是自注意力机制。编码器和解码器在注意力上的关键区别：
- **编码器的注意力是双向的**：每个 token 可以同时看到它前面和后面的所有 token，获得完整的上下文理解。这就是为什么 BERT 在理解任务上很强——它能通盘考虑整句话。
- **解码器的注意力是单向的（因果遮掩）**：通过一个下三角矩阵 Mask，让每个 token 只能看到它左边和自身的 token，严禁偷看未来的词。这是自回归生成的必要条件——你总不能在写第 5 个字的时候就看到第 10 个字是什么吧。
- 此外，在 Encoder-Decoder 架构中，Decoder 还有一个**交叉注意力（Cross-Attention）**层，用于从 Encoder 的输出中提取信息。

4.了解CLIP吗 ，介绍一下其他的对比学习方法
**解答**：
- **CLIP**：OpenAI 的开创性工作，用 4 亿图文对训练了一个图像编码器和一个文本编码器，目标是让匹配的图文对在特征空间中靠近，不匹配的远离（InfoNCE Loss）。训练好之后，不用任何微调就能做零样本图像分类——直接算图片和文本标签的相似度就行。
- **其他对比学习方法**：
  - **MoCo（Momentum Contrast）**：用一个动量更新的编码器维护一个大的负样本队列，避免了需要超大 Batch 的限制。
  - **SimCLR**：简单暴力，对同一张图做两种随机数据增强作为正对，同一个 Batch 里的其他图作为负对，需要非常大的 Batch Size 才能训好。
  - **DINO/DINOv2**：自蒸馏方法，Teacher 和 Student 看同一图的不同裁剪，不需要负样本，效果非常好。

5.说一下R1的训练过程
**解答**：DeepSeek-R1 的训练非常有意思，它的核心亮点是用强化学习激发推理能力：
1. **Cold Start（冷启动）**：先用少量高质量的长思维链数据做 SFT，教会模型"思考的格式"。
2. **RL 训练（GRPO）**：这是最关键的一步——不再依赖人类标注，而是用规则验证器（数学题对不对、代码能不能跑通）作为奖励信号，通过 GRPO 算法让模型自主探索推理策略。在这个过程中，模型涌现出了"自我反思""回溯纠错"等行为，DeepSeek 称之为"aha moment（顿悟时刻）"。
3. **拒绝采样 + SFT**：用 RL 后的模型生成大量推理数据，筛选出正确的作为新的 SFT 数据，再做一轮监督微调提升稳定性。
4. **最终 RL 对齐**：最后再做一轮 RL，加入安全性和格式方面的奖励信号，完成最终对齐。

6.BLIP 的三个损失函数分别是什么，数据是怎样清洗的
**解答**：
- **三个 Loss**：
  - **ITC（Image-Text Contrastive）**：图文对比损失，类似 CLIP，让匹配的图文对靠近、不匹配的远离。
  - **ITM（Image-Text Matching）**：图文匹配损失，把图文特征通过交叉注意力融合后，做二分类判断这对图文是否匹配。比 ITC 更细粒度。
  - **LM（Language Modeling）**：给定图像，自回归地生成对应的文本描述。训练模型的图像理解和文本生成能力。
- **数据清洗（CapFilt）**：BLIP 的一个核心贡献。网上爬来的图文数据噪声很大，于是 BLIP 训练了两个小模型：一个 **Filter（过滤器）** 判断图文是否真的匹配，过滤掉噪声数据；一个 **Captioner（描述生成器）** 给图片重新生成高质量描述。用这种方式反复迭代清洗数据，极大提升训练数据质量。

7.BLIP2相对于 BLIP 有哪些改进，BLIP3又有哪些改进
**解答**：
- **BLIP-2 的改进**：最大的突破是引入了 **Q-Former（Querying Transformer）**。它完全冻结视觉编码器和 LLM，只训练中间 Q-Former 这个轻量桥接模块。Q-Former 用一组可学习的 Query Token，通过交叉注意力从视觉特征中提炼出压缩的语义表示，再喂给 LLM。好处是：不用微调大模型，训练成本大幅降低，而且可以灵活替换不同的视觉编码器和 LLM。
- **BLIP-3（XGen-MM / InstructBLIP 等后续工作）的改进**：在 BLIP-2 的架构基础上，重点做了多模态指令微调（Instruction Tuning），引入海量多样化的视觉问答、推理、OCR 等任务数据进行训练，让模型能理解和执行各种复杂的多模态指令，大幅提升了泛化能力。

8.视觉编码器和 LLM 连接时，使用BLIP2中 Q - Former 那种复杂的 Adaptor 好还是 LLaVA 中简单的 MLP 好，说说各自的优缺点
**解答**：
- **Q-Former 的优缺点**：
  - 优点：把成百上千个视觉 Token 压缩成几十个 Query Token，大幅减少 LLM 需要处理的 Token 数量，节省显存和推理时间。
  - 缺点：Q-Former 本身比较复杂，需要单独精心训练，训练难度大、收敛慢；压缩过度时可能丢失细节信息（比如小字、细粒度空间关系）。
- **LLaVA MLP 的优缺点**：
  - 优点：结构极简，训练快、好调参、稳定性好；不丢失视觉信息，细节保留完整。实践证明简单的 MLP 投影就能达到非常好的效果。
  - 缺点：所有视觉 Token 全部保留传给 LLM（如 576 个 Token），占据大量上下文窗口，推理时显存和计算开销较大。
- **现在的趋势**：LLaVA 的简单 MLP 方案反而成了主流，因为大家发现只要数据质量好、训练充分，简单投影的效果不比复杂 Q-Former 差，甚至更好。

9.代码：买卖股票最佳时机
**解答**：LeetCode 121，经典贪心。一次遍历，维护一个"到目前为止见过的最低价"，每到一个新价格就算一下"如果今天卖出利润是多少"，更新最大利润。

```python
def maxProfit(prices):
    min_price = float('inf')
    max_profit = 0
    for price in prices:
        min_price = min(min_price, price)       # 到目前为止的最低买入价
        max_profit = max(max_profit, price - min_price)  # 今天卖出的利润
    return max_profit
```

时间 O(N)，空间 O(1)。

2.Qwen- VL 的三个训练流程分别是什么，有什么作用
**解答**：Qwen-VL 采用了三阶段渐进式训练：
- **第一阶段（预训练对齐）**：使用大规模网络图文对数据，冻结视觉编码器和 LLM，只训练中间的连接模块（如 Resampler/Adapter），让视觉特征和语言特征在同一空间对齐。这一步是打基础。
- **第二阶段（多任务微调）**：解冻视觉编码器，引入高分辨率图片，混合多种多模态任务（VQA、OCR、Grounding、图文交织理解等）进行大规模指令微调。同时支持多图输入，全面提升模型的视觉理解能力和指令遵循能力。
- **第三阶段（偏好对齐）**：通过 DPO 或 RLHF 等方法，参照人类偏好进行最终对齐，让模型的回答更安全、更有用、更符合人类期望。

介绍一下 CLIP 
**解答**：CLIP（Contrastive Language-Image Pre-training）是 OpenAI 在 2021 年提出的图文对齐模型。核心思路很直观：用一个图像编码器和一个文本编码器分别将图片和文本编码为向量，然后通过对比学习让匹配的图文对向量相似度高、不匹配的相似度低。训练用了 4 亿图文对。训练好之后，想做图像分类的话，只需要把类别名称编码成文本向量，然后和图片向量算内积取最相似的就行——完全不用微调，零样本泛化能力极强。

3.后来有哪些比较经典的基于 Transformer 的语言模型， Qwen 相比于原始 Transformer 有哪些结构上的改动
**解答**：
- **经典模型**：GPT 系列（GPT-2/3/4）、LLaMA 系列、Mistral、Gemma 等，都是 Decoder-Only 架构的代表。
- **Qwen 相比原始 Transformer 的改动**：
  1. **位置编码**：抛弃了原始的 Sinusoidal 绝对位置编码，改用 **RoPE（旋转位置编码）**，外推性更好，支持更长上下文。
  2. **激活函数**：抛弃了 ReLU，改用 **SwiGLU**，带有门控机制，实证表明性能和泛化更好。
  3. **归一化方式**：抛弃了 LayerNorm，改用 **RMSNorm**（Root Mean Square Normalization），去掉了均值中心化，只保留方差归一化，计算更快、效果一样好。
  4. **注意力机制**：采用 **GQA（Grouped Query Attention）** 代替原始的 MHA，减少 KV Cache 以加速推理。
  5. **Pre-Norm**：将 Norm 层放在注意力/FFN 之前而非之后，训练更稳定。

4.了解 RLHF 吗， DPO 和 PPO 有什么区别， Loss 是什么样的，各自的优缺点是什么
**解答**：
- **PPO**：需要单独训练一个 Reward Model 给模型生成的回复打分，然后通过 PPO 算法（带 Clip 截断的策略梯度 + KL 散度约束）来优化 Policy Model。训练流程复杂，需要同时维护 4 个模型（Policy、Reference、RM、Critic），显存消耗大，但探索能力强。
- **DPO**：数学上证明了 RL 最优策略可以用 Policy 自身的 log 概率比直接表达，因此**不需要单独的 RM**。直接拿人类偏好的成对数据（chosen vs rejected），用一个二分类交叉熵 Loss 端到端训练。Loss 公式是：`L = -log σ(β * (log π(y_w|x)/π_ref(y_w|x) - log π(y_l|x)/π_ref(y_l|x)))`，其中 y_w 是好的回复，y_l 是差的回复。
- **DPO 优点**：稳定、简单、省显存、工程友好。**缺点**：离线优化，无法实时探索新策略。
- **PPO 优点**：在线探索，能发现训练数据中没有的好策略。**缺点**：工程复杂度高，训练不稳定，调参困难。

6.了解 LoRA 吗， LoRA 微调的原理是什么 
**解答**：LoRA（Low-Rank Adaptation）的核心思想是：模型的权重更新矩阵 ΔW 其实是低秩的，没必要更新全部参数。具体做法：冻结原始预训练权重 W，在旁边插入两个小矩阵 A（降维，d→r）和 B（升维，r→d），其中 r 远小于 d（比如 r=8 或 16）。前向传播时 `output = Wx + BAx`，只训练 A 和 B。好处：训练参数量只有原模型的千分之几，显存占用大幅降低，而效果接近全参数微调。推理时还可以把 BA 合回 W 中，不增加任何推理延迟。

7.对PPO DPO GRPO计算逻辑的理解
**解答**：
- **PPO**：在线采样 → RM 打分 → Critic 估值 → GAE 计算 token 级优势 → Clip 限制更新幅度 + KL 惩罚。核心是用 Critic 做 token 级信用分配。
- **DPO**：直接用偏好数据对 → 计算 chosen/rejected 的 log 概率差 → 与 Reference Model 的概率差做对比 → 二分类交叉熵优化。核心是把 RM 隐式融入了优化目标。
- **GRPO**：对同一 Prompt 采样一组回复 → 全部打分 → 组内 Z-score 归一化得到优势 → Clip 更新。核心是用"同组比较"替代 Critic 模型。

8.代码：实现多头自注意力 
**解答**：

```python
import torch
import torch.nn as nn
import math

class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, n_heads):
        super().__init__()
        self.n_heads = n_heads
        self.head_dim = d_model // n_heads
        self.W_q = nn.Linear(d_model, d_model, bias=False)
        self.W_k = nn.Linear(d_model, d_model, bias=False)
        self.W_v = nn.Linear(d_model, d_model, bias=False)
        self.W_o = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x, mask=None):
        B, L, D = x.shape
        # 投影
        Q = self.W_q(x).view(B, L, self.n_heads, self.head_dim).transpose(1, 2)
        K = self.W_k(x).view(B, L, self.n_heads, self.head_dim).transpose(1, 2)
        V = self.W_v(x).view(B, L, self.n_heads, self.head_dim).transpose(1, 2)
        # Scaled Dot-Product Attention
        scores = (Q @ K.transpose(-2, -1)) / math.sqrt(self.head_dim)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float('-inf'))
        attn = torch.softmax(scores, dim=-1)
        out = (attn @ V).transpose(1, 2).contiguous().view(B, L, D)
        return self.W_o(out)
```

2.GNN与LLM结合理解 
**解答**：GNN 和 LLM 各有所长，结合可以互补：
- **LLM 的强项**：自然语言理解、常识推理、文本生成。**弱项**：不擅长处理图结构数据（如社交网络、知识图谱、分子结构）。
- **GNN 的强项**：对图结构数据的拓扑关系建模（节点间的消息传递和聚合）。**弱项**：缺乏语义理解和常识推理能力。
- **结合方式**：
  1. GNN 提取图结构特征 → 投影到 LLM 的输入空间作为额外 token → LLM 结合语言和图结构做推理。
  2. LLM 先对图中节点的文本属性做语义编码 → 作为 GNN 的初始节点特征 → GNN 做图推理。
  3. 在知识图谱问答中，用 GNN 在子图上推理得到候选答案，再用 LLM 做最终排序和生成。
