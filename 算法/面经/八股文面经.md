3.在 RM 训练阶段，我们通常收集的是成对比较数据，而不是让人类标注者直接给回复打一个绝对分数。你认为这样做的主要优势和潜在的劣势分别是什么？
**解答**：成对比较的优势：人类非常擅长比大小（A比B好），打绝对分（给A打8分，给B打7分）对人类来说太难了。而且成对比较能够消除标注员因为个人绝对尺度不一致的问题。劣势：信息丢失严重，只能知道A好于B，但不知道A到底比B好多少。

4.奖励模型的模型架构通常如何选择？它与我们最终要优化的 LLM 是什么关系？在训练奖励模型时，常用的损失函数是什么？
**解答**：架构：通常采用与SFT模型同等大小的LLM，只是把最后的 LM Head 替换成 Scalar Header。关系：RM 用于给模型打分。常用损失函数：Pairwise Ranking Loss（交叉熵的变种）。

5.在 RLHF 的第三阶段， PPO 是最主流的强化学习算法。为什么选择 PPO ，而不是其他更简单的策略梯度算法（如 REINFORCE ）或者 Q - learning 系算法？ PPO 中的 KL 散度惩罚项起到了什么关键作用？
**解答**：PPO非常稳定。它采用了截断机制（Clip），限制了模型参数更新步长。KL 散度惩罚项用于约束模型不要距离 SFT 模型太远，防止出现 Reward Hacking 导致胡言乱语。

6.如果在 PPO 训练过程中， KL 散度惩罚项的系数 B 设置得过大或过小，分别会导致什么样的问题？你将如何通过实验和观察来调整这个超参数？
**解答**：系数B过大：模型完全被死死拉回、钉死在SFT模型上，无法进行任何强化学习更新。过小：模型脱缰野马，为了拿 RM 的最高分，尽一切可能寻找捷径（例如吐出大量人类看不懂但在 RM 看来分数极高的乱码或者重复词汇）。

7.什么是"奖励作弊／奖励黑客"( Reward Hacking )?请结合一个具体的 LLM 应用场景给出一个例子，并探讨几种可能的缓解策略。
**解答**：指的是模型找到了 RM 的漏洞，为了拿高分而生成没有任何实际意义但符合高分特征的回答。例如：问怎么打开电脑，模型回答了一万字关于电脑有多伟大的废话赞美词，但没有一句有用。缓解策略：引入长度惩罚（Length Penalty）。

8.RLHF 流程复杂且不稳定。近年来出现了一些替代方案，例如 DPO 。请解释 DPO 的核心思想，并比较它与传统 RLHF （基于 PPO ）的主要区别和优势。
**解答**：核心思想：将 Reward Model 的偏好直接隐式地用 Policy Model 自己表达。优势：彻底抛弃了单独训练巨大 Reward 裁判网络的过程，并且也抛弃了由于 PPO 及其 Actor/Critic 模型带来的极大训练不稳定性和超大显存消耗问题，使得强化学习极其容易落地。

9.想象一下，你训练完成的 RLHF 模型在离线评估中表现优异，奖励模型分数很高，但上线后用户反馈其回答变得越来越"模式化"、奉承、且缺乏信息量。你认为可能的原因是什么？你会从哪些方面着手分析和解决这个问题？
**解答**：原因：RM 裁判网络本身自己过拟合了，有了偏见（裁判就喜欢这种长篇大论打官腔、拍马屁的八股文回答）。解决措施：收集 RM 偏好数据时，极大增强多样性和领域覆盖。

10.你知道 Deepseek 的 GRPO 吗，它和 PPO 的主要区别是什么？
**解答**：GRPO 抛弃了 PPO 极其庞大的 Critic 裁判网络，极大节省了显存，依靠自身生成的极其大量的（比如64个或者128个）多路样本进行互相打分比对（Z-score Normalize）。

11.GSPO和 DAPO 有听说过吗？他们和 GRPO 有什么区别？
**解答**：将粗糙的、段落级别的反馈细化为了多步骤（Step-Wise）过程，主要应用在如数学推理极长链路等每一步极其关键的推导过程中。

12.如何解决信用分配问题？ token 级别和 seq 级别的奖励有何不同？
**解答**：Token 级别能够精确指出到底生成这个句子的哪个词坏了事，极大地加速并稳定了收敛。比 Seq 级别由于只能给出一个干巴巴的整体得分，要强得多且细致得多。

13.除了人类反馈，我们还可以利用 AI 自身的反馈来做对齐，即 RLAIF 。请谈谈你对 RLAIF 的理解，它的潜力和风险分别是什么？
**解答**：利用超大杯天然模型（如 GPT-4）这尊大神作为裁判打分，替代人类。潜力：极度省钱省力。风险：大模型自己的盲区偏见将完美遗传给小模型，小模型越发陷入大模型的世界模型幻觉里。
