智能合约实例：自动售货机合约

  合约代码（简化版）

  contract VendingMachine {
      uint256 public price = 1 ether; // 商品价格：1个以太币
      address public owner; // 合约部署者
      bool public itemAvailable = true; // 商品库存状态

      constructor() {
          owner = msg.sender; // 设置部署者为合约所有者
      }

      function purchase() public payable {
          require(itemAvailable, "商品已售完"); // 检查是否有货
          require(msg.value == price, "付款金额不正确"); // 检查付款金额

          itemAvailable = false; // 标记商品已售出
          payable(owner).transfer(msg.value); // 将钱转给所有者
          // 这里可以添加发货逻辑
      }

      function restock() public {
          require(msg.sender == owner, "只有所有者可以补货");
          itemAvailable = true;
      }
  }

  执行流程

  1. 部署：所有者将合约部署到以太坊区块链
  2. 购买：用户调用purchase()函数，发送1个以太币
  3. 验证：合约自动检查条件（有货、金额正确）
  4. 执行：自动完成交易，无需第三方介入
  5. 记录：整个过程记录在区块链上，不可篡改

  传统方式 vs 智能合约

  | 传统售货机    | 智能合约售货机 |
  |----------|---------|
  | 需要维护人员   | 代码自动执行  |
  | 可能出现机械故障 | 无机械故障风险 |
  | 现金管理复杂   | 自动转账    |
  | 交易记录可能丢失 | 永久记录在链上 |

  
  - 区块链：像是一本无法篡改的公共账本，记录所有交易
  - 智能合约：像是账本上的自动执行条款，满足条件就自动触发

  在这个例子中，智能合约运行在区块链上，利用区块链的安全性和不可篡改性，实现了自动化的商业逻辑。
