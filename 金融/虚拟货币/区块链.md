  节点的具体工作

  交易验证流程

  1. 用户发起交易：调用智能合约或转账
  2. 广播到网络：交易被发送到附近的节点
  3. 节点验证：检查签名、余额、gas费等
  4. 打包区块：验证者节点将交易打包成区块
  5. 共识达成：全网节点就新区块达成共识
  6. 链上确认：新区块添加到区块链

  智能合约执行

  节点A：执行智能合约代码
      ↓
  节点B：验证执行结果
      ↓
  节点C：确认状态变更
      ↓
  全网：达成共识，更新状态

# 链上地址怎么确定
区块链地址是通过非对称加密技术生成的，每个地址都对应一个密钥对。让我详细解释生成过程：

  地址生成流程

  第1步：生成私钥

  # 256位随机数（32字节）
  私钥示例：
  E9873D79C6D87DC0FB6A5778633389F4453213303DA61F20BD67FC233AA33262

  第2步：从私钥推导公钥

  # 使用椭圆曲线加密算法（secp256k1）
  私钥 → ECDSA → 公钥

  私钥：E9873D79C6D87DC0FB6A5778633389F4453213303DA61F20BD67FC233AA33262
       ↓ (椭圆曲线乘法)
  公钥：04F01D6E... (64字节，压缩后33字节)

  第3步：从公钥生成地址（以比特币为例）

  公钥 → SHA256 → RIPEMD160 → 网络前缀 → Base58编码 → 地址

  详细步骤：
  1. 公钥：04F01D6E...（65字节）
  2. SHA256(公钥)：3F01D6E...（32字节）
  3. RIPEMD160(SHA256结果)：7A3F8B...（20字节）
  4. 添加网络前缀（主网=0x00）：007A3F8B...
  5. 校验和：007A3F8B...XX
  6. Base58编码：1BvBMSEYstWetqTFn5Au4m4GFg7xJaNVN2

  不同区块链的地址格式

  比特币地址

  传统地址：
  1BvBMSEYstWetqTFn5Au4m4GFg7xJaNVN2  (P2PKH)
  3J98t1WpEZ73CNmQviecrnyiWrnqRhWNLy  (P2SH)

  SegWit地址：
  bc1qar0srrr7xfkvy5l643lydnw9re59gtzzwf5mdq  (Bech32)

  以太坊地址

  格式：0x + 40位十六进制字符
  示例：0x742d35Cc6634C0532925a3b8D4C9db96C4b4Db45

  生成方式：
  公钥 → Keccak-256哈希 → 取后20字节 → 0x前缀

  地址生成代码示例

  Python生成比特币地址

  import hashlib
  import base58
  import ecdsa

  def generate_bitcoin_address():
      # 1. 生成私钥
      private_key = ecdsa.SigningKey.generate(curve=ecdsa.SECP256k1)

      # 2. 获取公钥
      public_key = private_key.get_verifying_key()

      # 3. SHA256
      sha256_hash = hashlib.sha256(public_key.to_string()).digest()

      # 4. RIPEMD160
      ripemd160 = hashlib.new('ripemd160')
      ripemd160.update(sha256_hash)
      hash160 = ripemd160.digest()

      # 5. 添加主网前缀
      payload = b'\x00' + hash160

      # 6. 双重SHA256校验
      checksum = hashlib.sha256(hashlib.sha256(payload).digest()).digest()[:4]

      # 7. Base58编码
      address = base58.b58encode(payload + checksum)

      return address.decode('utf-8')

  address = generate_bitcoin_address()
  print(f"比特币地址: {address}")

  JavaScript生成以太坊地址

  const crypto = require('crypto');
  const ethUtil = require('ethereumjs-util');

  function generateEthAddress() {
      // 1. 生成私钥
      const privateKey = crypto.randomBytes(32);

      // 2. 获取公钥
      const publicKey = ethUtil.privateToPublic(privateKey);

      // 3. Keccak256哈希
      const hash = ethUtil.keccak256(publicKey);

      // 4. 取后20字节
      const address = hash.slice(-20);

      // 5. 添加0x前缀
      return '0x' + address.toString('hex');
  }

  console.log('以太坊地址:', generateEthAddress());

  地址的安全性

  私钥的重要性

  私钥 → 地址生成流程（单向）→ 地址

  ❌ 不能反向推导
  地址 ✗→ 私钥（几乎不可能）

  所以：只要私钥不泄露，地址就是安全的
