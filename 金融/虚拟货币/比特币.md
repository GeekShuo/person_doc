比特币记录在比特币区块链这个专门的账本上，这是一个独立于以太坊等其他的区块链网络。

  比特币区块链账本结构

  基本组成

  比特币区块链账本：
  创世区块 (2009-01-03) → 区块1 → 区块2 → ... → 最新区块
        ↑                    ↑
      高度：0              高度：1          ...

  每个区块记录什么

  区块头信息：
  - 前一个区块哈希
  - Merkle根（所有交易的摘要）
  - 时间戳
  - 难度目标
  - Nonce（随机数）

  交易数据：
  - 发送方地址
  - 接收方地址
  - 转账金额（BTC）
  - 交易手续费
  - 数字签名

  独立账本系统

  比特币网络

  ┌─────────────────────────────────────────────────────┐
  │                比特币区块链账本                        │
  │                                                     │
  │  区块820,000 ← 区块819,999 ← ... ← 创世区块          │
  │       │              │                              │
  │  比特币交易      比特币交易                        │
  │  (BTC转账)      (BTC转账)                        │
  │                                                     │
  └─────────────────────────────────────────────────────┘
                              ↑
                      ~15,000个全节点维护

  与其他区块链的关系

  比特币账本 ←→ 以太坊账本 ←→ Solana账本 ←→ ...
      │           │           │
    独立网络     独立网络     独立网络
    独立账本     独立账本     独立账本

  真实的交易记录示例

  比特币交易

  区块高度：820,123
  时间：2024-01-15 14:30:22
  交易哈希：0x3f8c...7e2a

  输入：
  - 地址：1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa
  - 金额：0.5 BTC

  输出：
  - 地址：1BvBMSEYstWetqTFn5Au4m4GFg7xJaNVN2
  - 金额：0.498 BTC
  - 找零：0.001 BTC（手续费）

  账本查询方式

  区块浏览器

  网站：
  - blockchain.com
  - blockexplorer.com
  - mempool.space

  可查询：
  - 交易状态
  - 余额变化
  - 区块信息
  - 网络状态

  技术查询

  # 查看最新区块高度
  bitcoin-cli getblockchaininfo

  # 查询特定交易
  bitcoin-cli gettransaction "交易哈希"

  # 查询地址余额
  bitcoin-cli getreceivedbyaddress "地址"

  关键特点

  不可篡改性

  修改区块819,999：
  需要：
  1. 重新计算区块819,999的哈希
  2. 重新计算区块820,000的哈希
  3. 重新计算区块820,001的哈希
  ...
  4. 重新计算最新区块的哈希
  5. 获得51%的算力支持

  成本：几乎不可能

  全球账本同步

  美国节点 ←→ 中国节点 ←→ 欧洲节点
      │           │           │
    相同账本     相同账本     相同账本
    相同状态     相同状态     相同状态

  所以比特币就像在一个专门为BTC设计的"世界账本"上记账，这个账本由全球数万个节点共同维护，每笔交
  易都被永久记录且无法篡改。
