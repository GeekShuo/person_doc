## 二、CDG 项目深挖（本场主战场）

#### Q3 · 业务澄清：公安/法院是走接口传查询冻结文件？传的到底是什么？举个例 ⚠️
**我的回答**：讲了背景（商业机构不能随便给公安数据，商务部有要求）+ 输入形态（字段：哪个法院、查哪个账号、授权书/警官证；附件：PDF 或图片）+ 不合规形态（没盖章、图片糊、章和文书对不上、电话打不通、类型不在列表里）。

**失分点**：**信息对但组织散**，同一层意思重复了三遍（"授授授授明书"、"稍微有点糊"反复重讲），面试官中途只能自己总结一遍帮你收口。

**更优回答**：三句话结构化，一次讲完就停：
- **输入**：结构化字段（法院/账号/警官证/电话）+ 附件（PDF/图片）；
- **判定项**：印章有效性、类型码合法性、电话有效性、文书清晰度、异常检测，共 5~6 个模块；
- **输出**：同意 / 拒绝 + 错误类型码。
提示：讲完主动问"要不要我展开某一块"，把选择权交给面试官，避免自己铺太长。

#### Q4 · 拦截时给对方的 response 是什么？ ✅
**我的回答**：拒绝或同意；拒绝会带错误类型码（文书模糊 / 类型缺失 / 号码问题）。
**更优回答**：补两点就满分——① **响应分层**：业务码 + 可操作提示（"印章有问题"而不是"材料不全"，因为对方要拿去补材料）；② **合规与防对抗**：不暴露判定细节和阈值，避免被针对性绕过；支持**补材料后重提**（幂等 + 可重试），这一条正好接上 Q5。

#### Q5 · 拦截率 4.33% → 9.84%，你怎么定义"无效查询"？会不会误拦？召回多少？ ❌
**我的回答**：讲"无效"边界确实难定（要维持法院关系，稍微糊的也得放）→ 说测试集几万条、每批一万条 → **说"大概平均下来是 9.8% 的误拦"** → 精确率在这几万条上 ~100% → 召回只在几百条上看，"起码 70~80%"。

**失分点（本场最严重的一处）**：
1. **口径说反了**：把"拦截率 9.84%"说成了"9.8% 的误拦"——这两个是**完全不同**的量，面试官立刻抓"你这是拦截率还是误拦率"。**简历上的每一个数字都要能说出分子分母**；
2. **召回样本量太小**（几百条）却给了 70~80% 的点估计，没给置信区间，也没说抽样方式是否有偏；
3. **没讲清线上没有真值时怎么评估**——这是这个岗位最关心的问题。

**更优回答**（先定口径，再给评估方案）：
- **口径**：拦截率 = 被判定不合规的单据数 / 总请求数；分母是**全量请求**（不用抽样），分子是线上模型输出，所以拦截率本身是**可全量统计的、不需要标注**；
- **精确率怎么算**（无真值的核心难题）：对"模型判定不合规"的样本**全量人工复核**（量小、成本低），得到精确率；对"模型判定合规"的样本**分层抽样**复核（按模型分数分桶抽样，提高效率），得到漏放率估计 → 召回 = 1 − 漏放率 ×（合规量/真实不合规量），用**重要性抽样/分层估计**修正；
- **样本量与置信度**：几百条上估出的 70~80% 要补一句——"在 n=xx、置信水平 95% 下区间是 xx~xx，所以我更愿意说量级而非精确值"，**敢报区间比报单点更专业**；
- **主动承认**："9.84% 我们自己也认为偏低，是因为误判代价极高，我们在**精确率优先**的约束下才没继续压"。

#### Q6 · 【高价值追问】被打回后对方不再来第二次请求，能不能当作有效拦截？你们按 session 看过吗？ ❌
**我的回答**：承认没做，"这个可能之后处理的时候会把这个问题考虑一下"。

**为什么这题值钱**：面试官其实在**免费给你送一个线上弱监督标签方案**——这正是 Q5"线上没真值"的解法。答好这题能直接把 Q5 的失分补回来。

**更优回答**（四步，开口就给结论）：
1. **结论**：应该看，而且这是本场景**唯一能规模化拿到真值的途径**——把「同一法院 + 同一 UIN + 同一文书摘要」的多次请求串成 session；
2. **标签构造**：打回后**重新提交且内容有修改**（补章/换图/改电话）→ 说明是真需求、我们的拦截有**引导价值**；打回后**原样重提**→ 可能是材料确实有问题或流程对抗；打回后**不再来**→ 弱标签"疑似无效/试探"，但需排除"走了线下渠道"的噪声（用其他渠道查询记录对齐）；
3. **指标**：重提率、补材料后通过率、按错误类型的重提率分布（哪个模块的拦截最有价值）、**放弃率**（疑似无效占比，可作为拦截率质量的交叉验证）；
4. **边界**：不能单独作为真值（放弃也可能是去线下办了），要与人工复核样本做**校准**，把它当**弱监督 + 监控指标**而非 GT。

> 复盘：这类"面试官反问你一个你没做过的事"，**不要只说"之后可以考虑"**——先复述确认他的意图，再给可落地方案 + 边界条件，就变成加分题。

#### Q7 · 电话号码校验：为什么不用大模型？怎么判断号码能不能打通、属不属于这个地区的法院？ ✅
**我的回答**：分"有效性 + 合理性"两部分；号码是**字段**不是从图片 OCR 出来的；格式很乱（多个号码挤一起、区号与本地号有连字符/括号/无分隔）；本来想做接口强校验但产品说法院地位高、不能要求太多 → 最后用**14 条规则**兜住。

**更优回答**（把"脏活"讲成方法论）：
- **四段流水线**：归一化（全角/分隔符/多号码切分）→ 结构校验（区号合法性 + 本地号位数 + 总位数）→ **一致性校验（区号归属地 vs 法院地址）**→ 有效性（历史可联系性 / 白名单，而不是我们真去打电话）；
- **为什么不用大模型**（这题考的是取舍，答全四条）：① 成本（日均几十万次调用）② **不可解释 → 不可申诉**，合规审计需要给出明确原因 ③ 确定性任务规则更稳、延迟更低 ④ 可迭代（bad case 回流直接加规则，当天生效）；
- **规则治理**：14 条规则如何维护（每条规则有命中率/精确率监控、命中冲突的优先级、季度清理）；
- **点睛**：补一句"这不是技术做不到，是**甲方地位导致的接口约束问题**，技术侧做的是放宽输入、严判输出"——把产品博弈讲出来，面试官会认可你的全局视角（他当时就顺着说"这确实是产品问题"）。

#### Q8 · 清晰度任务：569 维 XGBoost 二分类，为什么改成五分类？ ✅
**我的回答**：真实分布不是清晰/模糊两端而是渐变的（"有点糊但没糊到不能看"要放过）；五分类让产品可选择性放宽松/收紧；训练效果也更好。

**更优回答**：补两个面试官追问点——
- **序数视角**：清晰→模糊是**有序**的，二分类把序数当名义，损失了序信息，中间带样本被强行压到两端；五分类 + 后两类合并为"模糊"，业务上仍可二值化，但阈值**可调**且**调阈值不需要重新训练**；
- **消融实验必须给**（面试官当场追问"XGBoost 也能做五分类，你比过吗"）：

| 方案 | 特征 | 标签 | 结果 |
|---|---|---|---|
| A 二分类 + 阈值切五档 | 569 维 | 二值 | 差（你说"直接划效果比较差"） |
| B XGBoost 五分类重训 | 同 569 维 | 五档 | 要有具体数字 |
| C VLM（Qwen3.5-9B）LoRA | 图片 | 五档 + 软标签 | 最优；**去掉语言层掉 ~2%** |

> 你的"C 去掉语言层掉 2 个点"这个细节讲得很好，说明**多模态语义（蒙文/藏文/手写体/印章干扰）是 C 胜出的根因**——面试时把这个因果讲成一句话结论。

#### Q9 · 五档标签是怎么定义的？ ⚠️
**我的回答**：两个业务维度——① 文字可辨比例（>95% → 一/二类；50~90% → 三类；10~40% → 四类；<10% → 五类）；② 一/二类之间再用**拉普拉斯方差（锐度/对比度）**区分。
**更优回答**：补两点——
- **为什么是"可辨比例 + 锐度"两维**：前者是**语义可读**（业务真正关心的：能不能看清写了什么），后者是**成像质量**（物理可测）；只用锐度会误判"字小但成像清晰"，只用 OCR 会误判"手写体/藏文"；
- **标注成本控制**：OCR 置信度先预标 → 只把**后三类（疑似模糊）**送产品复核 → 复核结果再去训 VLM。即"**便宜模型预标 + 人工只审边界样本**"，这也是你 ROI 的证明。

---

#### Q10 · OCR 为什么选 PaddleOCR 而不是 GPT-5.5？ ⚠️
**我的回答**：对比过，GPT-5.5 不如 PaddleOCR；参数量不到 1B、工业界最常用、成本极低。
**更优回答**：补上**失效模式**——你后面其实讲到了但没提前：OCR 置信度低 ≠ 图片糊，可能是**手写体、极小字体、藏文/蒙文、印章里的字、反光光晕**。所以 OCR 置信度只能当**特征**不能当**标签**，这正是要上 VLM 的原因。把"我为什么选它"和"它什么时候会骗我"一起讲，选型题才是满分。

---

#### Q11 · 既然有规则（拉普拉斯 + OCR 置信度），为什么还要 SFT 一个 9B 模型？ ✅
**我的回答**：规则在异常 case 上不行（印章里的字被当成正文、反光、小字、藏文手写体），预训练大模型能分辨"到底是谁糊"。
**更优回答**：把架构讲成**级联 ROI**：规则层（零成本，覆盖大部分确定样本）→ VLM 层（只处理规则低置信 / 边界档）→ 人工复核（最贵，只审最终结果）。并明确"**不是用 VLM 替换规则，而是规则预标 + VLM 精判 + 人工抽检**"，三层各有成本与职责。

#### Q12 · 硬件：用的什么卡？为什么不能训练？ ⚠️
**我的回答**：监管不让用英伟达卡，只能用国产卡（P600），训练算子缺失、生态不成熟，只能推理；后来被迫回到小模型。
**失分点**：卡型号说得含糊（"p六百 / p八百"来回改），面试官明显在确认你是否真的踩过。
**更优回答**：**面试前把硬件口径背死**——训练用 A800/P800，线上部署因合规要求落到国产卡（昆仑芯/P600），遇到的具体问题是算子缺失 + 驱动版本；应对路径是**蒸馏到小模型 / 量化 / 替换算子**，并说明这个约束如何反过来影响了你的技术选型（必须走"规则 + 小模型"路线）。数字说不利索的地方，宁可说"具体型号我记一下再确认"，不要现场改口。

#### Q13 · XGBoost 二分类为什么出现"双峰"？ ✅
**我的回答**：自己搭了标注/预览平台看数据，发现打分**排序不一致**（A 的分数比 B 高，但 A 实际更糊），说明阈值切分不可靠。
**更优回答**：补一句结论——双峰说明模型把样本推向两端、**中间地带分数不可信**，这正是"二分类定义本身有问题"的证据，由此推出序数五分类。你的"自己搭平台看数据"是很好的主动性证明，要在答案开头先讲。

---

#### Q14 · 五分类怎么让模型感知"有序"关系？ ✅
**我的回答**：让模型输出 `excellent / good / fair / bad` 这类**英文单词 token**，利用预训练模型对这些词的语义序关系。
**更优回答**（三种方案都报出来，是最加分的）：
1. **语义 token**（你的做法）：借预训练词序，零成本拿到序数先验；
2. **软标签 + KL**：把标注的均值/方差变成类别分布做监督，让相邻档惩罚更小（你的 CE+KL 就属于这一类，**面试时要把"KL 约束相邻档"这句话说完整**）；
3. **序数回归 / 距离加权损失**：预测相邻类别阈值为错误更轻；
4. **评估口径**：序数任务用 **QWK / MAE（偏离档数）**而不是 accuracy，并说明"后两类零误判"这个硬指标是怎么用**概率校准**保证的。

#### Q15 · 3.57% 是什么指标？样本量多大？能不能每天用大模型慢慢推？ ⚠️
**我的回答**：3.57% 不是召回，是**被判定为模糊（后两类）的样本占比**；样本"每批一万条"；通用多模态大模型判不了清晰度，必须微调。
**失分点**：样本量表述含糊（"两 p"），没给总数；"大模型判不了"是结论但没给证据。
**更优回答**：
- **口径三连**（被问任何数字都这样答）：3.57% = 判定为模糊的**占比**（分布/拦截口径），**不是召回、不是准确率**；样本量 = xx 张图 / xx 批 / 人工复核 xx 条（**背死具体数**）；
- **为什么不能直接用通用多模态模型**：给证据——"我们试过 xx 模型在 xx 条样本上与人工一致性只有 xx%，因为它预训练里没有'清晰度分级'这个任务，且判据是业务自定义的"；
- **为什么必须微调 + 成本账**：日均几十万条，大模型全量推理成本不可接受 → 只让 VLM 处理规则筛出的边界档。

## 三、京东 AI 安全护栏

#### Q16 · 场景是什么？负样本怎么构造？ ⚠️
**我的回答**：京东 AI 主站对话（客服/导购）用户发敏感图；风险点在**多轮对话**——前几轮正常，最后一轮把前面提到的东西和敏感对象关联起来；数据来自开源数据集（暴力/涉黄）+ 京东业务方历史数据 + 内部越狱策略（角色扮演、指令注入）扩充。

**失分点**：结构想到了（单轮/多轮/越狱），但**讲散**；对"隐晦表述"这一层答虚了。

**更优回答**（四层构造法，一口气列完）：
1. **单轮纯图**（开源敏感图 + 业务方历史图）；
2. **单轮图文**（"这张图讲了什么"这类诱导）；
3. **多轮关联**（前 N 轮 benign、最后一轮把前文实体与敏感对象绑定）——这是你最有价值的一层，要强调**必须覆盖"跨轮指代"**；
4. **越狱模板 × 敏感主体**：角色扮演、指令注入、编码/拆字。

## 四、算法题（WorkBuddy 按你简历出的，完整复盘）

> 面试官原话：「给定一个清晰度等级，找出一段连续（子数组），（模糊）占比 ≤ P%，最长」

### 题目还原
> 给定长度 n 的序列 `score[i] ∈ {1..5}`，其中 `1、2` 视为**模糊块**。给定百分比 `P`，求**最长连续子数组**，使其模糊块数量占比 **≤ P%**。

### 我的表现
**毫无头绪 → 面试官给了 3 轮提示后才推出来**，属于失分项（项目题答得不错，但 coding 这轮是明显短板）。

### 第 1 轮提示：不等式变换（"比值" → "区间和"）
设子数组长度 `len`、模糊块数 `bad`：

\[
\frac{bad}{len} \le \frac{P}{100}
\;\Longleftrightarrow\;
100\cdot bad \le P\cdot len
\;\Longleftrightarrow\;
100\cdot bad - P\cdot len \le 0
\]

用 `len = bad + good` 展开，即可写成**逐元素求和**：

\[
100\cdot bad - P\cdot(bad+good) = (100-P)\cdot bad + (-P)\cdot good
\]

**给每个块重新赋权**：

| 块类型 | 权重 |
|---|---|
| 模糊（分值 1、2） | `+(100 - P)` |
| 清晰（分值 3、4、5） | `−P` |

> **结论：「模糊占比 ≤ P%」 ⟺ 「该子数组加权和 ≤ 0」。**
> 通用套路：**均值/占比类约束 → 每个元素减去阈值 → 区间和符号约束**。这里等价于模糊记 1、清晰记 0，每位减 `P/100`，再乘 100 消掉浮点。

### 第 2 轮提示：前缀和
`S[0]=0, S[i]=Σw[0..i-1]`，要求：

\[
S[j]-S[i]\le 0 \;\Longleftrightarrow\; S[j]\le S[i],\quad \text{最大化 } j-i
\]

即：**在前缀和数组上找最远的满足"左 ≥ 右"的点对**。

### 第 3 轮提示：候选剪枝 + 单调 + 二分
面试官原话：「如果 l1 在 l2 左边，并且 S[l1] ≥ S[l2]，那 l2 永远不可能成为更好的起点」。

- 因为若 `l2` 可行（`S[j] ≤ S[l2]`），则 `S[j] ≤ S[l1]` 也成立，而 `l1` 更靠左、更长 → `l2` 被**支配**；
- 所以左端点只需保留**严格前缀最大值**，它们的 `S` 值**严格递增**（单调）；
- 对每个右端点 `j`，在候选序列上**二分**找第一个 `S[i] ≥ S[j]` 的 `i` → **O(n log n)**；改用「从右往左扫 + 单调栈弹出」→ **O(n)**。

（注：这题是 `S[j] ≤ S[i]`，保留的是**前缀最大值**；若题目是"子数组和 ≥ 0"，则对称地保留**前缀最小值**，别记反。）

### 参考实现（O(n log n)）

```python
import bisect

def longest_valid(scores, P):
    """scores: 1~5 清晰度，1/2 为模糊；P: 允许的最大模糊占比(百分数)
       返回 (最长长度, (左闭, 右开) 下标)"""
    n = len(scores)
    w = [(100 - P) if s <= 2 else -P for s in scores]   # 减阈值，整数避免浮点误差

    S = [0] * (n + 1)
    for i, x in enumerate(w):
        S[i + 1] = S[i] + x

    # 候选左端点：严格前缀最大值，S 值严格递增
    ci, cv = [], []
    for i, v in enumerate(S):
        if not cv or v > cv[-1]:
            ci.append(i)
            cv.append(v)

    ans, best = 0, None
    for j in range(1, n + 1):
        p = bisect.bisect_left(ci, j)                # 只保留下标 < j 的候选
        k = bisect.bisect_left(cv, S[j], 0, p)       # 第一个 S[i] >= S[j]
        if k < p and j - ci[k] > ans:
            ans, best = j - ci[k], (ci[k], j)
    return ans, best
```

### 必须准备好的追问（同一题的变形）
1. **边界**：`P=0`（只能全清晰段 → 清晰权重 0，退化为"最长连续清晰段"）、`P=100`（答案为 n）、空数组、全是模糊块（`100-P>0`，答案为 0 或 1，取决于是否允许单块）；
2. **严格 vs 非严格**：占比 `< P%` 与 `≤ P%` 只差一个等号，前缀和比较处改 `<` / `≤` 即可，**先跟面试官确认**；
3. **阈值泛化**：如果"模糊"定义改成 `≤ k` 分（k 可变），或要求"**且长度 ≥ L**"（加长度约束后单调栈失效，改二分答案 + 前缀和滑动窗口 O(n log n)）；
4. **变体**：求"最多清晰块数"而非最长长度、求**所有**满足条件的最长区间、序列变成环形；
5. **追问复杂度**：O(n²) 基线 → O(n log n) → O(n)，并说明 O(n) 的栈为什么能弹出（每个候选一旦满足就与**最大的可行 j** 配对，之后 j 只变小，不会更长）。

### 一句话答题模板（背下来）
> 先把占比约束做**减阈值变换**转成区间和 ≤ 0（模糊 `100−P`、清晰 `−P`），再用前缀和转成"找最远的 `S[j] ≤ S[i]` 点对"；左端点只需保留前缀最大值（单调），二分即可 O(n log n)，栈扫可做到 O(n)。
