分配的地址是连续的

kmalloc和vmalloc都是Linux内核中用于动态分配内存的函数。 kmalloc: kmalloc用于分配少量的连续的内核内存。它分配的内存是物理页面，因此分配的大小必须是一个页面整数倍，例如4KB或8KB。kmalloc的优点是速度快，分配的内存可以直接用于硬件设备，而不需要进行额外的映射。缺点是有一定的内存浪费，因为分配的大小必须是一个页面整数倍。 vmalloc: vmalloc用于分配大块的内核虚拟内存，大小可以超过一个页面。虚拟内存是在页表中映射物理页面的一种方法，因此vmalloc分配的内存并不一定是连续的物理页面，而是在虚拟地址空间中映射的内存块。vmalloc的优点是可以分配大块的内存，而不需要满足页面大小的限制，因此适用于需要大量内存的场景。缺点是速度较慢，而且分配的内存必须经过调整，以确保分配的内存是固定的虚拟地址范围，这可能导致一些内存浪费。 总之，kmalloc用于分配少量的连续的内核内存，它的分配速度快，但是需要满足页面大小的限制。vmalloc用于分配大块的内核虚拟内存，它的分配速度较慢，但是可以分配超过一个页面的内存。两种方法都是用于内核动态分配内存的常规方法，具体的选择取决于应用程序需要分配的内存大小和性能要求。

/* High-level overview: This works by maintaining a singly-linked list of previously-used memory segments that have been freed. */
#define NALLOC 1024
#include <errno.h>
#include <limits.h>
#include <string.h>
#include <unistd.h>
/* This header is stored at the beginning of memory segments in the list. */
union header {
  struct {
    union header *next;
    unsigned len;
  } meta;
  long x; /* Presence forces alignment of headers in memory. */
};
static union header list;
static union header *first = NULL;
void free(void* ptr) {
  if (ptr == NULL) {
    return;
  }
  union header *iter, *block;
  iter = first;
  block = (union header*)ptr - 1;
  /* Traverse to the spot in the list to insert the freed fragment,
   * such that the list is ordered by memory address (for coalescing). */
  while (block <= iter || block >= iter->meta.next) {
    if ((block > iter || block < iter->meta.next) &&
        iter >= iter->meta.next) {
      break;
    }
    iter = iter->meta.next;
  }
  /* If the new fragment is adjacent in memory to any others, merge
   * them (we only have to check the adjacent elements because the
   * order semantics are enforced). */
  if (block + block->meta.len == iter->meta.next) {
    block->meta.len += iter->meta.next->meta.len;
    block->meta.next = iter->meta.next->meta.next;
  } else {
    block->meta.next = iter->meta.next;
  }
  if (iter + iter->meta.len == block) {
    iter->meta.len += block->meta.len;
    iter->meta.next = block->meta.next;
  } else {
    iter->meta.next = block;
  }
  first = iter;
}
void *ff_malloc(size_t size) {
  union header *p, *prev;
  prev = first;
  unsigned true_size =
    (size + sizeof(union header) - 1) /
     sizeof(union header) + 1;
  /* If the list of previously allocated fragments is empty,
   * initialize it. */
  if (first == NULL) {
    prev = &list;
    first = prev;
    list.meta.next = first;
    list.meta.len = 0;
  }
  p = prev->meta.next;
  /* Traverse the list of previously allocated fragments, searching
   * for one sufficiently large to allocate. */
  while (1) {
    if (p->meta.len >= true_size) {
      if (p->meta.len == true_size) {
        /* If the fragment is exactly the right size, we do not have
         * to split it. */
        prev->meta.next = p->meta.next;
      } else {
        /* Otherwise, split the fragment, returning the first half and
         * storing the back half as another element in the list. */
        p->meta.len -= true_size;
        p += p->meta.len;
        p->meta.len = true_size;
      }
      first = prev;
      return (void *)(p+1);
    }
    /* If we reach the beginning of the list, no satisfactory fragment
     * was found, so we have to request a new one. */
    if (p == first) {
      char *page;
      union header *block;
      unsigned alloc_size=true_size;
      /* We have to request memory of at least a certain size. */
      if (alloc_size < NALLOC) {
        alloc_size = NALLOC;
      }
      page = sbrk((intptr_t) (alloc_size * sizeof(union header)));
      if (page == (char *)-1) {
        /* There was no memory left to allocate. */
        errno = ENOMEM;
        return NULL;
      }
      /* Create a fragment from this new memory and add it to the list
       * so the above logic can handle breaking it if necessary. */
      block = (union header *)page;
      block->meta.len = alloc_size;
      free((void *)(block + 1));
      p = first;
    }
    prev = p;
    p = p->meta.next;
  }
  return NULL;
}
void* calloc(size_t num, size_t len) {
  void* ptr = ff_malloc(num * len);
  /* Set the allocated array to 0's.*/
  if (ptr != NULL) {
    memset(ptr, 0, num * len);
  }
  return ptr;
}

代码解读：

该代码实现了一个简单的动态内存分配器，使用了首次适配算法。(准确说是下次适配算法，每次选择内存块时，从上一次分配的地方开始查找）

具体实现如下：

1. 定义了一个头部结构体 `union header`，包括指向下一个块的指针和块的长度。
2. 定义了一个静态的链表 `list`，它是一个 `union header` 类型的变量，并且指向它的指针 `first` 初始值为 `NULL`。
3. 实现了 `free` 函数，用于释放内存，它会找到空闲链表中合适的位置插入释放的内存块，并且如果有必要的话，将相邻的内存块合并。
4. 实现了 `ff_malloc` 函数，用于分配内存，它会首先在空闲链表中查找是否有合适的内存块，如果没有，就通过系统调用 `sbrk` 分配一块新的内存，并且将它加入到空闲链表中。

`sbrk`

1. 实现了 `calloc` 函数，用于分配一片内存，并且将它初始化为 0。

该代码实现了一个简单的动态内存分配器。

细节:

链表中存储的len代表了header的长度，分配的内存块大小都是以header数计算的，分配空间时也要记得加上sizeof(union header)，free内存空间记得从header指针+1的位置开始free。

代码free时，寻找要free的块产生的空闲块放到链表的位置时，考虑了链表中逻辑地址要连续，尝试新开辟的块放在链表中相邻的两个块中，如果新的块的地址大于链表最后一个节点的地址，则把它放到链表最后面。同时还要看新的块前后是否有空块，将其合并。

没有可用空间时，调用sbrk分配新的内存。

代码用first指针表示上一次分配的块的位置，尽量让相邻分配的块的逻辑地址相邻。

新开辟的块是从低位到高位增长的，分配块的时候是先放到空闲块的高位。
