一、 LLM 八股

1.在 LLM 的推理阶段，有哪些常见的解码策略？请解释 Greedy Search , Beam Search , Top - K Sampling 和 Nucleus Sampling ( Top - P ）的原理和优缺点。  
**解答**：
- **Greedy Search**：每一步选概率最高的词。优点：快；缺点：容易产生重复、单调的输出，质量较差。
- **Beam Search**：维护 K 条候选序列并行搜索。优点：结果更稳定、质量高；缺点：不够多样，容易生成"非人话"的过度优化短语。
- **Top-K Sampling**：只从概率最高的 K 个词中随机采样。优点：多样性好；缺点：K 固定，概率分布宽时会采到奇怪的词。
- **Top-P (Nucleus) Sampling**：动态截断——只保留概率累计到 P 为止的词集合进行采样。优点：自适应分布宽窄，是目前生成任务的主流方案。

2.什么是位置编码？列举两种实现方式。
**解答**：Transformer 的自注意力机制本身对词序是无感知的（全局并行计算），因此需要手动注入位置信息。两种主流方式：
- **Sinusoidal 绝对位置编码**（原始 Transformer）：用正余弦函数直接生成固定位置向量叠加到词向量上。
- **RoPE 旋转位置编码**（现代 LLM 主流）：通过旋转矩阵把绝对位置隐式编码进去，同时具备相对位置感知能力，外推性更好。

3.请你详细介绍 ROPE ，对比绝对位置编码它的优劣势分别是什么？
**解答**：RoPE 的思路是：对词向量在高维空间中进行旋转，旋转角度与绝对位置相关，这样两个词向量做点积时，结果自然包含了它们相对位置的信息。
- **优势**：天然支持相对位置感知；无需存储额外位置参数；外推性更好（通过 NTK-Aware 等scaling方法可支持更长上下文）。
- **劣势**：相比简单Sinusoidal在超长序列时仍有性能衰减，需要额外的长度外推手段。

4.MHA , MQA , GQA 的区别。
**解答**：
- **MHA（Multi-Head Attention）**：每个注意力头都有独立的 Q、K、V 矩阵。参数量最大，效果最好，但推理时 KV Cache 占显存大。
- **MQA（Multi-Query Attention）**：所有头共享同一组 K、V，只有 Q 是多头的。KV Cache 极小，推理快，但性能略有下降。
- **GQA（Grouped Query Attention）**：介于 MHA 和 MQA 之间，将 Q 头分组，每组共享一对 K、V。兼顾性能与效率，是 LLaMA2/Qwen2 等现代模型的主流方案。

5.请比较一下几种常见的 LLM 架构，例如 Encoder - Only , Decoder - Only ,和 Encoder - Decoder ，并说明它们各自最擅长的任务类型。
**解答**：
- **Encoder-Only（如 BERT）**：双向注意力，能看到完整上下文。擅长 NLU 任务（文本分类、NER、情感分析等）。
- **Decoder-Only（如 GPT、LLaMA）**：单向因果注意力，自回归生成。擅长 NLG 任务（对话、续写、代码生成等），也是当前大模型主流。
- **Encoder-Decoder（如 T5、BART）**：Encoder 读取输入，Decoder 生成输出。擅长 Seq2Seq 任务（翻译、摘要、问答等输入输出结构清晰的任务）。

6.什么是 Scaling Laws ？它揭示了模型性能、计算量和数据量之间的什么关系？这对 LLM 的研发有什么指导意义？
**解答**：Scaling Laws 指：模型 Loss 与**模型参数量（N）、训练数据量（D）、计算量（C）** 之间存在稳定的幂律关系——三者按比例增加，Loss 将持续平滑下降。关键结论（Chinchilla Laws）是：最优的训练应该让 N 和 D 同比例增长，而不是只堆参数。**指导意义**：在研发前就能预测不同规模组合的最终性能，从而科学地分配算力预算，避免盲目堆参数。

7.请详细解释一下 Transformer 模型中的自注意力机制是如何工作的？
**解答**：自注意力的计算流程：
1. 对输入序列的每个词向量，通过三个投影矩阵分别得到 Q（Query）、K（Key）、V（Value）。
2. 计算注意力分数：Q 与所有位置的 K 做点积，再除以 √d_k 进行缩放（防止内积过大导致 Softmax 梯度消失）。
3. 对分数做 Softmax 得到注意力权重。
4. 用权重对所有位置的 V 进行加权求和，得到当前位置的输出表示。
这样每个词都能"看到"序列中其他所有词，捕捉长距离依赖。

8.什么是词元化？请比较一下 BPE 和 WordPiece 这两种主流的子词切分算法。
**解答**：词元化（Tokenization）将原始文本拆分为模型能处理的 token 序列。
- **BPE（Byte Pair Encoding，GPT系列使用）**：从字符级别出发，迭代合并频率最高的相邻字节对，直到达到词汇表大小。
- **WordPiece（BERT 使用）**：与 BPE 思路相似，但合并准则是最大化语言模型的训练数据似然，而非简单的频率。
两者都能有效处理未登录词（OOV），WordPiece 得到的分词更"语言学友好"。

9.你觉得 NLP 和 LLM 最大的区别是什么？
**解答**：传统 NLP 是"专才"——为每个具体任务（分类、NER、翻译）单独训练专用小模型；LLM 是"通才"——通过大规模预训练，统一为"下一词预测"的范式，能以零样本或少样本方式解决几乎所有语言任务，这是范式层面的根本转变。

10.开源框架了解过哪些？ 
**解答**：
- **DeepSpeed**：微软出品，主攻训练侧显存优化，ZeRO 系列可将显存需求降低数倍。
- **Megatron-LM**：英伟达出品，专注张量并行/流水线并行，是大规模分布式训练的标准之一。
- **vLLM**：UC Berkeley 出品，推理侧加速利器，PagedAttention 机制使推理吞吐量大幅提升。

11.激活函数有了解吗，你知道哪些 LLM 常用的激活函数？为什么选用它？
**解答**：现代 LLM 最常用的是 **SwiGLU**（SwishGated Linear Unit）。它是门控线性单元的变体，具体是用 Swish 函数作为门控。选用它的原因：与 ReLU、GeLU 相比，SwiGLU 在多数大模型任务上展现出更优的性能和泛化能力，已被 LLaMA、Qwen 等主流模型采用。

12.混合专家模型（ MoE ）是如何在不显著增加推理成本的情况下，有效扩大模型参数规模的？请简述其工作原理。
**解答**：MoE 的核心是一个 **Router（门控网络）**：对于每个输入 Token，Router 计算其与各"专家"（FFN 子网络）的相似度，只激活 Top-K 个专家参与计算（如从64个专家中激活2个）。这样总参数量虽然很大，但单次推理实际计算量与 Dense 模型相当，实现了"参数多、计算量不增加"的效果。

13.在训练一个百或千亿参数级别的 LLM 时，你会面临哪些主要的工程和算法挑战？
**解答**：
- **显存瓶颈**：单卡放不下模型，要靠 ZeRO/张量并行/流水线并行等多种并行策略。
- **训练稳定性**：超大参数规模下 Loss Spike（损失突刺）频发，需要仔细调学习率曲线和梯度裁剪。
- **通信瓶颈**：多机多卡训练时，allreduce 等通信操作成为巨大瓶颈，需要高速互联（InfiniBand）和通信优化。
- **数据质量**：千亿规模需要 Trillion 量级 Token，数据清洗、去重、配比是重大工程挑战。

14.最近读过哪些 LLM 比较前沿的论文。
**解答**：读过 DeepSeek-R1（GRPO + Zero-Shot RL 引发长思考链）、DeepSeekMoE（细粒度专家共享）、Qwen2.5 系列技术报告等。目前重点关注 RL for Reasoning 和 MoE 架构这两个方向。

  

  

  

二、Agent八股 

1.你如何定义一个基于 LLM 的智能体（ Agent )？它通常由哪些核心组件构成？
**解答**：Agent 是以 LLM 为大脑，能够自主感知环境、规划决策、调用工具并最终完成复杂目标的系统。核心组件：
- **规划（Planning）**：分解目标、制定步骤（如 CoT、ToT、ReAct）。
- **记忆（Memory）**：短期记忆（Context Window）+ 长期记忆（外部向量数据库）。
- **工具使用（Tool Use）**：调用搜索、代码执行、API等外部工具。
- **行动（Action）**：将决策落实为具体操作并观察环境反馈。

2.有微调过 Agent 能力吗？数据集如何收集？
**解答**：略。

3.请谈谈目前有哪些主流方法可以赋予 LLM 规划能力？
**解答**：
- **CoT（Chain of Thought）**：在提示中加入"思考步骤"示例，让模型逐步推理。
- **ToT（Tree of Thought）**：探索多条思维路径并评估回溯，类似树形搜索。
- **ReAct**：将 Thought（思考）和 Action（行动）交替进行，形成感知-推理-执行的闭环。

4.请问如何为 Agent设计短期记忆和长期记忆系统？
**解答**：
- **短期记忆**：即 Context Window，将最近的对话轮次直接塞入 Prompt。简单但受上下文长度限制。
- **长期记忆**：将历史记录向量化后存入向量数据库（如 FAISS、ChromaDB），每次对话时检索相关片段注入 Context，突破长度限制。

5.请解释 LLM 是如何学会调用外部 API 或工具的？
**解答**：核心做法是 **SFT 微调**：构造大量"什么时候决定调用工具、如何构造结构化 JSON 参数、如何解析工具返回值"的训练样本，对模型进行监督微调，使模型学会在合适时机以规范的格式输出函数调用指令，由系统捕获后真正执行并将结果塞回对话中。

6. LangChain 和 LlamaIndex的核心应用场景有何不同？
**解答**：
- **LangChain**：是通用 Agent 编排框架，提供了 Chain、Agent、Memory 等各种组件，像一把瑞士军刀，适合构建复杂的多步骤认知流程。
- **LlamaIndex**（GPT Index）：专注于 RAG 场景，主攻"如何高效地将私有知识库与 LLM 连接起来"，在数据索引、检索优化上更深入。

7.在构建一个复杂的 Agent 时，你认为最主要的挑战是什么？
**解答**：最大的挑战是**可靠性与稳定性**——LLM 的幻觉可能导致工具调用参数错误，错误在多步任务中层层传播放大，最终陷入死循环或崩溃。让 Agent 在遇到错误时能够正确识别、回溯并重试，是工程上的巨大难题。

8.什么是多智能体系统？让多个 LLM Agent 协同工作相比于单个 Agent 有什么优势？又会引入哪些新的复杂性？
**解答**：多智能体系统是让多个 Agent 相互协作（如 AutoGen 框架）共同完成任务。**优势**：能进行角色分工（一个负责写代码、一个负责测试、一个负责审查）、多智能体辩论可以减少单点幻觉。**复杂性**：Agent 间的通信协调开销大；容易出现"决策爆炸"——多个 Agent 相互等待或产生矛盾指令；整体系统的可调试性极差。

9.你用过哪些 Agent 框架？你最终场景的评价指标是什么？
**解答**：用过 LangGraph 等。最终场景的核心评估指标是**任务完成率（Task Success Rate）** 和**平均完成步数**。

10.如何确保一个 Agent 的行为是安全、可控且符合人类意图的？在 Agent 的设计中，有哪些保障对齐方法？
**解答**：
- **系统预设安全指令**：在 System Prompt 中给出严格的行为边界和禁止清单。
- **沙箱隔离执行**：让 Agent 执行的代码/命令在沙箱（Sandbox）中跑，防止对宿主系统产生破坏。
- **人工审核节点**：在关键决策点（如删除文件、对外发邮件）前加入 Human-in-the-loop 确认。

11.了解A2A框架吗？它和普通 Agent 框架的区别在哪，挑一个最关键的不同点说明。
**解答**：A2A（Agent-to-Agent）是 Google 提出的 Agent 间互操作协议。与普通 Agent 框架的最关键区别在于：A2A 关注的是**跨系统、异构 Agent 之间的标准化通信协议**，使不同厂商开发的 Agent 能够相互发现、调用和协作；而普通 Agent 框架（如 LangChain）更多关注单个 Agent 内部的编排逻辑。

12.请详细解释 ReAct 框架。它是如何将思维链和行动结合起来，以完成复杂任务的？
**解答**：ReAct 让 LLM 交替生成 **Thought（思考）→ Action（行动）→ Observation（观察）** 三种输出，形成闭环：
1. **Thought**：模型用自然语言思考下一步该做什么。
2. **Action**：调用一个具体的工具（如搜索"北京天气"）。
3. **Observation**：系统将工具返回的结果（如"晴，25°C"）注入 Context。
4. 循环回到 Thought，继续分析 Observation，直到得出最终答案。
这种方式让推理过程透明、可追溯，并能利用外部实时信息，大幅减少幻觉。

  

  

三、VLM 八股

1.多模态大模型（如 VLM ）的核心挑战是什么？即如何实现不同模态信息（如视觉和语言）的有效对齐和融合？
**解答**：核心挑战在于**模态鸿沟**：视觉特征是连续、稠密的像素级信号，而语言是离散、高维的语义符号，两者的特征空间天然不一致。如何学习一个统一的对齐表示空间，让"一只猫"的图片向量和"猫"这个词向量彼此靠近，是对齐的本质难题。

2.有没有做过 VLM 相关方面的微调？什么模型？
**解答**：略。

3.像 LLaVA 或 MiniGPT -4这样的模型是如何将一个预训练好的视觉编码器（ Vision Encoder ）和一个大语言模型（ LLM ）连接起来的？请描述其关键的架构设计。
**解答**：核心做法是**冻结预训练的两端**（Vision Encoder 如 CLIP-ViT 和 LLM），只训练中间的**桥接模块**：
- **LLaVA**：采用简单的 MLP 作为连接器，将视觉特征直接投影到语言模型的特征空间，实现超轻量、高效的对齐训练。
- **MiniGPT-4、BLIP-2**：采用 Q-Former 作为连接器，用一组可学习的 Query Token 从视觉特征中提炼压缩信息，再喂给 LLM。

4.什么是视觉指令微调？
**解答**：构建包含 `<image>` 占位符的指令-回复数据对（如"描述这张图片里的内容"），以 SFT 方式对 VLM 进行微调，让模型学会理解并遵循视觉相关的人类指令，而不只是做图片描述。LLaVA 的成功很大程度上归功于这一步。

5.在处理视频等多模态数据时，相比于静态图片， VLM 需要额外解决哪些问题？（例如，如何表征时序信息？)
**解答**：
- **Token 数量爆炸**：视频是图片序列，如果每帧都展开为视觉 Token，Token 数会暴增，超出 LLM 上下文限制。需要帧采样或时序特征压缩。
- **时序建模**：需要提取帧间的连续时序依赖特征，静态图像模型无法捕捉运动、动作等时间维度信息。

6.请解释 Grounding 在 VLM 领域中的含义。我们如何评估一个 VLM 是否能将文本描述准确地对应到图片中的特定区域？
**解答**：Grounding 是指模型能将文本中的实体/描述精确地对应（"落地"）到图像的具体像素区域。评估方式：给模型一段描述和一张图片，要求其输出一个 Bounding Box（边界框），然后用预测框与 Ground Truth 框的 **IoU（交并比）** 来衡量定位精度。常用基准如 RefCOCO。

7.请对比至少不同的 VLM 架构范式，并分析它们的优劣。
**解答**：
- **MLP 连接器（如 LLaVA）**：简单直接，训练快，效果出色；但视觉 Token 数多，占用上下文长度。
- **Q-Former 连接器（如 BLIP-2）**：能大幅压缩视觉 Token 数，减少 LLM 负担；但 Q-Former 本身训练复杂，且信息压缩过度时会损失细节。

8.在 VLM 的应用中，如何处理高分辨率的输入图像？
**解答**：主流方案是 **AnyRes / Dynamic High Resolution**：将高分辨率图片切分成多个固定大小的图块（tile），分别编码后拼接输入给 LLM，同时保留一张降分辨率的全局缩略图维持整体感知。LLaVA-1.5、InternVL 等均采用此策略。

9.VLM 在生成内容时，同样会遇到"幻觉"( Hallucination ）问题，但它的表现形式和纯文本 LLM 有何不同？请举例说明。
**解答**：VLM 的幻觉不仅是"编造事实"，还包括**编造图像中不存在的物体或属性**（视觉幻觉）。例如：图中只有一只狗，但模型说"图中有一只狗和一只猫"；或图中物体是蓝色，描述成了红色。这比纯文本幻觉更隐蔽，因为用户很难从语言层面察觉视觉信息是否被篡改。

10.除了图片描述和视觉问答（ VQA )，还能列举出 VLM 的哪些前沿应用方向？
**解答**：
- **GUI/屏幕操作 Agent**：让 Agent "看"屏幕截图，自主操作 APP（如 GPT-4o 操作手机）。
- **自动驾驶感知**：端到端感知决策，理解路况语义。
- **医疗影像理解**：分析 CT、X 光片并生成报告。

11.请解释 CLIP 模型的工作原理。
**解答**：CLIP（Contrastive Language-Image Pre-training）由 OpenAI 提出，核心思路是**对比学习**：用亿级规模的图文对，训练一个图像编码器和一个文本编码器，使匹配的图文对在特征空间中靠近，不匹配的图文对远离（InfoNCE Loss）。这样两个编码器共享了一个统一的语义空间，能实现强大的零样本图文匹配和检索能力。

  

  

  

四、RLHF 八股

1.和传统 SFT 相比， RLHF 旨在解决语言模型中的哪些核心问题？
**解答**：SFT 只能让模型学会模仿训练数据的表面格式，却无法真正理解"什么是好的回答"的深层价值判断，比如安全性、无害性与实用性的权衡。RLHF 通过引入人类偏好信号，让模型直接对齐人类意图，解决 SFT 无法解决的价值对齐问题。

2.请详细阐述经典 RLHF 流程的三个核心阶段。在每个阶段，输入是什么，输出是什么，以及该阶段的关键目标是什么？
**解答**：
1. **SFT（监督微调）**：输入指令-回复数据集，输出会基本对话的基础模型，目标是建立对话格式能力。
2. **RM 训练（奖励模型）**：输入人类对多个模型回复的成对偏好标注，输出一个能打分的奖励模型，目标是将人类主观偏好量化为标量信号。
3. **PPO 强化学习**：利用 RM 对 SFT 模型生成的回复打分，通过 PPO 算法迭代更新策略模型，目标是最大化人类偏好得分，同时用 KL 散度约束防止模型跑偏。

3.在 RM 训练阶段，我们通常收集的是成对比较数据，而不是让人类标注者直接给回复打一个绝对分数。你认为这样做的主要优势和潜在的劣势分别是什么？
**解答**：**优势**：人类非常擅长比较（A比B好），但给出一个绝对分数（A给8分）非常困难，因为每个人的绝对尺度不同。成对比较能消除标注员间绝对偏好的不一致性，标注更简单、更可靠。**劣势**：损失了一部分信息——只知道 A > B，但不知道 A 到底比 B 好多少；并且需要大量成对数据，标注成本高。

4.奖励模型的模型架构通常如何选择？它与我们最终要优化的 LLM 是什么关系？在训练奖励模型时，常用的损失函数是什么？
**解答**：架构通常采用与 SFT 模型同等规模的 LLM，将最后的 LM Head 替换为输出标量分数的 Scalar Head。RM 是裁判，SFT 模型是被裁判的运动员。常用损失函数是 **Pairwise Ranking Loss（Bradley-Terry 模型）**，本质是对数偏好概率的交叉熵。

5.在 RLHF 的第三阶段， PPO 是最主流的强化学习算法。为什么选择 PPO ，而不是其他更简单的策略梯度算法（如 REINFORCE ）或者 Q - learning 系算法？ PPO 中的 KL 散度惩罚项起到了什么关键作用？
**解答**：选 PPO 是因为它**稳定**——通过 Clip 机制限制单步更新幅度，避免策略剧烈震荡。REINFORCE 方差太大，Q-learning 不适合序列生成这种连续动作空间。**KL 散度惩罚项**的作用：约束 RL 训练后的策略模型不要离 SFT 初始模型太远，防止模型为了骗取 RM 高分而产生"奖励黑客"（输出人类看不懂的乱码但 RM 打高分）。

6.如果在 PPO 训练过程中， KL 散度惩罚项的系数 B 设置得过大或过小，分别会导致什么样的问题？你将如何通过实验和观察来调整这个超参数？
**解答**：**B 过大**：模型被死死钉在 SFT 初始点，强化学习完全无法更新，训练形同虚设。**B 过小**：模型脱缰，为了最大化 RM 分数而走捷径（Reward Hacking），产生重复词汇或乱码。调整方法：观察 KL 散度的曲线趋势和 RM 平均分变化——若 KL 散度始终接近 0 则 B 过大，若 RM 分迅速飙升但 KL 暴增则 B 过小，需在两者之间找到稳定区间。

7.什么是"奖励作弊／奖励黑客"( Reward Hacking )?请结合一个具体的 LLM 应用场景给出一个例子，并探讨几种可能的缓解策略。
**解答**：RM 本身是对人类偏好的近似，它是有漏洞的。Reward Hacking 是指模型学会了利用 RM 的漏洞，生成 RM 打分高但人类觉得没用的回答。**例子**：RM 在标注时倾向于给更长的回复打高分，于是模型学会废话连篇。**缓解策略**：引入长度惩罚；定期更新 RM；在 RM 之外加入多种自动化评估信号（多 RM 集成）。

8.RLHF 流程复杂且不稳定。近年来出现了一些替代方案，例如 DPO 。请解释 DPO 的核心思想，并比较它与传统 RLHF （基于 PPO ）的主要区别和优势。
**解答**：**DPO（Direct Preference Optimization）** 的核心洞察是：RL 最优策略可以用一个封闭形式直接表达，因此**不需要单独训练 RM**，将人类偏好概率直接用 Policy Model 自身的 log 概率比来参数化，通过一个二元交叉熵 Loss 端到端优化。**优势**：彻底省去了大 RM 的训练和复杂的 PPO 在线采样流程，稳定、简单、省显存，工程落地门槛极低。**劣势**：离线优化，无法像 PPO 一样实时探索新策略。

9.想象一下，你训练完成的 RLHF 模型在离线评估中表现优异，奖励模型分数很高，但上线后用户反馈其回答变得越来越"模式化"、奉承、且缺乏信息量。你认为可能的原因是什么？你会从哪些方面着手分析和解决这个问题？
**解答**：根本原因是 **RM 过拟合了有偏见的标注数据**——标注员可能系统性地偏好语气好、态度积极的长答案，导致 RM 偏向这种风格，PPO 进一步强化了这种倾向。解决思路：审查 RM 训练数据的分布；引入 bad case 分析；考虑在 RM 外加入客观性指标（如答案准确性、信息密度）作为辅助信号。

10.你知道 Deepseek 的 GRPO 吗，它和 PPO 的主要区别是什么？
**解答**：GRPO（Group Relative Policy Optimization）的最大改变是**抛弃了 PPO 庞大的 Critic（价值）网络**，极大节省了显存。它的做法是：对同一个 Prompt 采样一批（如 64 个）回复，以这组回复之间的相对得分（Group-normalized reward）代替价值网络估计的 baseline，稳定性好、实现更简单。

11.GSPO和 DAPO 有听说过吗？他们和 GRPO 有什么区别？
**解答**：GSPO 和 DAPO 都是 GRPO 的改进变体，主要针对 GRPO 在数学推理等长链条任务中的信用分配问题：GRPO 是对整个序列给一个奖励，而 GSPO/DAPO 将奖励细化到步骤（Step-Wise），使模型能学习到"哪一步的推理出错了"，训练信号更精准。

12.如何解决信用分配问题？ token 级别和 seq 级别的奖励有何不同？
**解答**：信用分配问题是指：整个序列只有一个终态奖励时，模型不知道是哪个 Token 的生成导致了好/坏的结果。**Token 级奖励**：能精确归因到具体 Token，训练信号更稠密，收敛更快，但构造困难（需要过程监督数据，如 PRM）。**Seq 级奖励**：构造简单（有最终正确答案就行），但梯度信号稀疏，容易出现信用分配不准的问题。

13.除了人类反馈，我们还可以利用 AI 自身的反馈来做对齐，即 RLAIF 。请谈谈你对 RLAIF 的理解，它的潜力和风险分别是什么？
**解答**：RLAIF 用一个强大的 AI（如 Claude、GPT-4）替代人类作为裁判，给候选回复打分或生成偏好数据。**潜力**：成本极低、速度极快，可以规模化生成高质量对齐数据。**风险**：裁判 AI 的偏见和盲区会被完整地遗传给被训练的模型，同时裁判 AI 打高分的"易于被 AI 认可"风格不一定等于"真正被人类喜欢"的风格，存在 AI 偏见强化的隐患。
