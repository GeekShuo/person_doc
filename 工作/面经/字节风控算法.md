# 字节跳动风控算法一面

## 一、面试问题

### A. 项目经历与业务理解

#### 1. 实习

1. 先介绍一下你的这段实习经历。

**解答**：按“业务背景—目标—个人职责—技术方案—量化结果—复盘”组织。重点说明自己实际负责的数据、模型或工程模块，并区分个人贡献与团队成果。指标必须来自真实实验；不便披露时，可描述相对提升和评测方法。

2. 听起来你的工作主要集中在数据/样本构建上，是吗？

**解答**：根据真实经历回答。可以先确认数据工作的范围，再说明它与模型工作的关系，例如：“数据构建是我的主要职责，包括样本生成、过滤、难例挖掘和质量评估；同时我也参与了模型微调、消融实验和下游评测。数据工作并非简单清洗，而是围绕模型错误分析形成迭代闭环。”不要把未参与的模型训练说成自己的成果。

3. 你这里写了 VQG 和 VQA 一致性评估，这里的“一致性评估”是什么意思？

**解答**：VQG 根据图像生成问题，VQA 根据图像和问题生成答案。一致性评估用于检查生成的问题是否确实由图像支持，以及问题、答案和图像三者是否语义一致。常见做法是把原始答案与回答答案比较，结合精确匹配、语义相似度、VLM/LLM 评审或人工抽检。它衡量的是闭环一致性，不等同于事实正确性；若 VQG 与 VQA 模型共享相同偏差，也可能出现“错误但一致”，因此需要独立模型或人工校准。

4. 所以你的意思是，让大模型先生成问题，再生成答案，然后看问题和答案是否对得上，是吗？

**解答**：基本流程可以这样概括，但应补充图像证据：先由 VQG 基于图像和目标答案生成问题，再由独立 VQA 模型根据“图像+问题”回答，最后比较回答与目标答案，并检查问题是否自然、唯一且可由图像回答。为了减少自洽偏差，生成器和评估器最好相互独立，并对评分阈值做人工标注校准。

5. 所以最后是不是回答不一致的样本，就说明它比较难？

**解答**：不一定。不一致可能表示样本较难，也可能来自问题歧义、目标答案错误、图像信息不足、OCR 失败或评估模型能力不足。更稳妥的做法是把“不一致”作为候选难例信号，再结合多模型一致性、置信度、图文相关性和人工抽检分类，区分真正难例与脏数据。

6. 这个项目过程中，你有做过哪些模型方面的工作？

**解答**：按真实情况回答，可从模型选型、LoRA/SFT、损失设计、难例采样、超参数搜索、消融实验、离线评测和部署优化展开。每项说明“为什么做、具体怎么做、指标变化怎样”。如果主要负责数据，应坦诚说明模型侧参与边界，并强调如何通过错误分析推动数据和模型共同迭代。

#### 2. LLM-as-a-Judge 项目

7. 研究生阶段你还有一个 LLM-as-a-Judge 的项目，能大概介绍一下吗？

**解答**：建议按“目标—评分维度—评审协议—校准—验证”介绍。说明 Judge 评估的是正确性、相关性、完整性或安全性，采用单答案打分还是成对比较；通过交换回答顺序、隐藏模型身份、多次采样降低位置和风格偏差；再用人工标注计算一致率、Spearman/Kendall 相关系数或分类指标。最后说明该评分如何服务数据筛选或模型迭代。不要把 LLM 评分当成绝对真值。

8. 你最后这个总分好不好，是通过一个下游任务来验证的吗？

**解答**：应通过外部效度验证，而不能只看 Judge 自身分数。可以比较不同分数区间数据训练出的模型在独立下游测试集上的准确率、F1、生成质量或人工偏好，并与随机采样、规则筛选等基线对照。同时检查 Judge 分数与人工评分的相关性，以及不同类别、难度上的偏差。

9. 如果我理解得对，就是你打分之后选 Top 20% 的数据去微调，再和随机选 20% 做对比，是这个意思吗？

**解答**：如果实际实验如此，可以确认，并补充控制变量：两组数据量、类别分布、训练步数和超参数保持一致，测试集与候选池严格隔离，最好用多个随机种子报告均值和方差。还应加入全量数据、规则筛选或分层采样基线，避免 Top 20% 只选到简单、同质样本。

10. 这个事情听起来很像样本选择，甚至有点像强化学习，你有从这个方向考虑过吗？

**解答**：它首先属于数据选择或课程学习：评分器为样本赋予效用，再决定训练分布。若选择策略根据模型训练后的回报持续更新，可以建模为 Contextual Bandit 或双层优化；若只是一次性打分后筛选，则不属于严格意义上的强化学习，因为没有序列决策、环境交互和策略回报闭环。实践中也可用影响函数、梯度相似度或不确定性采样评估样本价值。

### B. 强化学习基础

11. 你对强化学习了解吗？系统地学习过一些强化学习的方法吗？

**解答**：强化学习研究智能体如何与环境交互以最大化期望累计回报。核心元素包括状态、动作、转移、奖励、策略和折扣因子。方法可分为基于价值的 Q-learning/DQN、策略梯度 REINFORCE、Actor-Critic、PPO，以及离线强化学习等。回答时应区分理论学习和真实实践，并说明是否实现过环境、奖励、优势估计和策略更新。

12. on-policy 和 off-policy 分别是什么意思？

**解答**：On-policy 使用当前目标策略或与其非常接近的行为策略采样，并据此更新该策略，如 SARSA、REINFORCE、PPO；数据新鲜但复用率较低。Off-policy 允许行为策略与目标策略不同，可复用历史经验，如 Q-learning、DQN、SAC；样本效率更高，但需要处理分布偏移。该区分针对数据由什么策略产生，不等同于在线与离线训练。

13. importance sampling 是什么？

**解答**：重要性采样用于用分布 \(q(x)\) 的样本估计分布 \(p(x)\) 下的期望：

\[
\mathbb E_{x\sim p}[f(x)]=\mathbb E_{x\sim q}\left[\frac{p(x)}{q(x)}f(x)\right],
\]

前提是当 \(p(x)>0\) 时有 \(q(x)>0\)。强化学习中常用概率比 \(\pi(a\mid s)/\mu(a\mid s)\) 修正行为策略与目标策略的差异。权重可能造成高方差，因此常采用裁剪、归一化或截断；PPO 的概率比裁剪就是稳定更新的一种方式。

14. DPO 和 PPO 是什么关系？它们有什么区别？

**解答**：PPO 是通用的 on-policy 策略优化算法。经典 RLHF 中先训练奖励模型，再在线采样回答，用 PPO 最大化奖励，并加入相对参考模型的 KL 约束；通常还需价值模型，成本较高。DPO 从 KL 正则化奖励最大化推导出偏好分类目标，直接使用“偏好/非偏好”回答对优化策略与参考模型的相对对数概率，不显式训练奖励模型，也不需要在线 rollout 或 Critic。DPO 更简单稳定，但受固定偏好数据覆盖范围限制；PPO 可利用在线反馈探索，但更复杂且可能发生奖励投机。

### C. LoRA / 参数高效微调

15. 你在项目里用 BLIP-2 做了 LoRA 微调。LoRA 为什么可以省显存？

**解答**：LoRA 冻结原权重 \(W\)，只训练低秩增量 \(\Delta W=BA\)，其中秩 \(r\ll \min(d_{in},d_{out})\)。训练时只有 A、B 需要梯度和优化器状态，因此相较全参数微调大幅减少可训练参数对应的显存。基座权重和前向激活仍需保存，所以节省的主要是梯度、优化器状态及部分通信开销；若结合量化基座权重形成 QLoRA，还可进一步降低权重显存。

16. 参数增加了，为什么 LoRA 反而还能省显存？

**解答**：比较基准是全参数微调，而不是纯推理。LoRA 虽新增少量参数，但冻结了数量远大的基座参数。以 Adam 为例，全参数微调需为每个可训练参数保存梯度和一、二阶矩，混合精度下还可能保存 FP32 主权重；LoRA 只为低秩参数保存这些状态。因此新增量远小于被冻结部分省下的训练状态。激活显存不会因 LoRA 自动消失，仍可配合梯度检查点等方法优化。

17. 推理阶段用 LoRA 和不用 LoRA，有什么区别？效率上有什么影响？

**解答**：LoRA 可以在部署前把 \(BA\) 合并进基座权重，此时单适配器推理的算子数量和延迟通常接近原模型，但得到的是已适配模型。若不合并以支持多租户动态切换，每层需额外计算低秩分支，会增加少量计算、访存和调度开销；批次中混用多个 Adapter 时开销更明显。它通常不增加上下文长度。合并可能受量化格式和频繁切换 Adapter 的限制。

### D. 多模态模型 / VLM

#### 1. BLIP-2 相关

18. 你为什么选择 BLIP-2 做微调？选择 BLIP-2 的考虑是什么？

**解答**：应结合真实实验说明。一般考虑是 BLIP-2 用冻结视觉编码器和冻结 LLM，通过轻量 Q-Former 完成模态桥接，训练成本低于端到端训练整个 VLM；它具备图像问答和描述能力，生态成熟，便于在有限算力下用 LoRA 适配。选型仍应与 LLaVA、Qwen-VL 等候选在目标数据上比较准确率、吞吐、显存、语言能力和许可证，不能仅凭模型名判断。

19. BLIP-2 相对于 BLIP 有什么改进？

**解答**：BLIP 主要统一视觉语言理解与生成，并通过 Captioner 和 Filter 进行数据自举。BLIP-2 的核心改进是连接冻结的预训练图像编码器与冻结 LLM，引入 Q-Former：可学习 Query 通过交叉注意力从视觉特征中提取固定数量的信息，再映射到 LLM。其两阶段预训练先做视觉—语言表示学习，再做视觉到语言的生成对齐，从而以较少可训练参数利用强大的单模态模型。

#### 2. VLM 路线理解

20. 你对 VLM 这条线还有哪些了解？之前有关注过哪些相关工作？

**解答**：VLM 常见路线包括：CLIP 式双塔对比学习，适合跨模态检索；BLIP/BLIP-2 式视觉编码器加 Q-Former；LLaVA 式视觉编码器加投影层再接 LLM；Qwen-VL 等统一多模态对话模型；以及支持高分辨率、多图、视频和工具调用的模型。可从视觉 token 化、模态对齐、预训练与指令微调数据、动态分辨率、位置编码、幻觉评估和推理效率进行比较。

21. Qwen-VL 了解吗？

**解答**：Qwen-VL 系列将视觉编码器输出通过适配模块映射到语言模型空间，支持图像理解、OCR、定位和多轮图文对话。不同版本架构和训练策略不同，回答时应注明版本。新版本通常强化动态分辨率、多图/视频输入、细粒度视觉理解和更长上下文。训练一般包含视觉语言预训练、跨模态对齐与多模态指令微调，不能把所有版本概括为完全相同的三阶段流程。

22. 相比于 LLaVA，Qwen-VL 有哪些不一样的地方？

**解答**：原始 LLaVA 使用 CLIP 视觉编码器和较简单的投影层连接 LLM，重点通过视觉指令数据获得通用对话能力。Qwen-VL 系列更强调多语言 OCR、图像定位、多图/视频和动态分辨率等能力，部分版本的视觉编码器、位置编码和 token 压缩方式也不同。但 LLaVA 与 Qwen-VL 都在持续迭代，准确比较必须指定具体版本，并通过同一数据集、输入分辨率和部署配置评测。

### E. Transformer / 大模型基础

23. Position Encoding 是什么？有哪些分类？

**解答**：自注意力对输入排列本身不敏感，位置编码用于注入顺序和距离信息。常见类别包括：固定或可学习的绝对位置编码；在注意力分数中加入相对距离偏置的 RPE、T5 Bias、ALiBi；以及对 Q、K 做位置相关旋转的 RoPE。不同方法在参数量、相对位置建模和长度外推方面各有取舍，原始 RoPE 超出训练长度也可能退化。

24. 旋转位置编码、绝对位置编码，是直接加到 token embedding 上的吗？

**解答**：绝对位置编码通常与 token embedding 相加，也可采用其他融合方式。RoPE 不直接加到 token embedding 上，而是在每个注意力头中按位置旋转 Q 和 K，使二者内积包含相对位置差；V 通常不旋转。

25. 相对位置编码呢？比如 RPE 这种，它一般是加到哪里？

**解答**：实现取决于具体方法。Shaw RPE 可在注意力的 Key/Value 交互中加入与相对距离有关的向量；T5 Relative Position Bias 和 ALiBi 通常把按相对距离计算的标量偏置直接加到 Softmax 前的 Attention Logits 上。它不是统一地加到 token embedding 上。

26. Decoder 里面 causal attention 是怎么实现的？

**解答**：在注意力分数 \(QK^\top/\sqrt{d_k}\) 上加入因果掩码：对位置 \(i\) 不允许访问的未来位置 \(j>i\) 加 \(-\infty\) 或足够小的数，再做 Softmax，使其权重为 0。训练时可并行计算整个下三角注意力；自回归推理时每步只计算新 token 的 Q、K、V，并利用 KV Cache 复用历史 K、V。实现时还需叠加 Padding Mask，并注意数值类型和掩码方向。

### F. 手撕：最长不重复子串

**解答**：使用滑动窗口。`last[ch]` 记录字符最近出现位置；若它位于当前窗口内，则把左边界移动到其后一位。

```python
def length_of_longest_substring(s: str) -> int:
    last = {}
    left = 0
    ans = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

时间复杂度为 \(O(n)\)，空间复杂度为 \(O(|\Sigma|)\)，其中 \(|\Sigma|\) 为字符集大小。
