# 一面

1. 自我介绍。

**解答**：按“背景—相关能力—代表项目—个人贡献—量化结果—岗位匹配”组织，控制在 1～2 分钟，只陈述真实经历。

2. 讲一下 RAG 的总体流程，结合项目。

**解答**：离线完成文档解析、清洗、切块、Embedding 和索引；在线进行 Query 理解/改写、BM25 与向量混合召回、元数据过滤、Reranker、上下文组装、基于证据生成和引用校验。结合项目时说明真实语料、索引、模型、指标和本人职责。

3. BN 和 Dropout 在训练和推理时有什么不同？

**解答**：BatchNorm 训练时使用当前 Mini-batch 的均值和方差，并更新运行统计量；推理时使用训练阶段累计的 Running Mean/Variance。Inverted Dropout 训练时以概率丢弃激活，并把保留值除以保留概率；推理时关闭 Dropout，无需再次缩放。调用 `model.train()`/`model.eval()` 可切换行为。

4. 文档问答中如何构建索引，提升对用户问题的泛化能力？

**解答**：按标题和语义边界切块并保留父子关系、来源、时间与权限元数据；使用适合领域的 Embedding，结合 BM25 与 Dense 混合检索；通过 Query 改写、多查询或 HyDE 提升表达覆盖，再用 Reranker 精排。用 Recall@K、MRR/NDCG、延迟和端到端答案正确率调参。

5. Attention 为什么除以 \(\sqrt{d_k}\)，还有哪些 Scale 处理？

**解答**：若 Q、K 各维独立、均值 0、方差 1，则点积方差约为 \(d_k\)；除以 \(\sqrt{d_k}\) 可把方差拉回约 1，避免 Softmax 过度饱和。其他相关缩放包括 Temperature、余弦注意力的可学习温度，以及位置编码的 NTK/YaRN 缩放；它们目标不同，不能混为一谈。

6. 如何构建重排序模型的微调数据？

**解答**：从查询日志或人工题库构造 Query—Document 对；正样本来自可靠点击、成交或人工标注，负样本包括随机负样本和由 BM25/Dense 召回的 Hard Negative。要处理曝光与位置偏差、去重并按用户/时间隔离测试集。可训练二分类 Cross-Encoder，或使用 Pairwise/Listwise 排序损失，并以 MRR、NDCG、Recall 和线上指标评估。

7. RoPE 相对正弦绝对位置编码有哪些优势？

**解答**：绝对正弦编码通常加到输入表示；RoPE 对注意力中的 Q、K 做位置相关旋转，使点积自然包含相对位置差，无需学习位置表且适配自回归注意力。原始 RoPE 超出训练长度仍可能退化，不能宣称天然解决长度外推。

8. 为什么使用 RMSNorm 代替 LayerNorm？

**解答**：LayerNorm 同时减均值并按标准差缩放；RMSNorm 不做中心化，只按均方根缩放，计算更简单且在许多 Transformer 中效果稳定。它不是对所有模型都必然更优，实际收益依赖实现、硬件和训练配置。

9. RMSNorm 与 LayerNorm 的数学区别是什么？

**解答**：
\[
\operatorname{LN}(x)=\gamma\odot\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta,
\quad
\operatorname{RMSNorm}(x)=\gamma\odot\frac{x}{\sqrt{\frac1d\sum_i x_i^2+\epsilon}}。
\]
RMSNorm 去掉均值中心化，很多实现也不使用偏置 \(\beta\)。

10. 指令微调和提示学习有什么区别？

**解答**：Instruction Tuning 使用指令—回答数据更新模型参数或 LoRA 等适配参数，使能力写入模型；Prompting 在推理时用自然语言指令和示例引导冻结模型。Prompt Tuning 则是提示学习的一种参数高效方法：冻结基座，只学习连续软提示向量，不能与普通文本 Prompting 混为一谈。

# 二面

1. 介绍项目。

**解答**：按真实经历说明背景、目标、个人职责、方案取舍、量化结果和复盘，不虚构指标。

2. Embedding 与生成模型如何协同？

**解答**：典型方式是 RAG：Embedding 双塔将 Query 与文档编码为向量并做 ANN 召回，Reranker 精排后把证据交给生成模型。也可将检索结果用于工具调用或记忆。Embedding 负责高效相关性检索，生成模型负责综合和表达，两者需分别及端到端评估。

3. 减少大模型幻觉用过哪些方法？

**解答**：使用高质量数据和拒答样本；对实时/私域事实采用数据库或 RAG；优化召回与重排；要求引用证据且无证据时拒答；使用规则、检索、NLI 或人工复核。降低 Temperature 只减少随机性，不能保证正确。

4. 如何识别输出幻觉，有哪些自动化指标？

**解答**：把答案拆成原子事实，再检查是否被上下文或可信外部来源支持。RAG 可评估 Faithfulness、Citation Precision/Recall、Context Precision/Recall 和 Answer Correctness；开放域可用检索验证、NLI 或 LLM Judge 辅助。自动指标存在偏差，需用人工标注集校准，并单独统计拒答准确率。

5. 搜索准确性不高怎么排查？召回、排序哪个阶段最可能出问题？

**解答**：先建立带相关性标注的诊断集。若相关文档不在候选 Top-K，问题在数据、切块、索引、过滤、Query 或召回模型；若已召回但名次靠后，问题在融合或排序；若文档排名正确但答案差，则查上下文组装和生成。不能脱离分阶段指标直接判断哪个阶段“最可能”。

6. 如何从系统层面提升搜索相关性？

**解答**：做好文档清洗、语义/父子切块和元数据；结合 BM25、Dense、结构化/图谱多路召回；使用 RRF 或学习融合，并以 Cross-Encoder 精排；加入 Query 改写、拼写纠错、实体识别、反馈闭环和时效性过滤；用 Recall@K、MRR、NDCG 与线上实验验证。

7. LoRA 的原理及优势？

**解答**：冻结 \(W\)，只学习 \(\Delta W=(\alpha/r)BA\)，其中 \(r\) 很小。它减少可训练参数对应的梯度、优化器状态和通信成本，Adapter 便于保存和切换；推理时可合并到基座权重。它不会自动消除激活显存，也不保证效果等同全参微调。

8. 了解生成式排序吗？能否保证 Top-1 准确性，怎么提高？

**解答**：生成式排序把候选标识、相关性标签或排列作为序列生成，可统一检索与生成，但不能保证 Top-1 正确。可通过高质量 Pairwise/Listwise 数据、候选约束解码、检索与生成混合、难负样本、蒸馏、校准和重排提高效果，并用 NDCG/MRR/Recall 与业务指标验证。

9. 项目中做过哪些相关性优化，有没有量化结果？

**解答**：按真实实验回答，列出基线、单项改动、离线指标、线上 A/B、时延和置信区间；没有正式数据时如实说明，不编造提升比例。

10. 为什么参数高效微调使用低秩矩阵分解？

**解答**：经验研究表明，预训练模型适配特定任务时的有效权重更新常具有较低内在秩，因此可用小矩阵 \(BA\) 近似增量，显著减少可训练参数和优化器状态。低秩是假设而非定理，秩过小会限制表达能力，需要针对任务验证。

11. 数组中目标值出现的开始和结束位置。

**解答**：分别用二分查找 `lower_bound(target)` 和 `lower_bound(target + 1) - 1`。若左边界越界或值不等于目标，返回 `[-1, -1]`。时间复杂度 \(O(\log n)\)，空间复杂度 \(O(1)\)。

# 三面

1. 了解 DeepSeek-R1 吗？

**解答**：DeepSeek-R1 系列重点展示了推理能力的后训练路线。R1-Zero 从基座模型直接进行大规模可验证奖励 RL，出现长推理、自检等行为，但可读性和语言混杂存在问题；R1 在此基础上加入冷启动 SFT、推理 RL、拒绝采样 SFT 与更广泛偏好对齐。描述应以公开技术报告为准，不能把所有阶段简化为“Zero-Shot RL”。

2. 什么是灾难性遗忘，怎么缓解？

**解答**：模型学习新领域后在原有任务上的性能显著下降即灾难性遗忘。可混入高质量通用回放数据、降低学习率和训练轮数、使用 LoRA/Adapter、蒸馏或 KL/L2 正则约束与基座输出/参数距离，并持续评测通用与领域能力。LoRA 只能降低风险，不能保证不遗忘。

3. GBDT 怎么并行化？

**解答**：同一棵树的层级通常存在依赖，但每层可并行构建各特征的梯度直方图、并行扫描候选切分点，并在数据并行节点间 All-Reduce 聚合统计量；也可做特征并行和投票式通信。多棵树通常按 Boosting 顺序依赖，不能简单全部并行。XGBoost、LightGBM 的具体分布式策略不同。

4. DeepSpeed 三个 ZeRO 阶段。

**解答**：ZeRO-1 分片优化器状态；ZeRO-2 再分片梯度；ZeRO-3 再分片参数并在计算时按需聚合。阶段越高单卡静态显存越低，但通信与调度成本通常越高；CPU/NVMe Offload 是独立选项。

5. 多路检索如何实现、融合和排序？

**解答**：并行执行 BM25、Dense、结构化过滤或图谱召回；各路先去重，可用 RRF 按名次融合，或校准分数后加权；再用 Cross-Encoder Reranker 精排并做多样性/业务约束。权重和 Top-K 需在标注集上以 Recall、MRR、NDCG、时延和端到端效果调优。

6. 什么是 RoPE，解决什么问题？

**解答**：RoPE 按位置旋转注意力中的 Q 和 K，使 \((R_mq)^T(R_nk)=q^TR_{n-m}k\)，从而让注意力分数包含相对位置差。它解决自注意力缺少顺序信息的问题，无需可学习位置表；原始 RoPE 的长度外推仍会退化。

7. 训练一个 7B 模型占多少显存，不同 ZeRO 阶段节省多少？

**解答**：只算 BF16 权重约 14 GB；全参训练还需梯度及 Adam 的主权重和一、二阶矩，常见粗估约 16 Bytes/参数，即约 112 GB 静态状态，另有激活、临时缓冲和碎片。设数据并行度为 \(N\)：ZeRO-1 仅把优化器状态除以 \(N\)，ZeRO-2 再把梯度除以 \(N\)，ZeRO-3 连参数也除以 \(N\)。精确值取决于实现、精度、优化器、序列长度、Batch、Checkpoint 和 Offload。

8. Embedding 与生成模型如何协同？

**解答**：见二面第 2 题：Embedding 负责大规模召回，生成模型基于筛选后的证据综合回答；中间通常加入 Reranker、权限过滤和引用校验，并分别评估检索与生成。

9. 讲 DPO、PPO、RLHF。

**解答**：RLHF 是利用人类反馈对齐模型的流程，经典实现为 SFT、奖励模型和 PPO。PPO 在线采样，使用优势估计、裁剪概率比与 KL 约束，成本高但可探索；DPO 直接用偏好对优化策略相对参考模型的对数概率，不显式训练奖励模型和 Critic，简单稳定但受离线数据覆盖限制。
