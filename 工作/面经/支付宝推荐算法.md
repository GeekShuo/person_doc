2.八股介绍一下MMOE,极化现象知道吗，如何解决？
**解答**：
- **MMoE (Multi-gate Mixture-of-Experts)**：多任务推荐系统经典红文。底座包含多个相互独立的Expert（专家网络）。在此之上，业务的每一个预测目标（例如预估点击率、预估转化率）都会配有一个**专属的Gate（门控网络）**。这个任务Gate会根据每个新进来的不同User特征，对底座的所有Expert进行独立的Softmax打分权重分配，从而让每个任务灵活拼凑各种专家的综合意见。
- **极化现象 (Routing Collapse)**：指门控网络养出了废人。在训练中，如果某个特定的专家在早期不小心梯度跑得比别人快一丝丝，赢者通吃导致所有任务门控全把 $100\%$ 的概率分高分砸向这位“明星专家”，别的专家彻底收不到任何反向梯度更新从而变成死神经元闲置。这导致引以为傲的MMoE直接退化成了传统残疾的单模型硬共享网络。
- **如何解决极化**：
  1. **辅助惩罚Loss (Load Balancing Loss)**：在Loss里加上惩罚项，强力要求每次在长长的Batch内，各个专家被选中的总频次必须趋向于绝对均等的正态分布！
  2. **引入 Dropout / Noisy Gate**：在门控打分时故意注入随机噪音，强迫它不得不同时开通多个冷板凳专家的门。
  3. **架构升级（如PLE网络）**：最彻底治本方案。给每个任务显式分配一个“禁止别人碰的私有独享专家”，再另外保留几个大家联用的“共享专家”。从而在底座彻底实现底层特征物理隔离提取，叫 CGC 架构（Customized Gate Control）。

3.code最大子数组和链表交替打印。
**解答**：
- **最大子数组和 (LeetCode 53)**：经典 $O(N)$ 题目。用动态规划数组 `dp[i] = max(nums[i], dp[i-1] + nums[i])` 或者贪心：设一个全局Max，一个当前累加和，如果你当前这个数前面累加上来已经掉到负数甚至不及别人单兵作战大了，那么前面的彻底抛弃清零从你现在重新算。

4.AUC是如何计算的？
**解答**：两套说辞。
- **物理（概率）意义与通透算法**：假设我们从测试集中随机挑选出一个正样本和一个负样本。大模型针对这个正样本给它的预测得分**大于**那个负样本得分的绝对概率。
- **工业界基于排序的 $O(N\log N)$ 死背公式法**：将所有预测样本按模型输出概率从小到大排好队发号码牌（序号就是Rank位）。套公式：$\text{AUC} = \frac{\sum(\text{纯正样本的整体Rank号加总}) - \frac{M(M+1)}{2}}{M \times N}$。这里 $M$ 是正样本总数，$N$ 是负样本总数。
- 如果真想画图逼近：画出 ROC 曲线（横轴FPR、纵轴TPR），用梯形积分求ROC曲线围成的底部面积即是。

5.样本不均会对 AUC 和 ROC 曲线有影响吗？
**解答**：
**完全没有任何影响！这是 AUC 最强大的立身之本。**
它是对类别不平衡极具有**免疫鲁棒性**的王者指标。因为ROC曲线上的两个基准点（TPR和FPR）分别只在自己的小群体（纯阳性内部、纯阴性内部）里算比例打转，它们绝不互相算加减跨界。所以就算你把数据的负类小偷样本翻一万倍，正派被淹没，曲线形状和曲线底下的AUC分数依然岿然不动。
（补充防坑：如果样本极度不平衡绝不能看 Accuracy准确度，甚至 PR 曲线也会严重飘移走形）。

6.L1和L2的区别介绍一下bn过拟合还有什么其他方法
**解答**：
- **L1 正则化（Lasso回归）**：惩罚 Loss 里的权重绝对值之和。L1 的等高线是一个带尖角的菱形块，在梯度下降中非常极其容易切在纯坐标轴的 $0$ 截距上。所以它很容易促使原本弱小的权重**彻底归零坍缩，产生绝对稀疏的高维权值矩阵**（自带粗暴特征筛选基因）。
- **L2 正则化（Ridge回归）**：惩罚 Loss 里权重的平方和。L2 只是让所有权重变得非常非常微小接近0，但并不会真的被抹去杀到绝对0。它的作用是抵抗协方差极其严重的共线性特征权重发散爆缸，让权值**总体趋于平滑抗噪**。
- **防止过拟合的其它神功手段**除了 Batch Normalization (BN) 还有：
  1. 引入随机失活（Dropout）；2. 粗暴增加带噪音数据或者Data Augmentation；3. 利用验证集直接开启提早停止训练机制（Early Stopping）；4. 在输入侧强制降低模型维度天花板（直接把树减小或网络减层）。

7.项目中的 loss 是怎么做的？
**解答**：
（推荐系统典型）：通常基于点击与否采用二元交叉熵损失函数（Binary Cross Entropy, 即LogLoss）。如果遭遇极大不平衡或者想让模型更专注挖掘难分错题特征（Hard Example Mining），则引入了 Focal Loss 衰减容易确信样本的传导权重。

8.最后上线看什么指标？线上推理用什么指标？
**解答**：
- **模型离线验证打榜看**：绝不能光看全局AUC（它可能忽略了不同用户天然极其不同的活跃度点击率导致的系统面不公），重推 **GAUC (Group AUC)** 指标，即在每个受众用户的个人池子里单独算一个他们自己的AUC，最后再按照该用户曝光量总体加权合并。
- **真刀真枪接轨真实用户的线上（在线AB实验看板）**：看核心收益商业指标：**CTR**（大盘总点击率）、**CVR**（用户下单总转化率）、以及终极大Boss：即该排序位给公司真带来的日成交额大盘增长。还有各种反向监控指标：如页面跳出流失率、千次展现带来的充值收益利润（RPM/eCPM）。

9.为什么在计算时要进行放缩，怎么放缩的？
**解答**：
这是典型的 Transformer $\text{Softmax}(\frac{QK^\top}{\sqrt{d_k}})$ 相关八股。
- **怎么放**：强制把 $Q$ 与 $K$ 算出来的内积实数果子，除以此前嵌入向量的隐层厚度维度（比如64）的**平方根 $\sqrt{d_k}$（比如除以8）**。
- **为何放**：如果硬桥硬马不放缩去点乘，该点乘内积果实值的**方差**会随着隐特征维度 $d_k$ 变厚而**呈直线剧烈飙大膨胀**。进入Softmax后，极其离谱高分的尖顶数据会导致指数 $e^x$ 爆炸并在分母占去统筹绝对权。它把本该丰富的分布变成极度陡峭且极端的0/1两极分配；同时把反向传播梯度逼进了Softmax函数的极平缓死区产生严重的**梯度彻底干涸消失（Gradient Vanishing）**。通过这个平平无奇的平方根缩小，恰好能将其方差硬生生稳压按回到稳如老狗的 $1$ 刻度上救活模型。

10.用 transformer 会导致什么性能上的问题，怎么解决的，了不了解一些节省空间的 attention ?
**解答**：
- **最大死穴性能灾难**：在Attention做自内积发牌机制时，它的内存消耗量和浮点计算总时间与**传入文章Tokens序列全长度成丧心病狂的 $O(L^2)$ 抛物线级倍增灾难（序列一旦上万字，A卡也当场死机爆炸）。**
- **怎么救与省空间Attention流**：
  1. **工业刚需续命药（推理期特供）**：**KV-Cache 张量缓存法**，以及通过降低甚至分组强行砍掉大量独立特征头的 **MQA/GQA （多查询聚合注意力）**极度节流存KV的池子。
  2. **砍断全局死连结（稀疏化/局部分割）**：比如引入类似 Sliding Window Attention 滑动窗户策略（如Longformer的做法，当前Token只跟在它前后几十里地的邻居Token发生Attention连线计算，切断极遥远的羁绊）；又或者构建树状分组合并，用稀疏连线化解算力。
  3. **硬件级突破**：Flash Attention 通过极致的分块入寄存器读写来化解高昂极其费空间的临时变量（如巨大的 $n \times n$ 分数打分表不入主显存）。

11.linux 熟悉吗，用过什么命令， git 用过什么命令，如果 push 了想撤回怎么办？
**解答**：
- **Linux极客三件套**：`awk`和`sed`常用来在极其庞大的没有界面的纯文本几十G大日志海中切分查找断点和切除首位特殊字符；挂服务器炼丹常备 `htop`, `watch -n 1 nvidia-smi` 紧盯掉卡；模型暴毙死机果断 `ps -ef | grep py` 找到所有相关的脏僵尸孤儿进程再利用 `xargs kill -9` 进行连坐诛族斩首释放显存。
- **Git 错交撤回大杀器**：
  - **情形A（独自练级不留痕迹）**：如果还没人下载这个公共主干，直接先在本地撤销退档回上一节点 `git reset --hard HEAD~1`，然后拿出不要命的心态强行推送覆压远端 `git push origin <分支名> --force`，当无事发生。
  - **情形B（团队协作不想被打）**：这是极其正规绝对安全无痛的正轨打法，绝对不能重置。执行反补指令 `git revert <刚才传错了的那段倒霉的Commit哈希号>`。它将产生一个全新的魔法补丁，“这块新补丁的意义是百分百反演推平并且彻底抵消抹掉上一次我搞出的所有新代码块灾难”，生成这段新补丁Commit后安全优雅地直接 `git push` 推向云端拯救世界。

12.📚概率题：一根木棍切两刀能拼成三角形的概率。
**解答**：
**极度经典：$1/4$。** 
这是之前快手里面也有一样的题目！设一根长为1大绳剪出 $x$ 和 $y$。要求就是这三条边分别小于半米大关 $0.5$（也就是 $x<0.5, y<0.5, x+y>0.5$ 这个超强约束）。在坐标抽大布上画，这就是底和高度分别由横纵切满全图的面积为 $0.5$ 大直角三角形被等边刀卡出的正核心小倒三角形区域。其占比恒为 $1/4$。
