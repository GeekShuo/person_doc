## 2．讲一下大模型训练和推理的流程，SFT 和 RLHF 的作用分别是什么

**解答**：训练通常包括数据清洗与去重、Tokenizer 处理、自监督预训练、SFT、偏好对齐和评测。预训练用海量文本做下一 Token 预测以获得通用能力；SFT 用指令—回答数据学习指令遵循、任务格式和领域行为；RLHF 用人类偏好训练奖励模型并通过 PPO 等优化策略，或使用 DPO 等直接偏好优化，使模型更符合帮助性、安全性等偏好，但不能代替事实知识学习。

推理分为 Prefill 和 Decode：Prefill 并行处理输入并建立 KV Cache；Decode 每次生成一个 Token，复用历史 K、V，直至 EOS 或长度上限。部署还需考虑量化、批处理、并行、采样策略和服务监控。

## 3．为什么探索 MoE 架构，MoE 相比 Dense 有什么好处

**解答**：Dense 模型每个 Token 激活全部参数；MoE 用 Router 为每个 Token 选择少数专家：

\[
y=\sum_{i\in\operatorname{TopK}(g(x))}g_i(x)E_i(x)。
\]

MoE 能在单 Token 激活计算量相对可控时扩大总参数量和模型容量，并让专家产生一定专业化。代价是全部专家仍占存储，训练需要 Expert Parallel 和 All-to-All 通信，还会遇到负载不均、容量溢出和路由不稳定，因此通常需要负载均衡损失与合理的并行策略。

## 4．有没有全量微调过

## 5．推导一下神经网络反向传播的过程

**解答**：设第 \(l\) 层为

\[
z^{(l)}=W^{(l)}a^{(l-1)}+b^{(l)},\quad a^{(l)}=f(z^{(l)})。
\]

定义 \(\delta^{(l)}=\partial\mathcal L/\partial z^{(l)}\)。输出层由损失直接求得；Softmax 加交叉熵时有 \(\delta^{(L)}=\hat y-y\)。隐藏层根据链式法则：

\[
\delta^{(l)}=(W^{(l+1)})^\top\delta^{(l+1)}\odot f'(z^{(l)})。
\]

参数梯度为

\[
\frac{\partial\mathcal L}{\partial W^{(l)}}=\delta^{(l)}(a^{(l-1)})^\top,\qquad
\frac{\partial\mathcal L}{\partial b^{(l)}}=\delta^{(l)}。
\]

反向传播本质是从损失出发，按计算图逆序应用链式法则并复用中间梯度。

## 6．在 RLHF 中，目前主流的强化学习算法有哪几个，写一下损失函数

**解答**：常见方法有 PPO、REINFORCE/RLOO、GRPO；DPO 严格说是离线直接偏好优化，也常与 RLHF 一起讨论。

PPO 的概率比与裁剪目标为：

\[
r_t(\theta)=\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\theta_{old}}(a_t\mid s_t)},
\]

\[
L_{PPO}=-\mathbb E_t\left[\min\left(r_t\hat A_t,
\operatorname{clip}(r_t,1-\epsilon,1+\epsilon)\hat A_t\right)\right]，
\]

通常再加入价值损失、熵项和相对参考模型的 KL 约束。

DPO 对偏好对 \((x,y_w,y_l)\) 优化：

\[
L_{DPO}=-\mathbb E\log\sigma\left(\beta\left[
\log\frac{\pi_\theta(y_w\mid x)}{\pi_{ref}(y_w\mid x)}-
\log\frac{\pi_\theta(y_l\mid x)}{\pi_{ref}(y_l\mid x)}
\right]\right)。
\]

GRPO 对同一问题采样一组回答，用组内标准化奖励估计优势，再使用类似 PPO 的概率比裁剪目标，从而省去独立 Critic。

## 7．一道排列组合的概率题

**解答**：题干缺少具体条件，不能给唯一数值答案。通用步骤是：明确样本空间是否等可能、是否有放回、是否考虑顺序；分别计算样本总数 \(|\Omega|\) 与满足条件的数量 \(|A|\)，等可能时 \(P(A)=|A|/|\Omega|\)。排列用 \(A_n^k=n!/(n-k)!\)，组合用 \(C_n^k=n!/[k!(n-k)!]\)。不等可能时应使用条件概率、全概率公式或随机变量分布，不能只数情况。

## 8．平常有用过 RLHF 吗，简单介绍一下

**解答**：按真实经历回答。经典流程是：先对基座模型做 SFT；对同一 Prompt 的多个回答进行偏好标注并训练输出标量分数的奖励模型；再让策略模型在线生成回答，用奖励与 KL 约束构造目标，通过 PPO 更新，同时训练价值模型。若只做过 DPO/GRPO 或阅读复现，应明确范围，并说明数据、奖励、训练稳定性和评测方式。

## 9．开放题：对目前大模型的发展有什么看法

**解答**：可以从四点回答：一是能力提升越来越依赖高质量数据、合成数据与训练后对齐，而不只是扩大参数；二是 MoE、量化、投机解码和高效注意力推动成本下降；三是 RAG、工具调用和 Agent 使模型从文本生成器走向可执行系统，但可靠性与评测仍是瓶颈；四是多模态和长上下文快速发展，同时带来幻觉、安全、版权与能耗问题。判断应基于公开事实，并结合岗位说明自己更关注的方向。

## 10．代码：多头自注意力

**解答**：以下实现输入、输出均为 `[batch, seq_len, d_model]`，并支持布尔 Mask：

```python
import math
import torch
from torch import nn

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int):
        super().__init__()
        if d_model % num_heads != 0:
            raise ValueError("d_model must be divisible by num_heads")
        self.num_heads = num_heads
        self.head_dim = d_model // num_heads
        self.qkv = nn.Linear(d_model, 3 * d_model)
        self.out = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor, mask: torch.Tensor | None = None):
        b, n, d = x.shape
        qkv = self.qkv(x).view(b, n, 3, self.num_heads, self.head_dim)
        q, k, v = qkv.permute(2, 0, 3, 1, 4)
        scores = q @ k.transpose(-2, -1) / math.sqrt(self.head_dim)
        if mask is not None:
            scores = scores.masked_fill(~mask, torch.finfo(scores.dtype).min)
        attn = torch.softmax(scores, dim=-1)
        y = (attn @ v).transpose(1, 2).contiguous().view(b, n, d)
        return self.out(y)
```

时间复杂度为 \(O(BN^2D)\)，注意力矩阵空间复杂度为 \(O(BHN^2)\)。

## 2．知道哪些强化学习算法，除了 PPO 和 DPO 还有什么

**解答**：可按类别介绍：值函数方法如 Q-learning、DQN；策略梯度如 REINFORCE；Actor-Critic 方法如 A2C/A3C、DDPG、TD3、SAC；信赖域方法如 TRPO、PPO；离线 RL 如 CQL、IQL；大模型对齐中还有 RLOO、GRPO 等。DPO 不需要在线环境交互，属于直接偏好优化。回答时选择真正掌握的算法，说明 on/off-policy、离散/连续动作及主要稳定化手段。

## 3．LoRA 的原理是什么，A 和 B 怎么初始化，还有哪些初始化方法

**解答**：LoRA 冻结原权重 \(W\)，学习低秩增量

\[
W'=W+\frac{\alpha}{r}BA，
\]

其中 \(A\in\mathbb R^{r\times d_{in}}\)、\(B\in\mathbb R^{d_{out}\times r}\)。常见初始化是一侧随机初始化、另一侧置零，使训练开始时 \(\Delta W=0\)，模型初始输出不变；不同库对 A/B 的命名和方向可能相反。其他方法包括 PiSSA，利用原权重的主奇异分量初始化；LoftQ，联合考虑量化误差初始化；EVA，利用激活统计分配秩。它们是否更好需用目标任务验证。

## 4．除了 DeepSpeed，还用过哪些优化方法

**解答**：训练侧可使用 PyTorch FSDP、Megatron-LM 的张量/流水线并行、混合精度、梯度累积、梯度检查点、CPU/NVMe Offload、FlashAttention 和高效数据管线。推理侧可使用 vLLM/SGLang、PagedAttention、连续批处理、量化、张量并行和投机解码。vLLM 是推理框架，不能当作 DeepSpeed 训练优化的同类替代品；应按真实经历说明实际使用范围。

## 5．ZeRO-1、ZeRO-2、ZeRO-3 的区别

**解答**：普通数据并行在每张卡保存完整参数、梯度和优化器状态。ZeRO-1 分片优化器状态；ZeRO-2 进一步分片梯度；ZeRO-3 再分片模型参数，并在前向/反向时按需 All-Gather。阶段越高，单卡静态显存越低，但通信、调度和实现复杂度通常越高。是否 Offload 到 CPU/NVMe 是独立配置，并非某个阶段必然行为。

## 6．讲一下 RLHF 的流程，之前有用 RLHF 做过模型对齐吗

**解答**：经典流程是 SFT、偏好数据收集、奖励模型训练、PPO 策略优化和评测。奖励模型通常对完整 Prompt—Response 输出标量，并用成对排序损失训练；PPO 目标加入相对参考模型的 KL 约束。按真实经历说明是否完整训练过 RM、Critic 和在线 rollout；如果只做过 DPO 或 LoRA，应明确区别，不虚构实践。

## 7．用 ZeRO-3 微调 Qwen2-72B，每张卡显存大约多少，怎么估算

**解答**：不能脱离卡数、精度、优化器、是否全参、序列长度和 Offload 给固定值。以全参 BF16、Adam、8 卡、无 Offload 粗估：BF16 参数约 144 GB；BF16 梯度约 144 GB；FP32 主权重与 Adam 一、二阶矩约 864 GB，合计约 1.15 TB，ZeRO-3 理想均分后约 144 GB/卡，尚未包含激活、临时 All-Gather、碎片和通信缓冲，因此 8×80 GB 放不下。若优化器实现不保留 FP32 主权重，静态占用会下降；LoRA、更多 GPU、CPU Offload、梯度检查点和较短序列可进一步降低显存。最终应以实际配置和峰值监控为准。

## 8．微调 Qwen 时数据怎么构造

**解答**：先定义目标任务和能力分类，从合法业务数据、公开数据和人工种子中构建指令—回答；统一为模型对话模板，只对 Assistant 输出计算损失；做脱敏、事实核验、格式过滤、精确/近似去重和训练测试污染检查；再按领域、难度和任务类型配比。Self-Instruct 可用于扩充，但生成数据必须经过规则、模型与人工抽检，不能把单一模型生成当成唯一来源。

## 9．代码：无重复字符的最长子串

**解答**：

```python
def length_of_longest_substring(s: str) -> int:
    last = {}
    left = ans = 0
    for right, ch in enumerate(s):
        if ch in last and last[ch] >= left:
            left = last[ch] + 1
        last[ch] = right
        ans = max(ans, right - left + 1)
    return ans
```

滑动窗口中每个字符至多进入和离开一次，时间复杂度 \(O(n)\)，空间复杂度 \(O(|\Sigma|)\)。
