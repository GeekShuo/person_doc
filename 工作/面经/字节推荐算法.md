2.如何做attention，为什么attention要除以根号dk?
**解答**：在缩放点积注意力（Scaled Dot-Product Attention）中，$QK^T$ 的结果必须除以 $\sqrt{d_k}$。
如果不缩放，当词向量维度 $d_k$ 变大时，$QK^T$ 点积结果的绝对值会暴涨。将这类绝对值的数字送入Softmax函数时，会落在指数函数的严重饱和区。这会导致计算出的梯度趋近于0（梯度消失），模型根本没法更新。
除以根号 $d_k$ 是为了将内积结果方差重新拉回缩放至1，保证在Softmax处理时梯度的稳定健康。

3.讲讲你对Embedding了解多少？
**解答**：Embedding（嵌入）本质上是一种将高维稀疏的离散特征（比如几十万词汇的One-hot，千万级的用户/商品ID）映射到低维稠密的连续实数向量空间的技术。
在推荐系统和NLP中，训练好的Embedding能非常优雅地度量不同实体间的隐式语义或共现相似度。在推荐里常见的产生Embedding的做法包括：User/Item的传统矩阵分解（MF）、Item2Vec（基于随机游走和Word2Vec）、以及当下主流的基于大图神经网络（GNN/GraphSAGE）聚合抽取的结构化表征。

4.对推荐系统都有哪些了解？常用技术点有哪些？
**解答**：推荐系统通常是一个漏斗形的层级架构。从海量物品中层层筛选给用户：
1. **召回（Recall）层**：负责从千万级库里快速初筛出几百上千个潜在物品。常用技术包括：多路召回（热门、ItemCF/UserCF）、向量召回（DSSM双塔极速ANN检索）。
2. **粗排（粗排序）层**：作为兜底，用稍微复杂的模型进一步筛到几百。常用轻量级DNN或经典的树模型。
3. **精排（精排序）层**：对这几百个物品进行精准的CTR（点击率）或CVR（转化率）预估打分。这里算力吃紧且非常核心，常用DeepFM、DIN（深度兴趣网络结合序列处理）、多任务学习（MMoE/PLE）等深度模型。
4. **重排（重排序）层**：结合业务侧的离散逻辑，打散同质化内容保证多样性。

5.从从ROC到AUC、再到GAUC，它们分别是什么，有什么区别？
**解答**：
- **ROC曲线**：接收者操作特征曲线，以FPR假阳性率为横轴，TPR真阳性率为纵轴，反应了在不同阈值下分类器表现的折线。
- **AUC**：即ROC曲线下的面积大小，专门衡量模型把正样本排在负样本前面的统计学概率。优点在于它是一个纯排序指标，对正负样本的天然不均衡比例不敏感，是业界最广泛在用的离线指标。
- **GAUC (Group AUC)**：在推荐系统中，由于普通AUC混合了所有的User，那些活跃或者由于自身特殊癖好（瞎点）的用户会拉偏大盘的整体评分。GAUC就是在每个独立User的圈层内部单独计算AUC，再根据其交互次数作为权重进行按User的加权求和平均。由于它消除了用户固有的点击偏置，能更准确地衡量模型对“针对单一用户精准排序提升个性化体验”的好坏。

6.为什么Transformer选用LayerNorm而不是BatchNorm？
**解答**：BatchNorm是对一个Batch内**所有的样本**在同一个特征维度上做归一化。但在NLP文本处理领域，不同句子的长短差异巨大，包含了太多毫无意义的Padding，且不同样本在同一个词元位置上的截面对齐在统计上是没有实际宏观特征意义的。
LayerNorm是对**单个样本**自身的所有特征维度进行归一化。即计算当前这个词其自身几千维Embedding内在分布的表现。这种方式与Batch的大小说无关，不论长短文本，归一化的结果都非常稳定，最适合处理变长的RNN或Transformer结构任务。

7.如何进行模型的在线训练，和离线训练有什么区别？
**解答**：
- **离线训练（Offline Learning）**：拿过去几周或几个月的全量静态历史数据死表，在Hadoop/Spark集群上通过多轮Epoch循环一次性把模型训好（或增量更新日级模型）。缺点是模型感知不到当天的新闻热点和新物料（冷启动时效滞后）。
- **在线训练（Online / ODL 流式训练）**：系统在离线训出Base基座推流后，借助Flink等实时流处理计算框架，收集线上引擎刚发出不久就已经产生的曝光、点击埋点流，在几分钟甚至是秒级延迟内拼接好Label发送给后端的流式更新训练机，模型在内存中进行实时的增量梯度更新（Incremental Update）。这对解决新闻资讯、短视频这类吃时效性的推荐场景有绝大提升。

10.交叉熵怎么理解？
**解答**：这是从信息论中引入的核心概念。本来信息熵衡量了一个真实概率分布的不确定性。当我们使用一个预估分布 $Q$ 来拟合真实分布 $P$ 时，因为表达有误差，所需的平均编码长度相对于完美情况会有所增加，这就是交叉熵：$-\sum P(x)\log Q(x)$。
在二分类或多分类深度学习中，真实标签的分布是固定的。因此，最小化预测概率分布与真实标签的交叉熵，在数学上等价于在做**似然估计**，即让模型产生的分布无限逼近上帝视角的那个正确答案的分布。

11.算法题：三数之和
**解答**：Leetcode 15 经典高频题。
**核心思路：先排序，再遍历用双指针。**
```python
def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums) - 2):
        # 避免外层重复数字导致重复的三元组
        if i > 0 and nums[i] == nums[i-1]:
            continue
        left, right = i + 1, len(nums) - 1
        while left < right:
            s = nums[i] + nums[left] + nums[right]
            if s < 0:
                left += 1
            elif s > 0:
                right -= 1
            else:
                res.append((nums[i], nums[left], nums[right]))
                # 记录完后继续寻找，且要跳过重复数字
                while left < right and nums[left] == nums[left+1]:
                    left += 1
                while left < right and nums[right] == nums[right-1]:
                    right -= 1
                left += 1
                right -= 1
    return res
```

2.深度学习batchsize变大会产生什么影响？
**解答**：Batch Size（批大小）变大：
- **优点**：一次送入卡的标量计算更多，对矩阵并行非常友好，提升GPU总体的运算吞吐量。同时因为梯度计算综合了更多样本，使得优化的方向更准，损失曲线下降更平滑。
- **缺点**：过大的Batch Size极有可能陷入尖锐的局部最优最小值导致模型泛化能力差；缺乏震荡的噪声也容易让模型困在鞍点中。通常在将Batch Size翻倍增大时，必须辅以适当对应调大或者翻倍的学习率（Linear Scaling Rule）并辅以Warmup。

3.介绍一下 MMOE ，极化现象了解多少，解决途径是什么？
**解答**：
- **MMoE (Multi-gate Mixture-of-Experts)**：为了解决推荐里“点击”和“转化”等多任务目标存在微弱冲突（Negative Transfer 负迁移）问题提出的架构。它底层构建了多个通用的专家表征网络（Experts），并在上方为每一个具体业务目标（如CTR头、CVR头）分别单独设置了一个Gate（门控网络结构）。不同任务根据其特性用自己的门控按需吸纳不同专家的特征，从而实现了软性参数共享机制。
- **极化现象**：训练期间，某个门控在经历了Softmax分配后，可能极端地把 $0.99$ 的概率砸给了某一位专家，剩下的是 $0.01$。这样不仅会导致其余专家网络实际上因为收不到梯度而“饿死”崩溃，更使得网络结构实质上退步倒退为了落后的“单一硬共享方式”。
- **解决途径**：采用标签平滑、在Gate前加入一定的噪声或Dropout、加入温度超参数平滑Softmax；最主流的做法是在总Loss中插入关于Gate分布方差的**平衡辅助Loss（Load Balancing Loss）**，强迫模型均匀探索。

4.说一下L1和L2的区别。
**解答**：它们都是为了限制模型参数变得过大以防止过拟合的正则化手段：
- **L1 正则化（Lasso）**：在误差中加入所有权值**绝对值之和**的惩罚项。它的梯度推导出来是常数。在参数被优化的过程中如果贴近0，梯度仍然是一刀截断。所以它能够产生极致**稀疏的权重矩阵**（把很多没用的特征直接置0），带有一点Feature Selection提取关键特征的作用。
- **L2 正则化（Ridge）**：在误差中加入权值**平方和**的惩罚项。它的梯度与参数本身大小成比例线性衰减。即使是在接近最优点0的时候衰减力道也会随之变小，所以参数只会无限趋近于0、变得很小但是不绝对等于0。它的结果是使模型变得“平滑”抗干扰强，通常最常被直接使用作Weight Decay防止大参数过拟合。

5.Transformer的参数量如何计算？
**解答**：设模型隐层特征维度为 $d$，不论几头：
1个标准Transformer块（Block）主要分为两大耗参巨头：
- **MHA多头注意力**：涵盖四个矩阵变量：产生Q、K、V的投射矩阵，再加上用来统一的输出投影矩阵（$W_q, W_k, W_v, W_o$），由于都是 $d \times d$ 的方阵，这部分的参数量为 $4d^2$。
- **FFN前馈网络层**：经典设计是中间扩大4倍又拉回。第一层映射是 $d \times 4d$，第二层是 $4d \times d$。因此参数量是 $8d^2$。
因此，单层Block参数就是 $12d^2$ 左右。把层数 $L \times 12d^2$，加上字典Embedding（$Vocab \times d$）以及最后的预测头即可求得大概估算总量。

6.软共享和硬共享的区分方法有哪些？  
**解答**：针对深度多任务学习（Multi-Task Learning）的参数划分问题：
- **硬共享（Hard Parameter Sharing）**：多个不同任务必须共同强制享用所有的底层网络（参数捆死完全一致），仅仅到了最后的全连接那一点才开辟独立专属的头输出（如一个MLP切成两份输出点击和购买判定）。弱任务往往会被强任务的反向梯度淹没带偏。
- **软共享（Soft Parameter Sharing）**：各个任务可以有自己专属独立的一层或多层参数（如MMuE里的独占Gate、或者是Cross-stitch多塔间的网状链接层）。大家虽然相对独立，但是在前向传播过程中，自己特定任务的浅特征可以被其它任务有选择的参考融合（通过权重组合连接）。这种共享更宽松灵活，表现通常更好。

7.如何理解深度学习？
**解答**：广义来看，它是一种基于人工神经网络且包含多层堆叠隐层架构的机器学习技术核心分支。
从根本上区别于传统机器学习的核心在于**“端到端表示学习（End-to-End Representation Learning）”**。我们再也无需让人类专家基于经验去死磕手工提取各种繁琐的数据特征（人工特征工程）；我们将生硬的大规模原始数据（图像像素/词汇索引）喂入，依靠无数复杂的非线性模块叠加与反向传播机制层层过滤反思，促使模型像大脑一样在数据海中自发地提取、理解并抽象出解决问题的终极密码准则。

8.解读一下隐马尔可夫模型
**解答**：隐马尔可夫模型 (Hidden Markov Model, HMM) 是统计模型里用以描述拥有隐藏、不可见未知参数系统的一个马尔科夫过程建模理论经典框架。
在一个HMM中，存在一条真实的，被遮挡住了的双目不可见的**“隐藏状态序列”**（遵循马尔可夫转移性质），但你能看到它向外映射发射出的一条**“可见的观测序列”**。
经典的三大问题和算法解决核心：
1. **评估计算率**：用前向-后向算法解出看到某一观测序列有多大可能。
2. **解码窥探问题**：使用著名的 Viterbi (维特比算法)利用动态规划逆推找出这堆观测现象背后最有可能隐形导致出的一条“隐藏状态线路”。（被曾用于语音识别找音素/古老分词）。
3. **参数学习**：基于大批量观测数据用 EM架构 (Baum-Welch算法)把系统暗箱里的转移概率矩阵算个底朝天。

9.交叉熵与kl散度的关系？
**解答**：
信息论中有着优雅的联系公式：**KL散度 (相对熵) = 交叉熵 - 信息熵**。（即 $D_{KL}(P || Q) = H(P, Q) - H(P)$ ）
在一个模型损失优化当中，目标任务真实标签的分布 $P$ 是固定不变客观存在的统计学事实规律。因此真实分布的信息熵 $H(P)$ 是一个常数。
由此得出，我们千方百计地想要降低网络预估概率分布 $Q$ 和真实答案分布 $P$ 之间的 KL 散度（即减小两者之间的分布差异距离），在计算图梯度优化操作的过程中就百分之百完全等价于**直接地去最小化它们两者之间的交叉熵 $H(P, Q)$**。

10.概率题：54张扑克牌，平均随机分给6个人，其中2张王都在一个人手里的概率是？
**解答**：
采用坑位考虑法：
牌堆一共打出了54个位置坑位均匀发放。考虑大王（第一张王）：因为大家都一样，这54个槽位它随便选一个（占有该人名下的某个名额），此时因为每个人发9张牌，那名抽中大王的幸运儿手中这9张配额就剩下8个空位置还没发牌。
随后再考虑小王（第二张王）。这会儿桌上总共剩给小王能去钻的槽位因为大王占了一个还剩53个。小王想要恰巧和大哥大王待在一起落在同一个人身上，它必须钻进大王那个主人手中所剩下的8个空位名额里。
所以概率完美即：他手中剩下的那8个坑位 除以 全场总计供挑选的53个坑位，结果是 $\frac{8}{53}$。
