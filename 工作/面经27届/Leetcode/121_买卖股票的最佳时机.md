# [121] 买卖股票的最佳时机 (Best Time to Buy and Sell Stock)

## 题目描述
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。
你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。
返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

## 解题思路
- **贪心算法（一次遍历）**：我们在遍历价格数组时，始终记录**截止目前出现的最低价格**（`min_price`）。
- 每天都假设我们在今天卖出，那么今天的利润就是 `今天价格 - 之前的最低价格`。
- 我们比较每天计算出的利润，记录最大值即可。
- O(N) 时间复杂度，O(1) 空间复杂度。

## 代码模版 (Python)

```python
class Solution:
    def maxProfit(self, prices: list[int]) -> int:
        if not prices:
            return 0
            
        min_price = float('inf')
        max_profit = 0
        
        for price in prices:
            if price < min_price:
                # 遇到更低的价格，更新最低买入价
                min_price = price
            elif price - min_price > max_profit:
                # 尝试今天卖出，看看是否能刷新最大利润
                max_profit = price - min_price
                
        return max_profit
```

## 边界条件与易错点
1. **不能当天买卖产生利润**：虽然题目要求必定在未来的日子卖出，但就算我们把相同的一天当作买又卖（利润为0），上述代码逻辑 `max_profit` 初始也是 0，不影响结果。
2. **一直在跌的烂股票**：如果数组是 `[7,6,4,3,1]`，整个遍历过程中 `max_profit` 一直保持为 0 不被更新，最终返回 `0`，符合题意“不能获取任何利润返回 0”。
3. **初始值 `min_price`**：务必设为一个极大值（如 `float('inf')`），确保第一个元素能顺利更新进去。
