# [290] 单词规律 (Word Pattern)

## 题目描述
给定一种规律 `pattern` 和一个字符串 `s` ，判断 `s` 是否遵循相同的规律。
这里的 遵循 指完全匹配，例如， `pattern` 里的每个字母和字符串 `s` 中的每个非空单词之间存在着双向连接的对应规律。

## 解题思路
- **双向哈希映射**：这一题的本质和【205. 同构字符串】是一模一样的，只不过那题是 `字符映射到字符`，这一题是 `字符映射到单词`。
- 我们先把字符串 `s` 通过空格切分 `split()` 变成单词数组。
- 处理长度校验：如果 `pattern` 的长度和 `words` 数组的长度不一致，说明直接不遵循规律，返回 `False`。
- 然后使用两个字典分别记录 `char -> word` 和 `word -> char` 的映射关系，进行遍历比对检查。

## 代码模版 (Python)

```python
class Solution:
    def wordPattern(self, pattern: str, s: str) -> bool:
        words = s.split()
        
        # 如果长度不一致，必定不能完全映射
        if len(pattern) != len(words):
            return False
            
        char_to_word = {}
        word_to_char = {}
        
        for char, word in zip(pattern, words):
            # 验证正向（字母 -> 单词）
            if char in char_to_word and char_to_word[char] != word:
                return False
            # 验证反向（单词 -> 字母）
            if word in word_to_char and word_to_char[word] != char:
                return False
                
            # 建立映射
            char_to_word[char] = word
            word_to_char[word] = char
            
        return True
```

## 边界条件与易错点
1. **漏掉长度比对**：`split()` 切出来的单词数量可能和 `pattern` 字符数量不统一，如果只遍历两者 `zip` 后较短的一方就直接判断结束，会产生漏判，所以 `len(pattern) != len(words)` 必须写在开头。
2. **一对多的陷阱**：如果不配双哈希，当 `pattern = "abba"`, `s = "dog dog dog dog"` 时，会让 `a -> dog`, `b -> dog`，从而判定为 `True`，这就是没检查反向 `word_to_char` 导致的错误，单词和字母必须是一对一！
