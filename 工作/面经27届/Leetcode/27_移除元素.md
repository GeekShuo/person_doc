# [27] 移除元素 (Remove Element)

## 题目描述
给你一个数组 `nums` 和一个值 `val`，你需要 **原地** 移除所有数值等于 `val` 的元素，并返回移除后数组的新长度。
不要使用额外的数组空间，你必须仅使用 `O(1)` 额外空间并 **原地 修改输入数组**。
元素的顺序可以改变。你不需要考虑数组中超出新长度后面的元素。

## 解题思路
- **双指针法**：这也是一道典型的原地覆盖题目。
- 维护一个 `slow` 指针记录放置不需要移除元素的最新位置。
- `fast` 指针遍历整个数组，只要遇到了 `nums[fast] != val` 的元素，就把他赋值给 `nums[slow]`，然后 `slow` 右移。
- 最终 `slow` 的值就是剩下不等于 `val` 的元素的个数。

## 代码模版 (Python)

```python
class Solution:
    def removeElement(self, nums: list[int], val: int) -> int:
        slow = 0
        for fast in range(len(nums)):
            if nums[fast] != val:
                nums[slow] = nums[fast]
                slow += 1
        return slow
```

## 边界条件与易错点
1. **元素顺序可以改变**：题目说了不需要保持原顺序，其实上述写法也是一直覆盖过去，不会破坏原有不需要删除元素的相对顺序。如果要求尽量少修改数据结构，可以用双向指针把最后面的元素换过来覆盖要删除的，但上面的写法已经足够 O(N) 一次遍历。
2. **数组只有自己要删除的元素**：例如 `nums = [2,2,2], val=2`。`slow` 根本不会移动，返回 0，没有任何赋值，完全正常工作。
