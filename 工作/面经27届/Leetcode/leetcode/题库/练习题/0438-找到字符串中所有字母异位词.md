# 438. 找到字符串中所有字母异位词

**难度**：Medium | **分类**：滑动窗口 | **LeetCode**：[在线练习](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

## 题目描述

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的异位词的子串，返回这些子串的起始索引。

异位词指由相同字母重排列形成的字符串。

#### 示例

```
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
```

```
输入：s = "abab", p = "ab"
输出：[0,1,2]
```

#### 提示

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写英文字母
