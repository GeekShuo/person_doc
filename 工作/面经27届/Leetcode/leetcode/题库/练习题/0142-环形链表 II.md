# 142. 环形链表 II

**难度**：Medium | **分类**：链表、双指针 | **LeetCode**：[在线练习](https://leetcode.cn/problems/linked-list-cycle-ii/)

## 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

不允许修改链表。

**说明：**本题需要构造带环链表并返回某个节点对象。当前 Playground 的单函数测试模型不适合可靠验证该题，因此本地只提供题面与模板，不提供自动测试用例。

#### 示例

```
输入：head = [3,2,0,-4], pos = 1
输出：索引 1 对应的节点（值为 2）
```

```
输入：head = [1,2], pos = 0
输出：索引 0 对应的节点（值为 1）
```

```
输入：head = [1], pos = -1
输出：null
```

#### 提示

- 链表中节点的数目范围在 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效索引
