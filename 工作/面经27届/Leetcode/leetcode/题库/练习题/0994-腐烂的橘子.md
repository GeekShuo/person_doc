# 994. 腐烂的橘子

**难度**：Medium | **分类**：graph | **LeetCode**：[在线练习](https://leetcode.cn/problems/rotting-oranges/)

## 题目描述

给定 `m x n` 网格：

- `0` 空格子
- `1` 新鲜橘子
- `2` 腐烂橘子

每分钟，腐烂橘子会使上下左右相邻的新鲜橘子腐烂。返回所有橘子腐烂所需的最小分钟数；若不可能则返回 `-1`。

#### 示例

```
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4

输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1

输入：grid = [[0,2]]
输出：0
```
