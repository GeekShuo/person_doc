# 76. 最小覆盖子串

**难度**：Hard | **分类**：滑动窗口 | **LeetCode**：[在线练习](https://leetcode.cn/problems/minimum-window-substring/)

## 题目描述

给你一个字符串 `s` 和一个字符串 `t`。返回 `s` 中涵盖 `t` 所有字符的最小子串。如果不存在，返回空字符串 `""`。

#### 示例

```
输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
```

```
输入：s = "a", t = "a"
输出："a"
```

```
输入：s = "a", t = "aa"
输出：""
```

#### 提示

- `1 <= s.length, t.length <= 10^5`
- `s` 和 `t` 由英文字母组成
