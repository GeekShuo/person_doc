# 189. 轮转数组

**难度**：Medium | **分类**：数组、双指针 | **LeetCode**：[在线练习](https://leetcode.cn/problems/rotate-array/)

## 题目描述

给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。

请**原地**修改数组；本站测试会读取修改后的 `nums`，无需返回值。

#### 示例

```
输入：nums = [1,2,3,4,5,6,7], k = 3
输出：[5,6,7,1,2,3,4]
```

```
输入：nums = [-1,-100,3,99], k = 2
输出：[3,99,-1,-100]
```

#### 提示

- 1 <= nums.length <= 105
- 0 <= k <= 105
- 尝试使用空间复杂度为 `O(1)` 的原地算法。
