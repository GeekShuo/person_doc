# 45. 跳跃游戏 II

**难度**：Medium | **分类**：贪心、数组 | **LeetCode**：[在线练习](https://leetcode.cn/problems/jump-game-ii/)

## 题目描述

给定一个长度为 `n` 的 0 索引整数数组 `nums`。你最初位于 `nums[0]`。

数组中的每个元素 `nums[i]` 表示你在位置 `i` 最多可以向前跳跃的步数。

返回到达 `nums[n - 1]` 的最少跳跃次数。题目保证可以到达终点。

#### 示例

```
输入：nums = [2,3,1,1,4]
输出：2
```

```
输入：nums = [2,3,0,1,4]
输出：2
```

#### 提示

- 1 <= nums.length <= 104
- 0 <= nums[i] <= 1000
