## 题目描述

#### 示例

```
输入：grid = [[0,0,1,0],[1,1,1,0],[0,1,0,0]]
输出：5
```

```
输入：grid = [[0,0,0,0]]
输出：0
```

#### 提示

- `1 <= m, n <= 50`
- `grid[i][j]` 为 `0` 或 `1`
