# 139. 单词拆分

**难度**：Medium | **分类**：dp | **LeetCode**：[在线练习](https://leetcode.cn/problems/word-break/)

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict`，判断 `s` 是否可以由 `wordDict` 中的单词拼接出来。

注意：可以重复使用字典中的单词。

#### 示例

```
s = "leetcode", wordDict = ["leet","code"]
输出: true
```

```
s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
```
