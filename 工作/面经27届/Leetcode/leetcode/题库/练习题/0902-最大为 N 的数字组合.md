# 902. 最大为 N 的数字组合

**难度**：Hard | **分类**：动态规划、数位 DP | **LeetCode**：[在线练习](https://leetcode.cn/problems/numbers-at-most-n-given-digit-set/)

## 题目描述

给定一个按非递减顺序排列且元素互不相同的数字字符数组 `digits`，你可以使用其中任意次数的数字组成正整数。

返回可以生成的小于或等于整数 `n` 的正整数个数。

#### 示例

```
输入：digits = ["1","3","5","7"], n = 100
输出：20
```

```
输入：digits = ["1","4","9"], n = 1000000000
输出：29523
```

```
输入：digits = ["7"], n = 8
输出：1
```

#### 提示

- `1 <= digits.length <= 9`
- `digits[i]` 是从 `'1'` 到 `'9'` 的数字字符
- `digits` 中的所有值互不相同，并按非递减顺序排列
- `1 <= n <= 109`
