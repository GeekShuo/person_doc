# [189] 轮转数组 (Rotate Array)

## 题目描述
给定一个整数数组 `nums`，将数组中的元素向右轮转 `k` 个位置，其中 `k` 是非负数。
**进阶**：
- 尽可能想出更多的解决方案，至少有 三种 不同的方法可以解决这个问题。
- 你可以使用空间复杂度为 `O(1)` 的 **原地** 算法解决这个问题吗？

## 解题思路
- **数组翻转法 (最优解O(1)空间)**：这非常像旋转字符串。向右轮转 `k` 个位置，等价于把数组后面的 `k` 个元素放到前面来。
- 我们只需要进行三次翻转操作即可原地实现：
  1. 翻转**整个数组**。
  2. 翻转**前 `k` 个**元素（此时前 `k` 个元素的相对顺序恢复正常）。
  3. 翻转**其余 `n-k` 个**元素（此时它们的相对顺序也恢复正常）。
- 注意：如果 `k > len(nums)`，轮转会导致循环周期，实际有效轮转次数为 `k % len(nums)`。

## 代码模版 (Python)

```python
class Solution:
    def rotate(self, nums: list[int], k: int) -> None:
        """
        Do not return anything, modify nums in-place instead.
        """
        n = len(nums)
        k = k % n  # 处理 k 大于数组长度的情况
        
        if k == 0:
            return
            
        # 辅助函数：翻转指定区间 [left, right]
        def reverse(left: int, right: int) -> None:
            while left < right:
                nums[left], nums[right] = nums[right], nums[left]
                left += 1
                right -= 1
                
        # 1. 翻转整个数组
        reverse(0, n - 1)
        # 2. 翻转前 k 个元素
        reverse(0, k - 1)
        # 3. 翻转剩下的 n-k 个元素
        reverse(k, n - 1)
```

## 边界条件与易错点
1. **`k` 大于数组长度**：如果 `nums` 长为 3，让你向右轮转 4 个位置，实际上等同于轮转了 1 个位置，所以必须要执行取模 `k %= n`。
2. **Python 切片陷阱**：如果不要求 O(1) 空间，Python 非常喜欢写 `nums[:] = nums[-k:] + nums[:-k]` 完成。但面试时考官通常要求“不用额外空间”，因此必须掌握三次翻转法。注意：不能直接 `nums = ...`，修改的必须是 `nums[:]` 才算修改原地址对象。
3. **空数组或只有一个元素**：`k % n` 时，如果 `n=0` 会发生除以零异常（这题说明数组至少有一个元素，所以没事）。
