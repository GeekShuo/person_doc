# [2] 两数相加 (Add Two Numbers)

## 题目描述
给你两个 非空 的链表，表示两个非负的整数。它们每位数字都是按照 逆序 的方式存储的，并且每个节点只能存储 一位 数字。
请你将两个数相加，并以相同形式返回一个表示和的链表。
你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

## 解题思路
- **模拟相加**：同时遍历两个链表，逐位计算它们的和，并与当前位置的进位值相加。
- 如果两个链表的长度不同，则可以认为长度短的链表的后面有若干个 0。
- 此外，如果链表遍历结束后，有 `carry > 0`，还需要在返回的链表尾部附加一个值为 `carry` 的节点。

## 代码模版 (Python)

```python
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next

class Solution:
    def addTwoNumbers(self, l1: Optional['ListNode'], l2: Optional['ListNode']) -> Optional['ListNode']:
        dummy = ListNode(0)
        curr = dummy
        carry = 0
        
        while l1 or l2 or carry:
            val1 = l1.val if l1 else 0
            val2 = l2.val if l2 else 0
            
            # 计算总和与进位
            total = val1 + val2 + carry
            carry = total // 10
            
            # 创建新节点存入余数
            curr.next = ListNode(total % 10)
            curr = curr.next
            
            if l1: l1 = l1.next
            if l2: l2 = l2.next
            
        return dummy.next
```

## 边界条件与易错点
1. **两个链表长度不一致**：当一个链表遍历完而另一个没完时，需要用 0 补齐空缺的位置。
2. **最后的进位**：遍历完两个链表后，如果最高位仍有进位（如 `99 + 1 = 100`，会多出一位），千万别忘了在末尾再加一个节点存储这个进位。
3. **虚拟头节点（Dummy Node）**：对于链表题目，使用 `dummy` 头节点可以极大方便返回结果且不用对头节点做特殊判断。
