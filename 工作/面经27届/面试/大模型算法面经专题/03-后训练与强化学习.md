# 后训练与强化学习面试专题

## 一、完整链路

```text
数据治理
→ SFT
→ 偏好数据 / Reward Model / Verifier
→ DPO 或在线 RL（PPO/GRPO 等）
→ 拒绝采样与迭代训练
→ 能力、偏好、安全、成本联合评测
```

## 二、SFT

### 必答问题

- SFT 仍是 next-token 交叉熵，为什么通常 mask prompt，只训练 assistant token？
- 多轮对话是只训最后一轮，还是所有 assistant 轮？EOT/EOS 如何处理？
- 全参微调、LoRA、QLoRA 如何取舍？
- 数据质量、数量、多样性和配比如何权衡？
- 如何避免灾难性遗忘、训练集污染与风格单一？

### 数据工程

需要能讲清精确哈希、MinHash/LSH、Embedding 去重、格式校验、事实检查、困难样本、能力配比与 benchmark 污染检测。面试官通常更关心“错误数据如何被发现并闭环”，而不是只问数据量。

## 三、Reward Model 与偏好数据

Reward Model 常使用同一 prompt 下的 chosen/rejected 对，学习相对排序：

\[
\mathcal L_{RM}=-\log\sigma(r(x,y_w)-r(x,y_l))
\]

高频追问：

- 为什么 RM 的绝对分数没有独立语义？
- Best-vs-worst 为什么不够，如何构造困难 pair？
- RM 如何做 pairwise accuracy、排序相关性、校准与 OOD 泛化评测？
- Reward Hacking、长度偏好、风格偏好和 Judge 偏差如何识别？
- Process Reward 与 Outcome Reward 如何取舍？

## 四、PPO、DPO、GRPO

### PPO

必须区分：

- `policy / old policy`：计算概率比和 clipped objective；
- `reference policy`：通过 KL 约束限制策略漂移；
- `Reward Model`：给完整回复质量分；
- `Critic`：估计前缀未来回报，用于 advantage。

常见稳定性手段：Reward/Advantage Normalization、Gradient/Value Clipping、自适应 KL、熵监控、长度监控、独立评测和早停。

### DPO

核心目标是直接提高 chosen 相对 rejected 的隐式奖励，不训练显式 RM/Critic。要会说明：

- 优点：离线、稳定、工程成本低；
- 局限：受偏好数据覆盖限制，缺少在线探索；
- Reference Model 的锚定作用；
- IPO、KTO、SimPO、ORPO 的动机，不必只背公式。

### GRPO

对同一 prompt 采样一组回答，以组内奖励均值和方差构造相对 advantage：

\[
A_i=\frac{r_i-\operatorname{mean}(r)}{\operatorname{std}(r)+\epsilon}
\]

与 PPO 相比不需要独立 Critic，但 rollout 更贵；当组内 reward 全相同、组太小或奖励稀疏时容易退化。面试还会延伸到 DAPO、GSPO、RLVR、异步 rollout 与 policy lag。

## 五、推理模型与 Agentic RL

- R1-Zero：Base Model + 可验证奖励 + GRPO，观察长链推理、自检与纠错。
- R1：Cold-start SFT → Reasoning RL → 拒绝采样 → 通用 SFT/RL。
- PRM 对过程打分，信用分配更细但标注昂贵；ORM 只看最终结果，成本低但反馈稀疏。
- 数学答案、代码测试和格式验证属于可验证奖励，但验证器不完整时仍会被 Reward Hacking。
- 多轮 Agent 需处理轨迹奖励、工具成本、无效步骤、长程信用分配、User Simulator 和环境非平稳性。

## 六、2026 面试趋势

小红书和知乎样本反复出现：

- “几个 O”只是起点，重点转向为什么改、改了什么、牺牲了什么；
- 高频工程问题包括熵坍缩/爆炸、Reward Hacking、Rollout 成本、数据合成与质检；
- 单纯“魔改 GRPO”区分度下降，后训练与 Agent、Harness、评测结合更加重要；
- 面试会要求把公式映射到代码张量和训练框架，而不是只口述论文。

## 七、必答清单

1. SFT loss 与 prompt masking。
2. RM 与 Bradley–Terry loss。
3. PPO 的 policy/value/entropy/KL 四部分。
4. PPO 中 old policy 与 reference policy 的区别。
5. DPO 推导直觉、Reference Model 和长度偏差。
6. PPO、DPO、GRPO 的适用条件和失败模式。
7. GRPO 组内 advantage、组大小和 rollout 成本。
8. Reward Hacking、熵坍缩、模式坍塌如何监控。
9. PRM、ORM、规则奖励和 LLM-as-Judge 如何组合。
10. Agent 多轮轨迹如何做 credit assignment。
11. Policy lag 与异步 rollout 如何影响稳定性。
12. 如何设计离线、真人和 A/B Test 三层评测。
