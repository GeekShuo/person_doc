# 真实面经与 27 届趋势

## 一、27 届面试发生了什么变化

从 2026 年公开面经看，考察重点已从“会背 Transformer、会调 API”转向完整闭环：

1. **项目真实性**：数据从哪里来、规模多大、为什么选这个模型、失败过什么、个人贡献是什么。
2. **训练与评测闭环**：不只问 loss，还问数据清洗、奖励设计、离线评测、线上指标、Bad Case 和回滚。
3. **算法与系统并重**：后训练岗位会追问 rollout、并行训练和显存；Agent 岗会追问上下文、沙箱、权限、超时和成本。
4. **模型模块手撕**：MHA、RoPE、RMSNorm、GQA、KV Cache 与常规 LeetCode 并存。
5. **Agentic RL 上升**：重点从单轮偏好对齐扩展到多轮轨迹、环境反馈、过程奖励和信用分配。

## 三、跨方向高频问题

### 项目答辩

- 你的核心贡献如何用代码、实验和决策证明？
- 数据规模、许可、去重、污染和 train/val/test 划分如何处理？
- Baseline 为什么这样选？最小消融实验是什么？
- 指标提升是否显著？失败实验和最大 Bad Case 是什么？
- 如果重做一次，数据、模型和评测分别会改什么？
- 上线后的 P95 延迟、吞吐、单位成本、安全与 fallback 如何设计？

### 基础与模型结构

- Attention 为什么除以 \(\sqrt{d_k}\)？Mask 在哪里加？
- MHA、MQA、GQA、MLA 的质量、显存和吞吐取舍。
- RoPE 如何工作，长度外推有哪些问题？
- RMSNorm 与 LayerNorm 的差异。
- LoRA 为什么低秩有效？rank 与 alpha 如何选择？
- MoE 路由、负载均衡、专家并行和 all-to-all。

### 手撕

- 常规：滑窗、树/图、DFS/BFS、堆、链表、动态规划。
- 模型模块：stable softmax、MHA、RoPE、RMSNorm、GQA、SFT/DPO loss、top-k/top-p。
- 工程题：RAG 伪代码、批处理推理、缓存、限流、工具超时恢复。

## 四、准备策略

建议采用“一主一副”：

- 多模态主线 + 后训练副线；
- 后训练主线 + 训练系统副线；
- Agent 主线 + RL/评测副线；
- 推理优化主线 + 模型结构副线。

每条主线至少准备：1 个可演示项目、1 张系统架构图、1 份实验表、3 个 Bad Case、2 个失败方案和 1 套离线评测集。

牛客第一人称、岗位和轮次明确的记录优先；小红书用于发现近期考点和招聘趋势；知乎、公众号及汇总文章用于补全知识结构。来源之间冲突时，以官方论文/代码和本人实际实验为准。
