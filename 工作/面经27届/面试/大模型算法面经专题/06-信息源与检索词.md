# 信息源、证据等级与检索词

## 一、信息源优先级

### A 级：官方与原始材料

用于确认岗位要求和技术事实，不用于推断真实面试题。

- 公司官方招聘/JD：字节 Seed、DeepSeek、腾讯混元、百度、智谱、美团 LongCat、上海 AI Lab。
- 原始论文与技术报告：arXiv、OpenReview、ACL Anthology、Papers with Code、Hugging Face Papers。
- 官方代码和文档：模型/训练框架的 GitHub、vLLM、SGLang、DeepSpeed、Megatron-LM、verl 等。

### B 级：一手面经

优先选择作者第一人称、公司/岗位/轮次/日期明确的内容。

- [牛客](https://www.nowcoder.com/)：最适合核验公司、岗位、轮次和发布时间。
- 小红书：时效性高，适合发现新岗位与近期问法，但图片题需核验，营销内容较多。
- 知乎：长文复盘和技术解释较完整，注意区分原帖与搬运汇总。
- 脉脉：适合发现组织变化和岗位需求，技术题细节通常较少。

### C 级：专题知识库与汇总

适合建立复习框架，不直接视为真实原卷。

- [2025—2026 国内大模型算法岗招聘、面经与笔试汇总](https://keepkeen.github.io/blog/llm-recruit-interview-roundup/)
- [Awesome LLM Interview](https://github.com/laoshan-song/Awesome-LLM-Interview)
- [LLM/MLLM 后训练面试题库](https://liyongzhi.xyz/blog-post-llm-mllm-posttrain-interview/)
- [VLM 算法知识与面经汇总](https://stein-wang0226.github.io/mllm-interview-notes/vlm-knowledge-interview.html)
- [代码随想录/卡码大模型面经](https://programmercarl.com/qita/0022.llminterview.html)
- [FAQ Of LLM Interview](https://github.com/aceliuchanghong/FAQ_Of_LLM_Interview)
- [LLM Interview Questions](https://github.com/llmgenai/LLMInterviewQuestions)

### D 级：视频与公众号

适合补充口述解释和行业趋势，重要结论需回查论文或官方代码。

- B站：搜索论文解读、框架源码、面试复盘、手撕模型模块。
- 微信公众号：机器之心、PaperWeekly、量子位、InfoQ、OneFlow、各公司技术团队。
- YouTube：Full Stack Deep Learning、Hugging Face、Stanford CS25、DeepLearningAI、官方技术演讲。

## 三、筛选规则

1. 记录标题、作者、平台、日期、岗位、轮次和原始 URL。
2. 同一内容被多平台转载时保留最早或最接近一手的来源。
3. 明确区分“候选人亲历”“题库整理”“课程广告”“岗位 JD”“论文观点”。
4. 面试题只归纳问法，不宣称是公司统一原卷。
5. 公式、模型版本和性能数据回查论文/官方代码。
6. 过期或带临时 token 的链接保留稳定页面 ID，并记录采集日期。
7. 每月复查一次最近 30–60 天内容，按公司和方向去重。

## 五、更新建议

每次增量采集以“小红书 + 牛客”为面经主源，以“GitHub + 官方论文/JD”为技术校验源，再用知乎/B站/公众号补充解释。推荐按周搜索：`公司名 + 方向 + 面经 + 一面/二面 + 当前月份`，按月更新本专题的来源索引和高频题矩阵。
