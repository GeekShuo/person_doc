### G34｜决策树、随机森林、GBDT 和 XGBoost 有什么区别？

**场次**：本轮补充的题目／回答素材，尚未标出具体面试场次；不能追记到某一场真实面试。

**我的回答（原始草稿）**：决策树就是一连串“如果……那么……”的判断，最后根据走到的叶子节点给出预测。随机森林训练很多棵树，每棵树用的数据和能看的特征不完全一样，最后让它们投票或取平均；树之间基本互不依赖，可以同时训练。GBDT 也是很多棵树，但它们一棵接一棵训练：先训练一棵，再看它预测得不好的地方，后面的树补前面留下的误差。简单说，随机森林是“大家各自预测，最后投票”；GBDT 是“前一棵先预测，后一棵接着改进”。

**更好回答**：

| 方法 | 核心思路 | 树之间的关系 | 常见优缺点 |
|---|---|---|---|
| 决策树 | 按特征阈值递归划分，叶子输出类别或数值 | 单棵树 | 可解释、能表达非线性；深树容易过拟合、方差较大 |
| 随机森林 | Bagging：对样本做 bootstrap 抽样，并在候选分裂时随机选特征子集，训练多棵树后聚合 | 树主要独立，可并行训练 | 通过平均降低方差，通常稳健；模型较大，解释性弱于单树 |
| GBDT | Boosting：逐轮添加树，让新树拟合当前损失的负梯度（平方误差时与残差相关），逐步降低整体损失 | 轮次有先后依赖 | 能逐步修正误差、表达能力强；需控制树深、学习率和轮数，容易过拟合，训练轮次不易并行 |
| XGBoost | GBDT 的一种高效正则化实现；树模型每轮近似优化损失的二阶展开，并用正则项控制叶子数和叶权重 | 与 GBDT 一样按 boosting 轮次迭代 | 提供 shrinkage、行／列采样、缺失值默认分支与多种分裂算法；效果和速度仍依赖数据、参数和实现配置 |

原始说法方向正确，但“后面的树补误差”可再精确一些：一般损失下，GBDT 拟合的是损失函数对当前预测的**负梯度**，不总是原始标签减预测值这样的残差。平方损失时负梯度才与残差成比例。树的构建可并行部分工作（如候选分裂统计），但 boosting 的下一轮依赖前一轮预测结果，不能把各轮像随机森林的树那样独立训练。

XGBoost 并不是与 GBDT 并列的完全不同原理；在这里比较的树模型用法中，它属于梯度提升树方法的一种实现。其典型目标是损失的一阶梯度与二阶 Hessian 近似，加上树复杂度正则化；分裂收益由这些梯度统计量计算。实际 XGBoost 的树方法可以是 exact、approx 或 hist 等，不能笼统承诺使用二阶信息就一定比其他 GBDT 更准或更快。[XGBoost：Boosted Trees](https://xgboost.readthedocs.io/en/stable/tutorials/model.html)、[XGBoost 参数与树构建方法](https://xgboost.readthedocs.io/en/stable/parameter.html)

**面试短答**：决策树是一棵树做判断；随机森林通过样本和特征随机化训练许多相对独立的树，最后投票或平均，主要降低方差；GBDT 顺序加树，每轮按损失梯度修正当前模型；XGBoost 是 GBDT 的工程化实现之一，典型特点是二阶损失近似、树复杂度正则化和高效分裂算法。做业务选型时我会在同一数据切分下比较验证集指标、校准、训练／推理耗时与模型复杂度，不预设某一种必胜。


## G35 ｜归一化和标准化的区别

归一化	标准化
依据	极值 min / max	均值 μ / 标准差 σ
输出范围	固定 [0,1]	无固定界
对异常值	极敏感（一个离群点会把其余数据全挤到一起）	较稳健（异常值仍会拉大 σ，但影响小得多）
数据要求	需知道明确的边界	不要求有界
新数据	超出原 min/max 会溢出 [0,1]，需重新拟合	可直接套用训练集 μ、σ
什么时候用哪个
优先标准化（默认选择）：

数据近似正态、或存在异常值
涉及距离/梯度的算法：SVM、KNN、K-Means、PCA、逻辑回归、神经网络
树模型（决策树、RF、XGBoost）两者都不需要，因为分裂只看排序
优先归一化：

数据分布有明确边界且不含异常值
图像处理（像素 0–255 → 0–1）
神经网络输入要求固定区间
稀疏数据（文本 TF-IDF、词向量），标准化会破坏稀疏性（减去均值后 0 变非 0）
