━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

对每行OCR结果，置信度 < 80% 的算"不可辨"。
权重 = 0.7 * 字数 + 0.3 * (文本框面积/图片面积 * 1000)
字数为主（70%），面积为辅（30%）。

unreadable_ratio = sum(weight where 行置信度 < 80%) / sum(all weights)

分档：
- ratio >= 90% 或 平均置信度 < 60 → 等级5（完全无法辨认）
- ratio >= 50% 或 平均置信度 < 75 → 等级4（大部分模糊）
- ratio >= 10% → 等级3（局部模糊）

漏检补偿（OCR未检出文字）
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

问题：模糊文字太糊时OCR检测器直接跳过，不产生文本框，导致不可辨比例偏低。

方法：
1. 用Otsu二值化+轻膨胀提取文字像素区域
2. 用QRCodeDetector检测并移除二维码区域
3. 对连通区域过滤：排除密度>0.90的实心块（背景/图标），只保留文字状区域
4. 计算OCR文本框外的文字像素占比 = undetected_ratio
3. 清晰图片的基线undetected_ratio约0.43（含边框、印章、logo等非文字暗区）
4. 如果undetected_ratio超出基线，说明有文字被漏检：
   - excess = undetected_ratio - 0.43
   - excess > 0.15 → 等级+1
   - excess > 0.30 → 等级+2

最终等级 = base_level + boost（上限5）

已知问题
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━



1. 模糊文字漏检：当文本区域太糊时，OCR检测器直接跳过该区域，不产生文本框。导致不可辨比例反而偏低（分母减小），本该是等级3-4的被误判为等级1-2。极端情况下完全模糊的图片OCR检测到0行被判等级5（正确），但"大部分模糊"的图片只检出少数能认的行，被判等级1-2（错误）。

2. 印章文字干扰：印章内弯曲排列的文字OCR置信度天然偏低，不是因为图片模糊。已通过红色像素检测排除，但边缘情况（框只覆盖印章一小部分）可能遗漏。

3. XGB blur_score双峰分布：原始XGBoost二分类的blur_score集中在0-1和90-99两个区间，中间区间数据极少，不适合直接切分5档阈值。

1. 不要说“这段没怎么用模型”
应当说：

这段工作的特点不是追求模型规模，而是在高准确率、低延迟和可解释性约束下，组合轻量模型、传统视觉算法和确定性规则，解决线上文档审核问题。

错误需要可定位；

2. 最有价值的算法故事：类别不均衡
你的原始指标看起来有 98.6%，但换一个目标类别后 Precision 只有 30%左右。这是非常典型的类别不均衡问题。

面试时可以说：

最初整体准确率达到 98.6%，但通过分析混淆矩阵，我发现评测集中的正负样本严重不均衡，Accuracy 掩盖了稀缺类别效果。当业务目标切换到识别另一类别时，Precision 只有约30%。因此我没有继续围绕 Accuracy 调参，而是补充困难样本，重建 1,152 张评测集，并使用 Precision、Recall、PR 曲线及覆盖率重新评估方案。

这句话能体现你理解指标，而不是机械调模型。

3. 为什么引入 unsure
推荐回答：

线上系统并不一定要强制模型对所有样本做二分类。对于高风险业务，模型可以只自动处理高置信样本，把决策边界附近的数据标记为 unsure，交给人工或更高成本模型。这相当于选择性分类，优化目标从单一准确率变为“自动处理覆盖率和自动决策准确率之间的平衡”。

高置信子集 Precision 达到 100%，并不代表全部样本准确率达到 100%，而是在牺牲一定 Coverage 后保证自动决策的可靠性。

这点一定要主动说，否则面试官会质疑“100%”不可信。

4. 为什么使用小模型融合
三个模型分别对版面区域、细粒度对象和专用目标更敏感，错误模式并不完全一致。通过阈值扫描和信号融合，可以利用模型之间的互补性。相比直接上大模型，这种方案吞吐更高、成本更低，而且每个失败样本都能追溯到具体信号和阈值。

5. 文档分类为什么可以达到 99.9%
不要说是“训练了一个准确率 99.9% 的模型”，因为你的主要贡献是链路优化。

正确说法：

文档类别本身与标题、版面和方向等强特征高度相关，因此没有必要完全依赖端到端大模型。我使用 OCR 抽取标题，通过白名单做稳定匹配，再用 Layout 和方向检测处理特殊版式，同时修正评测集中的错误标签，最终在约 6,000 条数据上达到 99.9% 准确率。
