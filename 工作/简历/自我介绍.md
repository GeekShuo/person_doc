### 腾讯
**（背景）**腾讯这段我独立负责的是法院、公安传过来的查询和冻结文件，里面有模糊的、没盖章的、类型不合规的、电话号码脏的，日均大概 40 万条。约束是快、便宜、不能有幻觉、不能误拦。

**（问题）**我先讲最有代表性的一个：文书清晰度。原来是一个 569 维特征的 XGBoost 二分类，只输出清晰或模糊两档。它的问题不是说不准，而是**两档本身不够用**：第一，它的分数不符合真实数据的分布；第二，颗粒度太粗，业务没法自己选松紧尺度；第三，卡在边界上的样本特别容易误判。

我去翻了数据分布，发现这个分数是**双峰**的——清晰样本全挤在 0.05 到 1，模糊样本挤在 90 到 99，中间几乎是空的，而且分数跟人眼看到的模糊程度并不单调。

**（关键判断）**所以我当时的判断是：**这不是阈值或概率校准的问题，是任务定义的问题**。二分类损失只要求模型学"清晰和模糊的边界"，没要求它学"同一类里谁更严重"。你再怎么做 Platt Scaling、Isotonic Regression，也只是重新映射已有信息，变不出中间三档的序数结构。所以我就没继续调阈值了，回去重定义任务。

**（为什么是五档）**这里要说清楚：**训练我做的是五分类，但业务最终落地的判定还是"拒绝 / 不拒绝"两类。** 做五档不是为了多输出几档给业务看，而是因为只有把中间这段灰度显性建模出来，业务才能按自己的风险偏好选切分点——今天想严一点就切在 3，想松一点就切在 4，不用我重新训模型。同时档位之间有明确的序关系，边界样本的误判也少了很多。

**（怎么做的）**我把清晰度拆成两个维度：一个是**不可辨文字比例**，决定严重的三档；一个是**可辨区域的锐度**，区分最好的两档。这样能分开两种本质不同的情况——一种是全文轻微发虚但都读得出来，另一种是整体看着还行、但关键信息已经彻底糊了。这两种在业务上完全不是一回事。

数据上我用 OCR 行置信度、文本框面积、拉普拉斯锐度，加上排除红章，做规则预标注，然后自己写了个可视化标注平台做人工复核，拿到 1.3 万张确认图。

这里有个细节：**规则预标注在小字、小众字体、手写体上不准**，所以我用评分的均值和方差去拟合质量分布，构造了五维软标签。原因是 2 档和 3 档之间本来就模糊，用 one-hot 会把相邻档位的轻微分歧当成完全错误。

模型用 Qwen3.5-9B 做 LoRA SFT，把输出限制在五个等级 token 上，closed-set softmax 出分布，CE + KL 联合训练，推理时取概率期望做校准。最后落回业务的时候，取后两档判为模糊、走拒绝，其余通过，所以出口还是两类。当前后两档占比 3.57%，抽检 Precision 100%，零误拦。

在京东零售 AIGC 团队，我主要做商品图训练数据、OCR 选型部署，以及服饰和家居扩图 Benchmark。目前在腾讯，我负责文书有效性校验，重点做清晰度建模、印章识别和文书类型判断。

这些经历让我对数据、训练和业务决策之间的关系有比较完整的理解。我希望继续深入多模态模型训练，并用可靠的评测推动模型迭代。

## 5. 行为问题与回答素材

**网安背景为什么做算法？**

安全问题经常涉及风险判断、对抗样本和错误代价，和多模态审核有直接联系。我在实习中从数据与模型训练开始，逐渐把关注点放到模型如何形成可靠决策。后续希望继续在多模态算法方向积累。若谈到其他安全 Agent 项目，只补自己能具体展开的模块。

**三段实习的关系？**

京东安全侧重领域数据和模型后训练，京东零售让我更系统地做质量标准与生成评测，腾讯则让我把这些方法用于错误代价敏感的识别系统。共同主线是任务定义、数据质量和可验证决策。

**最大的挑战？**

从腾讯举例：业务希望少误拦且多识别，但“模糊”和“有效”的边界并不天然一致。我先把模棱两可的业务标准拆成可标注可定位的原子指标，再构建数据、模型和复核链路。可以展开某个真实失败样本与规则变更，不必额外添加没有记录的效率提升数字。

**最大的不足？**

目前部分项目有最终评测，但实验归因不完整。例如 Guard 没有系统比较 SFT、难例继续 SFT 与 RL，因此不能把最终结果直接归因给某个算法。后续我会优先固定数据与评测，把关键变量的对照补齐。

**讲一次失败或反思。**

按“初始假设 → 观察到的失败 → 新解释 → 调整措施 → 仍未解决的问题”组织。腾讯可以讲二分类分数无法直接表达细分质量等级，或者 OCR 漏检严重模糊文字导致质量被高估。只有确认过日志后再使用具体 loss 和 step。

**为什么录用你？**

我既参与过多模态模型训练，也做过数据标准、评测和部署，能从错误样本出发定位问题属于数据、模型还是决策规则，并把解决过程落到可复用的链路上。

**我的回答**：复盘提到三类素材：腾讯项目临近截止日期效果未达标，重新审视任务和方案；AI 安全部政务新闻推送中主动协调数据来源和业务标准；从亲自使用生图工具出发学习生成模型。覆盖部门／人数和效果数字未在此单独核验。

**更好回答**：每题只讲一个事件，用“目标与约束—我作出的判断—亲自采取的行动—可核验结果—下次改进”组织。压力题重点解释为什么原方案无效、如何缩小问题与安排优先级；主动承担题讲如何确定新闻价值标准、协调数据接口并交付；学习题讲怎样把原理用于实际数据或评测问题。没有记录的结果数字就省略，结尾给具体反思，例如提前建立标签一致性样本，避免只说“第一性原理”或“形成闭环”。
