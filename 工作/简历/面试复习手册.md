## 一、项目亮点速记（带口径提醒）

### 1. 腾讯 CDG · 图文有效性校验（独立负责，2026.6-至今）
- **整体链路**：输入标准化 + 质量门控 → OCR/版面分析/目标检测多源信号 → 后校验输出高置信结论；整体拦截率 **4.33% → 9.84%**，日均拦截 **38,198** 条无效查询。
- **文书清晰度五级评估（新增）**：旧版 569 维 XGBoost 二分类呈双峰、无法表达模糊序关系 → 重定义为"不可辨文字比例 + 可辨区域锐度"二维序数五分类；融合 OCR 行置信度/面积、拉普拉斯锐度、排除红章规则预标注 + 自研可视化平台人工复核；以均值方差拟合构造五维软标签，基于 **Qwen3.5-9B 做 LoRA SFT**，CE + KL 联合训练 + 概率期望校准；五分类后两类判模糊占比 **3.57%**，**Precision 100%（零误拦）**。
- **无印章识别**：无章样本仅 2% + 浅色章漏检 → 融合三路版面/印章检测 + HSV 红色分割；**86 组阈值搜索 + 有/无/不确定三分类 + VLM 难例复核**；高置信子集 **P 100% / R 98.94%**，主链路 <100M、单图 <1s。⚠️ 必须限定"高置信子集"，非整体。
- **文书类型识别**：DBNet + LCNet 方向检测/全文 OCR/标题定位/白名单级联；阅读顺序恢复 + 同义词归一化 + 自适应模糊匹配；数万条人工标注独立测试集 **Accuracy 94.59% → 99.99%**，单条 0.28s。

### 2. 京东零售 · AIGC 基模组（数据/Benchmark/评测，2026.3-2026.5）
- **主图训练数据构建**：分辨率/清晰度规则 + PP-OCR + 文字贴片检测 + Qwen3-VL 美学评分 + 同品匹配多阶段清洗；产出 **27.6 万单图 / 14.7 万文本准确性样本 / 8.6 万 Real-Real Pair**，人工标注高质量产出率 **86%**。
- **OCR 评测与落地**：分层标注 + 人工 GT + 文本归一化 + exact/merge/split 匹配；横评 3 OCR + 5 VLM；选型 **Precision 95.05% / F1 95.21%**，推理成本降两个数量级；华为 910C 并行部署 + FastAPI，接入数十万级清洗链路。
- **生成模型评测体系**：方→长图扩图，14 项原子指标；内部模型可用率较 Nano Banana Pro / Seedream-5.0-lite 领先 **7.0 / 12.1 个百分点**（机评口径）。

### 3. 京东 CCO · AI 安全护栏（数据/SFT/RL/Agent，2025.9-2026.3）
- **多模态数据构建**：业务 + 开源 + 合成；Qwen3-VL-235B + 多模型投票 + 规则过滤；正负重采样训宽松/严格模型交叉标注降噪；关键词引导合成 + 对照增强；产出 **89 万条**高质量多模态 SFT，覆盖涉政/色情/暴力等数十类风险 + 多模态 CoT。⚠️ 分清个人流水线环节 vs 团队总盘。
- **后训练**：分布式全参数微调 Qwen3-VL 模型组；引入 **GDPO 多目标优化**，解耦风险拦截/误杀惩罚/格式遵循奖励并归一化，缓解奖励坍塌；高风险 **F1 > 85%** 同时**过度拒答率降 37%**。⚠️ 确认 F1 口径（二分类/Macro）。
- **Agent 落地**：合规数字人 0→1，调用超 3 万次；Hybrid Search + Re-ranking 缓解长尾幻觉；日爬 **300+ 政务源**推 150+ 部门/个人；Long-term Memory 向量化跨会话；DeepResearch 接小红书/知乎/bilibili 多模态解析。

## 二、8 条口径自查（面试护城河）

1. 印章 100% 是**高置信子集**，非整体模型准确率；R 从 10%→98.94% 三轮迭代。
2. 文书 99.99% 基于数万条人工标注独立测试集；说明类别均衡与测试集独立性。

## 三、技术难点清单

- **长尾少数类**：2% 无章样本让整体 Accuracy 失真 → 重构评测集 + 补充难例 + 分层指标。
- **多目标奖励坍塌**：GDPO 分奖励归一化再加权，避免量化学得好的目标主导。
- **过度拒答 vs 漏判**：误杀惩罚项 + 应拒/应放评测集平衡。
- **数据质量闭环**：级联漏斗 / 多模型投票 / 三轮难例回流，共性"构建→评测暴露→回流→迭代"。
- **轻量 + 分层**：高置信全自动、低置信走 VLM/人工；按业务代价分配算力。
- **指标口径严谨**：F1/子集/离线 vs 线上/抽检 vs 全量，每次写数字前先问"怎么算的、边界在哪"。

## 四、大模型基础八股（原理 + 项目映射）

- **SFT / 全参 vs LoRA**：数据质量 > 数量；LoRA 低秩分解（rank/alpha），全参容量高但显存大；你的安全护栏全参 SFT、文书清晰度用 LoRA SFT。
- **RLHF / DPO / GDPO**：PPO 需 RM+critic 成本高；DPO 隐式 RM；GDPO 解耦多奖励归一化抗坍塌。
- **RAG / Hybrid Search**：向量长尾失效 → 稠密+稀疏融合；重排解决"召回≠相关"；长上下文不替代 RAG（时效/溯源/成本/防幻觉）。
- **多模态对齐**：视觉编码器 → 投影层 → 与 LLM 拼接；浅色章在 CLIP 空间与无章近不可分 → 用 HSV 掩膜补特征。
- **Attention 效率**：MHA / MQA / GQA 的 KV-cache 差异；长序列瓶颈。

## 五、系统设计模块（白板题积木）

- **多模态内容审核系统**：接入 → 检测/识别（OCR+版面+印章）→ 多模态判别（VLM SFT+GDPO）→ 分层决策（高置信自动 / 低置信人工）→ 难例回流。
- **RAG 企业知识库**：解析切分 → 双索引 → 召回融合 → 重排 → 生成+引用 → 反馈回流。
- **数据生产流水线**：采集 → 级联过滤 → 质检（规则+投票+人工）→ 评测集 → 训练 → 回流。
- **设计要点**：分层阈值用 PR 曲线 + 业务代价矩阵；冷启动先用规则/zero-shot 打底；在线离线一致性用人工抽检校准；每个环节留指标埋点。
