## 题目描述

给定二叉树的根节点 `root` 和整数 `targetSum`，统计路径和等于 `targetSum` 的路径数。

路径必须向下（从父到子），但不要求从根开始，也不要求到叶子结束。

#### 示例

```
root = [10,5,-3,3,2,null,11,3,-2,null,1], targetSum = 8
输出: 3
```

#### 提示

- 节点数在合理范围内；节点值可能为负
- 输入以数组层序表示二叉树，`null` 表示空节点
