# 91. 解码方法

**难度**：Medium | **分类**：动态规划、字符串 | **LeetCode**：[在线练习](https://leetcode.cn/problems/decode-ways/solutions/)

## 题目描述

一条包含字母 `A-Z` 的消息通过以下映射进行了编码：`'A' -> "1"`, `'B' -> "2"`, ..., `'Z' -> "26"`。

给你一个只含数字的**非空**字符串 `s`，请计算并返回**解码**方法的总数。

#### 示例

```
输入：s = "12"
输出：2
解释：它可以解码为 "AB"（1 2）或者 "L"（12）
```

```
输入：s = "226"
输出：3
解释："BZ"（2 26）、"VF"（22 6）、"BBF"（2 2 6）
```

```
输入：s = "06"
输出：0
解释："06" 无法映射到 "F"，因为有前导零
```

#### 提示

- 1 <= s.length <= 100
- s 只包含数字，可能包含前导零
