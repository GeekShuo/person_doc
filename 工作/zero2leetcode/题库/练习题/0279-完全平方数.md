# 279. 完全平方数

## 题目描述

给你一个整数 `n`，返回和为 `n` 的完全平方数的最少数量。

完全平方数是一个整数的平方，例如 `1, 4, 9, 16 ...`。

#### 示例

```
n = 12
输出: 3
解释: 12 = 4 + 4 + 4
```

```
n = 13
输出: 2
解释: 13 = 4 + 9
```
