## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的回文子串，并返回该子串。

**回文串** 是正着读和反着读都一样的字符串。

#### 示例

```
输入：s = "cbbd"
输出："bb"
```

```
输入：s = "aaaa"
输出："aaaa"
```

#### 提示

- 1 <= s.length <= 1000
- s 仅由数字和英文字母组成
