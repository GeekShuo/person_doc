# 1423. 可获得的最大点数

**难度**：Medium | **分类**：滑动窗口、数组 | **LeetCode**：[在线练习](https://leetcode.cn/problems/maximum-points-you-can-obtain-from-cards/solutions/)

## 题目描述

几张卡牌排成一行，每张卡牌都有一个对应的点数。点数由整数数组 `cardPoints` 给出。

每次行动，你可以从行的开头或者末尾拿一张卡牌，最终你必须正好拿 `k` 张卡牌。

你的点数就是你拿到手中的所有卡牌的点数之和。返回你能获得的最大点数。

#### 示例

```
输入：cardPoints = [1,2,3,4,5,6,1], k = 3
输出：12
解释：取右边三张 [1,6,5] 或左1+右2 等组合，最优为 6+5+1=12
```

```
输入：cardPoints = [2,2,2], k = 2
输出：4
```

```
输入：cardPoints = [9,7,7,9,7,7,9], k = 7
输出：55
```

#### 提示

- 1 <= cardPoints.length <= 105
- 1 <= cardPoints[i] <= 104
- 1 <= k <= cardPoints.length
