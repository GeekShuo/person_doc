## 题目描述

给你一个整数数组 `nums`，请你将该数组升序排列。

**要求：**时间复杂度 O(nlogn)，不使用内置排序函数。面试中常要求手写快排或归并排序。

#### 示例

```
输入：nums = [5,2,3,1]
输出：[1,2,3,5]
```

```
输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
```

- 1 <= nums.length <= 5 * 104
- -5 * 104 <= nums[i] <= 5 * 104
