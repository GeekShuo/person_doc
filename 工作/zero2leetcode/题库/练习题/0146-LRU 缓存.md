## 题目描述

请你设计并实现一个满足 LRU 规则的数据结构，支持 `get` 和 `put`，并都要在平均 `O(1)` 时间完成。

当前页面暂未接入这类设计题的本地测试，但保留模板与跳转入口。

#### 示例

```
LRUCache cache = new LRUCache(2);
cache.put(1, 1);
cache.put(2, 2);
cache.get(1);       // 返回 1
cache.put(3, 3);    // 淘汰 key 2
cache.get(2);       // 返回 -1（未找到）
```
