## 题目描述

一个机器人位于一个 `m x n` 网格的左上角。机器人每次只能向下或者向右移动一步。

机器人试图到达网格的右下角。问总共有多少条不同的路径？

#### 示例

```
m = 3, n = 7
输出: 28
```

m = 3, n = 2
