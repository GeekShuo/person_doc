# 394. 字符串解码

**难度**：Medium | **分类**：栈、字符串 | **LeetCode**：[在线练习](https://leetcode.cn/problems/decode-string/)

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则：`k[encoded_string]` 表示括号中的 `encoded_string` 重复 `k` 次。你可以认为输入字符串总是有效的，且数字只表示重复次数。

#### 示例

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

#### 提示

- `1 <= s.length <= 30`
- `s` 由小写字母、数字和方括号组成
