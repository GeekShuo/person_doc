**难度**：Hard | **分类**：双指针、单调栈 | **LeetCode**：[在线练习](https://leetcode.cn/problems/trapping-rain-water/)

## 题目描述

给定 `n` 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

#### 示例

```
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
```

```
输入：height = [4,2,0,3,2,5]
输出：9
```

#### 提示

- `n == height.length`
- `1 <= n <= 2 * 10^4`
- `0 <= height[i] <= 10^5`
