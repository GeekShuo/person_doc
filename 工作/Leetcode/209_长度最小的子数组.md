# [209] 长度最小的子数组 (Minimum Size Subarray Sum)

## 题目描述
给定一个含有 `n` 个正整数的数组和一个正整数 `target` 。
找出该数组中满足其和 `≥ target` 的长度最小的 **连续子数组** `[numsl, numsl+1, ..., numsr-1, numsr]` ，并返回其长度。如果不存在符合条件的子数组，返回 `0` 。

## 解题思路
- **滑动窗口**：这是一个非常典型的可以用滑动窗口解的题（找满足某条件的最短/最长连续子数组）。
- 我们定义一个窗口 `[left, right]`，起初两个指针都指向 `0`。
- 不断向右移动 `right`，将其对应的值累加到窗口总和 `current_sum` 中。
- 一旦 `current_sum >= target`，我们就找到了一个有效的子数组。此时，我们尝试**缩减窗口左边界**（移动 `left`），以便寻找是否存在**更短**的符合条件的子数组，直到总和不再 `>= target`。
- 然后再继续移动 `right`，周而复始。

## 代码模版 (Python)

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: list[int]) -> int:
        left = 0
        current_sum = 0
        # 初始化为无穷大，为了最后做比较
        min_len = float('inf')
        
        for right in range(len(nums)):
            current_sum += nums[right]
            
            # 当窗口内的和满足 >= target 时，收缩左边界以找最小长度
            while current_sum >= target:
                min_len = min(min_len, right - left + 1)
                current_sum -= nums[left]
                left += 1
                
        # 看看有没有找到过有效解
        return min_len if min_len != float('inf') else 0
```

## 边界条件与易错点
1. **找不到满足条件的子数组**：如果所有元素加起来都小于 `target`，那么 `min_len` 不会被更新，最终由于判断 `min_len != float('inf')` 后应返回 `0` 而非 `inf`。
2. **正整数条件保障**：滑动窗口的核心是：加法必定使总和增加，减法必定使得总和减少。题目规定了是“正整数”，因此 `right` 扩张和 `left` 收缩的单调性是成立的。如果数组有负数，则不能直接用普通的滑动窗口，可能需要前缀和加上单调队列/二分查找。
3. **只更新 `target` 时 `min_len`**：由于我们要找的是满足 `sum >= target` 的**最小长度**，所以每次更新要在 `while sum >= target` 循环内部进行。
