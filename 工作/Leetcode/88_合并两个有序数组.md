# [88] 合并两个有序数组 (Merge Sorted Array)

## 题目描述
给你两个按 **非递减顺序** 排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n` ，分别表示 `nums1` 和 `nums2` 中的元素数目。
请你 **合并** `nums2` 到 `nums1` 中，使合并后的数组同样按 **非递减顺序** 排列。

**注意**：最终，合并后数组不应由函数返回，而是存储在数组 `nums1` 中。为了应对这种情况，`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素表示应合并的元素，后 `n` 个元素为 `0` ，应忽略。

## 解题思路
- **逆向双指针**：如果你从前向后合并，必定会覆盖掉 `nums1` 中原本有用的元素，需要额外空间暂存。
- 但是，既然 `nums1` 的后半段是空的！我们可以**从后往前遍历**，谁大就把谁放到 `nums1` 的最后面。
- 设置三个指针：
  - `p1 = m - 1`：指向 `nums1` 有效数据末尾。
  - `p2 = n - 1`：指向 `nums2` 末尾。
  - `p = m + n - 1`：指向 `nums1` 整体的末尾（放置数据的位置）。
- 当 `p1 >= 0` 且 `p2 >= 0` 时，比较并放入较大者；循环结束后如果 `nums2` 还有剩余，直接覆盖到 `nums1` 前面。

## 代码模版 (Python)

```python
class Solution:
    def merge(self, nums1: list[int], m: int, nums2: list[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        p1, p2, p = m - 1, n - 1, m + n - 1
        
        # 当两个数组都还有元素时
        while p1 >= 0 and p2 >= 0:
            if nums1[p1] > nums2[p2]:
                nums1[p] = nums1[p1]
                p1 -= 1
            else:
                nums1[p] = nums2[p2]
                p2 -= 1
            p -= 1
            
        # 补充边界处理
        # 如果 nums1 提前遍历完了，而 nums2 还有剩余，需要把 nums2 剩下的直接复制过去
        # 如果是 nums2 提前遍历完了，nums1 原本的元素已经是在正确的位置了，无需操作
        while p2 >= 0:
            nums1[p] = nums2[p2]
            p2 -= 1
            p -= 1
```

## 边界条件与易错点
1. **退出条件后的补充**：退出第一个 `while` 循环时，到底是 `p1 < 0` 还是 `p2 < 0`？
   - 如果 `p1 < 0`（即 `nums1` 原始数据跑完），说明 `nums2` 里还有更小的数据没放入，需额外 `while p2 >= 0:` 补进去。
   - 如果 `p2 < 0`（即 `nums2` 跑完），此时 `nums1` 剩下的刚好都在自己数组的前面位置上，本身自带且正确无需处理。
2. **下标范围**：注意定义 `p1` 时是 `m - 1`，而不是 `len(nums1) - 1`（因为 `len(nums1)` 实际上是 `m + n`）。
