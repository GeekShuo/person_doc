# [15] 三数之和 (3Sum)

## 题目描述
给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。
请你返回所有和为 `0` 且 **不重复** 的三元组。
注意：答案中不可以包含重复的三元组。

## 解题思路
- **排序 + 双指针**：这是一道非常高频且极易写得冗长的面试神题。如果使用三重循环或者哈希表，很容易产生大量的重复三元组，去重极其麻烦。
- 首先将数组**排序**，这样如果存在多个相同的数字，它们会聚集到一起，方便我们控制跳过。
- 遍历数组作为第一个加数 `nums[i]`，然后在其右侧使用左右双指针 `left` 和 `right` 寻找两数之和等于 `-nums[i]` 的组合。
- 在寻找过程中，要注意**两个去重环节**：
  1. 遍历 `i` 时，如果 `nums[i] == nums[i-1]`，直接 `continue`（跳过相同的第一个数字）。
  2. 找到一组答案后，`left` 和 `right` 指针遇到连续相同的数字时也要跳过。

## 代码模版 (Python)

```python
class Solution:
    def threeSum(self, nums: list[int]) -> list[list[int]]:
        nums.sort()  # 必须先排序
        n = len(nums)
        res = []
        
        for i in range(n - 2):
            # 剪枝：如果排好序后，第一个数都已经 > 0 了，三数之和不可能 == 0
            if nums[i] > 0:
                break
                
            # 去重：如果当前的数字和前一个一样，跳过以避免重复组合
            if i > 0 and nums[i] == nums[i - 1]:
                continue
                
            # 双指针寻找另外两个数
            left, right = i + 1, n - 1
            while left < right:
                total = nums[i] + nums[left] + nums[right]
                
                if total < 0:
                    left += 1
                elif total > 0:
                    right -= 1
                else:
                    # 找到了一组解
                    res.append([nums[i], nums[left], nums[right]])
                    
                    # 左右去重，跳过相同的数字
                    while left < right and nums[left] == nums[left + 1]:
                        left += 1
                    while left < right and nums[right] == nums[right - 1]:
                        right -= 1
                        
                    # 找到解并且去重后，双指针同时往中间收缩
                    left += 1
                    right -= 1
                    
        return res
```

## 边界条件与易错点
1. **去重时越界**：去重 `while` 循环里，千万别忘了也要加上 `left < right` 这个前置条件，否则在全是一样的数组（如 `[0,0,0,0,0]`）里会双双越界。
2. **提前终止优化（剪枝很重要！）**：由于已经排序过了，如果在循环开始处发现 `nums[i] > 0`，后面的数字必然都大于 0，绝对凑不成 0，直接 `break` 退出来，能挡住巨量无效计算。
3. **不能只让单一指针动**：找到 `total == 0` 时，如果不让 `left` 和 `right` 都收缩，循环会卡住不动从而死循环！
