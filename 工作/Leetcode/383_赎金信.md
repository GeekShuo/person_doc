# [383] 赎金信 (Ransom Note)

## 题目描述
给你两个字符串：`ransomNote` 和 `magazine` ，判断 `ransomNote` 能不能由 `magazine` 里面的字符构成。
如果可以，返回 `true` ；否则返回 `false` 。
`magazine` 中的每个字符只能在 `ransomNote` 中使用一次。

## 解题思路
- **哈希表计数**：为了判断 `ransomNote` 是否能由 `magazine` 中的字符组成，我们需要统计 `magazine` 中每种字符的数量。
- 遍历 `magazine`，将字符及其出现次数存入哈希表（或长度为26的数组）。
- 然后遍历 `ransomNote`，如果是哈希表里有的字符，将其计数减 1；如果计数小于 0 或者字符根本不存在，说明 `magazine` 不足以拼出这封勒索信，返回 `False`。
- 如果遍历完 `ransomNote` 没中途跳出，说明能拼成，返回 `True`。

## 代码模版 (Python)

```python
class Solution:
    def canConstruct(self, ransomNote: str, magazine: str) -> bool:
        # 如果 ransomNote 的长度大于 magazine，肯定拼不成
        if len(ransomNote) > len(magazine):
            return False
            
        from collections import Counter
        # 统计 magazine 中各个字符的数量
        mag_count = Counter(magazine)
        
        # 遍历 ransomNote，消耗 magazine 的字符
        for char in ransomNote:
            if mag_count[char] <= 0:
                return False
            mag_count[char] -= 1
            
        return True
```
*注：在 Python 中，直接使用 `Counter(ransomNote) <= Counter(magazine)` 也是可以且极简的，但面试中手写逻辑展示基本功更好。*

## 边界条件与易错点
1. **长度提前剪枝**：如果勒索信的长度本身就长过杂志长度，直接返回 `False`，避免无谓的哈希构建和遍历。
2. **字符种类**：题目指出字符均由小写英文字母组成，因此用长度为 26 的数组作为哈希表比使用通用 Map 或 Dict 更快也更省内存（虽然 Python 默认用字典非常方便）。
