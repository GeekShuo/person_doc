# [26] 删除有序数组中的重复项 (Remove Duplicates from Sorted Array)

## 题目描述
给你一个 **升序排列** 的数组 `nums` ，请你 **原地** 删除重复出现的元素，使每个元素 **只出现一次** ，返回删除后数组的新长度。元素的 **相对顺序** 应该保持 **一致** 。然后返回 `nums` 中唯一元素的个数。

考虑 `nums` 的唯一元素的数量为 `k` ，你需要做以下事情确保你的题解可以被通过：
- 更改数组 `nums` ，使 `nums` 的前 `k` 个元素包含唯一元素，并按照它们最初在 `nums` 中出现的顺序排列。
- 返回 `k` 。

## 解题思路
- **双指针法**：因为数组是升序排列的，所以重复的元素一定会相邻。
- 我们使用两个指针 `slow` 和 `fast`。
- `slow` 指针指向下一个要覆盖的非重复元素的位置，初始为 1（因为第一个元素总是非重复的）。
- `fast` 指针用来遍历整个数组，寻找与他前面不一样的元素，初始为 1。
- 如果 `nums[fast] != nums[fast - 1]`，说明找到了一个新的不重复元素，我们就把它放到 `nums[slow]` 的位置，然后 `slow` 前进。

## 代码模版 (Python)

```python
class Solution:
    def removeDuplicates(self, nums: list[int]) -> int:
        if not nums:
            return 0
            
        slow = 1
        for fast in range(1, len(nums)):
            # 如果当前元素和前一个元素不同，说明是不重复的新元素
            if nums[fast] != nums[fast - 1]:
                nums[slow] = nums[fast]
                slow += 1
                
        return slow
```

## 边界条件与易错点
1. **空数组判断**：虽然题目条件中 `nums.length >= 1`，但写代码加上 `if not nums: return 0` 是良好的工程习惯。
2. **返回值**：题目要求返回的是新逻辑数组的长度（也是唯一元素的个数），即 `slow`。
3. **原地修改**：这题考察重点是原地修改数组（O(1) 空间），不要去重新 `return list(set(nums))`，这会创建新数组且打乱顺序，不合题意。
