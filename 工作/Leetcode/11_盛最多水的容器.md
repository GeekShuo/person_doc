# [11] 盛最多水的容器 (Container With Most Water)

## 题目描述
给定一个长度为 `n` 的整数数组 `height`。有 `n` 条垂线，第 `i` 条线的两个端点是 `(i, 0)` 和 `(i, height[i])`。
找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。
返回容器可以储存的最大水量。
*说明：你不能倾斜容器。*

## 解题思路
- **双指针法**：容器的容量不仅由底部的宽度决定，还由两侧较短的一条边决定。即：`面积 = min(height[left], height[right]) * (right - left)`。
- 初始化双指针分别指向数组的两端，`left = 0`，`right = len(height) - 1`。
- 每次计算当前容器的容量，去更新最大容量 `max_area`。
- 重点在于如何移动指针：由于宽度一定会随着指针向内移动而减少，要使得面积增大，我们唯一的机会是遇到更高的边。因此，我们应该**移动较短的那一条边对应的指针**。

## 代码模版 (Python)

```python
class Solution:
    def maxArea(self, height: list[int]) -> int:
        left, right = 0, len(height) - 1
        max_area = 0
        
        while left < right:
            # 当前的面积
            current_area = min(height[left], height[right]) * (right - left)
            max_area = max(max_area, current_area)
            
            # 移动较短的一边
            if height[left] < height[right]:
                left += 1
            else:
                right -= 1
                
        return max_area
```

## 边界条件与易错点
1. **移动相同高度的边**：如果两边高度相同，移动哪边其实都可以，因为如果内侧存在更高的柱子，只移一边它仍被外侧剩下的这个短柱子限制。上方代码在高度相同时移动了 `right`，是完全没问题的。
2. **贪心正确性**：千万不要写成 O(n^2) 的双层循环去遍历所有组合，必定会超时。只需 O(N) 遍历一次。
