## 1. 多级投票标签机制为什么合理

**回答：**

这个机制用于解决多模态安全数据的大规模自动标注问题。风险类别长尾明显，隐喻、谐音、视觉偷渡和图文组合等边界样本又容易产生歧义。如果直接把单个教师模型的输出当作真值，教师的偶然错误和系统偏差都会被蒸馏进训练集。因此项目采用了“强模型初标—规则校验—交叉标注—投票聚合—争议样本复核”的多级质量控制链路。

具体分为几层：

1. **初始标注**：以 Qwen3-VL-235B 等强模型读取已有图片，生成文本问题、结构化判断依据和风险标签；规则负责格式、枚举值、父子标签一致性等确定性检查。
2. **交叉标注**：将数据划分为互斥子集，通过正负样本重采样训练偏宽松和偏严格的判别模型，再让模型标注未参与自身训练的另一子集，避免在训练样本上产生虚假的高置信度。
3. **投票聚合**：多个模型结论一致时作为高置信候选；结论分歧时，不强行用多数票掩盖不确定性，而是将样本降权、过滤或送人工复核。
4. **难例回流**：把模型分歧、线上 Bad Case 和多次采样结果不稳定的样本加入下一轮数据构建，持续修正决策边界。

宽松模型更关注降低高风险内容漏放，严格模型更关注控制正常内容误杀。二者的分歧本身就是一种不确定性信号。因此，这套机制的价值不是“多数一定正确”，而是利用不同模型的误差互补性降低单模型噪声，并把有限的人工成本集中到最有信息量的边界样本。

### 如何证明机制有效

不能只看最终投票结果，需要做消融和分层评估：

- 比较单教师、简单投票、交叉标注加投票三种方案的标签抽检准确率；
- 统计一致样本覆盖率、分歧率及分歧样本错误率；
- 计算模型之间的错误相关性，若模型高度同质，投票收益通常有限；
- 固定训练配置，只替换标签版本，比较下游 Precision、Recall、F1 和过度拒答率；
- 对高风险、正常、长尾类别分别统计，避免总体指标掩盖少数类问题。

**事实边界：**现有项目材料能确认多模型投票、规则过滤、互斥子集、宽松/严格模型及交叉标注，但没有记录具体是简单多数票还是置信度加权、平票策略和自动标签抽检准确率。面试时不应编造这些实现细节。

# 机器学习基础

## 2. 有约束的损失最小化：球形约束及证明

考虑优化问题：

$$
\min_w f(w),\qquad \text{s.t.}\quad \|w\|_2\le R。
$$

这里的可行域是半径为 $R$ 的闭球。常见解法有拉格朗日乘子法和投影梯度下降。

### 2.1 与 $L_2$ 正则化的关系

拉格朗日函数为：

$$
\mathcal L(w,\lambda)=f(w)+\lambda(\|w\|_2^2-R^2),\qquad \lambda\ge 0。
$$

若 $f$ 为凸函数、约束满足 Slater 条件，则强对偶成立，最优解满足 KKT 条件：

$$
\begin{aligned}
&\nabla f(w^*)+2\lambda^*w^*=0,\\
&\|w^*\|_2^2-R^2\le 0,\\
&\lambda^*\ge 0,\\
&\lambda^*(\|w^*\|_2^2-R^2)=0。
\end{aligned}
$$

当约束是活跃的，即 $\|w^*\|_2=R$ 时，通常有 $\lambda^*>0$。此时 $w^*$ 同时也是某个正则系数下

$$
\min_w f(w)+\lambda^*\|w\|_2^2
$$

的解。这说明球约束和 $L_2$ 正则在适当凸性条件下存在对应关系：球半径 $R$ 控制参数空间，正则系数 $\lambda$ 控制偏离原点的代价。但二者不是在所有非凸问题中都严格一一对应。

### 2.2 投影梯度下降

先做普通梯度更新，再投影回可行域：

$$
\tilde w_{t+1}=w_t-\eta\nabla f(w_t),
\qquad
w_{t+1}=\Pi_{\|w\|_2\le R}(\tilde w_{t+1})。
$$

$L_2$ 球的投影有闭式解：

$$
\Pi(\tilde w)=
\begin{cases}
\tilde w,&\|\tilde w\|_2\le R,\\
R\dfrac{\tilde w}{\|\tilde w\|_2},&\|\tilde w\|_2>R。
\end{cases}
$$

**为什么这是投影：**若点在球内，它自己就是距离最近的可行点；若在球外，根据柯西—施瓦茨不等式，最小化 $\|w-\tilde w\|_2^2$ 时，最优 $w$ 必须与 $\tilde w$ 同方向，并落在边界上，因此得到 $R\tilde w/\|\tilde w\|_2$。

## 3. 梯度下降的更新公式，以及为什么有效

更新公式是：

$$
w_{t+1}=w_t-\eta\nabla f(w_t)，
$$

其中 $\eta>0$ 是学习率。负梯度是局部下降最快的方向，因为一阶泰勒展开给出：

$$
f(w+\Delta w)\approx f(w)+\nabla f(w)^T\Delta w。
$$

在限制 $\|\Delta w\|_2\le\epsilon$ 时，要使内积最小，根据柯西—施瓦茨不等式：

$$
\nabla f(w)^T\Delta w\ge-\|\nabla f(w)\|_2\|\Delta w\|_2，
$$

等号在 $\Delta w=-\epsilon\nabla f(w)/\|\nabla f(w)\|_2$ 时成立，所以负梯度是欧氏空间中的最速下降方向。

### 用下降引理证明一步有效

若 $f$ 是 $L$-smooth，即梯度满足 Lipschitz 条件，则：

$$
f(y)\le f(x)+\nabla f(x)^T(y-x)+\frac L2\|y-x\|_2^2。
$$

令 $y=x-\eta\nabla f(x)$，可得：

$$
f(x-\eta\nabla f(x))
\le f(x)-\eta\left(1-\frac{L\eta}{2}\right)\|\nabla f(x)\|_2^2。
$$

因此当 $0<\eta<2/L$ 时，只要梯度非零，目标函数就下降；常取 $\eta\le1/L$，此时：

$$
f(w_{t+1})\le f(w_t)-\frac\eta2\|\nabla f(w_t)\|_2^2。
$$

进一步地：

- 对一般光滑非凸函数，只能保证逐渐接近一阶驻点；
- 对凸函数，合适步长下通常有 $O(1/t)$ 的函数值收敛率；
- 对 $\mu$-强凸且 $L$-smooth 的函数，可得到线性收敛。

所以“有效”依赖光滑性和学习率条件，不能理解为任意学习率、任意非凸函数都保证到达全局最优。

# 算法题

## 4. 快速排序的最差情况

当每次选到的枢轴都是当前区间的最小值或最大值时，划分结果是 $0$ 个元素和 $n-1$ 个元素。例如数组已经升序，而实现始终选最后一个元素作为枢轴。

递推式为：

$$
T(n)=T(n-1)+\Theta(n)=\Theta(n^2)。
$$

此时递归深度为 $O(n)$，递归栈空间也是 $O(n)$。平均情况下划分较均衡，时间复杂度为 $O(n\log n)$，栈空间期望为 $O(\log n)$。

改进方式：

- 随机选择枢轴，使固定输入难以持续触发最差划分；
- 三数取中，降低有序数据退化概率；
- 小区间改用插入排序；
- 控制递归深度，必要时退化为堆排序，即 Introsort；
- 对大量重复元素采用三路划分。

## 5. 找到 Top-K

需要先确认是求第 $K$ 大、前 $K$ 大，还是要求结果有序。

### 方案一：大小为 $K$ 的小顶堆

遍历元素：堆未满就入堆；堆满后，若当前值大于堆顶，则替换堆顶。最终堆中是前 $K$ 大元素。

- 时间复杂度：$O(n\log K)$；
- 空间复杂度：$O(K)$；
- 适合流式数据、数据不能全部放入内存，或 $K\ll n$ 的场景。

```python
import heapq

def top_k(nums, k):
    if k <= 0:
        return []
    heap = []
    for x in nums:
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)
    return sorted(heap, reverse=True)
```

### 方案二：Quickselect

利用快速排序的 partition。若枢轴最终位置正好是目标下标就结束，否则只递归一侧。

- 平均时间复杂度：$O(n)$；
- 最差时间复杂度：$O(n^2)$，随机枢轴可显著降低退化概率；
- 原地空间较省；
- 只能保证选出前 $K$ 个，若要求这 $K$ 个有序，还需额外 $O(K\log K)$ 排序。

## 6. 最大连续子数组

使用 Kadane 算法。令：

$$
dp[i]=\text{以 }i\text{ 结尾的最大连续子数组和}。
$$

则只有两种选择：把当前元素接到前面的最优连续段后面，或从当前元素重新开始：

$$
dp[i]=\max(nums[i],dp[i-1]+nums[i])。
$$

答案为 $\max_i dp[i]$。由于只依赖前一个状态，可以把空间降为 $O(1)$。

```python
def max_subarray(nums):
    current = best = nums[0]
    start = best_l = best_r = 0

    for i in range(1, len(nums)):
        if current < 0:
            current = nums[i]
            start = i
        else:
            current += nums[i]

        if current > best:
            best = current
            best_l, best_r = start, i

    return best, (best_l, best_r)
```

时间复杂度 $O(n)$，额外空间 $O(1)$。初始化不能写成 0，否则数组全为负数时会错误返回空子数组。
