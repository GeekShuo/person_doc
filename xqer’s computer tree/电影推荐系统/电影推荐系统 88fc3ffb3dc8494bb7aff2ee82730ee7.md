# 电影推荐系统

Owner: xqer

# 项目需求

用户注册，登录。

用户打分

用户得到推荐结果

# 访问流程：

vue页面 login index 有电影大全，用户登录，获取推荐

未登陆时只能浏览 登陆后可以打分

访问链接

（显示index页面）

用户点击注册

（返回注册页面）

点击提交账号，密码

（插入mysql，返回打分页面）

用户点击打分

（插入mysql）

点击推荐

（调用scala计算topk，根据topk id 查询电影详细信息，返回）

# 数据库设计

USERCF算法流程：

对一个用户，计算这个用户和所有其他用户的相似度，

再对每个项目，对（相似度*评分）求和

排序得到topk，进行推荐
