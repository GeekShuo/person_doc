# 直流电机

理解驱动直流电机方法的基础上，使用OutputDevice类来驱动直流电机

```

# 步进电机

步进电机的控制方式通常为“全步进”（Full Step）和“半步进”（Half Step）。

在全步进控制下，需要按照以下顺序控制步进电机的引脚：

1. A和B’
2. A’和B
3. A和B
4. A’和B’

这样的引脚控制方式可以使步进电机顺时针或逆时针旋转一定角度或一定步数。每次将电压应用至电机的不同引脚上，都会使电机有短暂的惯性，在脱离一个状态到进去一个状态的瞬间，会出现短暂的振荡状态，这个状态会导致电机旋转。

在半步进控制下，需要按照以下顺序控制步进电机的引脚：

1. A
2. A和B’
3. B’
4. A’和B’
5. A’
6. A’和B
7. B
8. A和B

## 分别转动45°、90°、180°、360°时停止，并能够直观显示该旋转角度

通过观察旋转一周需要的次数，就能得出需要的步进角

```
angle = 0
steps_per_revolution = 200
angle_per_step = 45
#full_step_ccw()
for i in range(int(360/angle_per_step)):
    full_step_ccw()
    angle += angle_per_step
```

在这段程序里改变angle_per_step ，发现其等于45时，步进电机差不多转了一圈，因此步进角为45°/4

```
angle = 0
steps_per_revolution = 200
angle_per_step = 45
for i in range(int(45/angle_per_step)):
    full_step_ccw()
    angle += angle_per_step

# 旋转90度
for i in range(int(90/angle_per_step)):
    full_step_ccw()
    angle += angle_per_step

# 旋转180度
for i in range(int(180/angle_per_step)):
    full_step_ccw()
    angle += angle_per_step

# 旋转360度
for i in range(int(360/angle_per_step)):
    full_step_ccw()
    angle += angle_per_step
