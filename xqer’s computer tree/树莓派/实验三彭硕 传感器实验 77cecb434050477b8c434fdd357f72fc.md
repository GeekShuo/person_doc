# 光学传感器

主要功能：检测特定范围内物体的存在

主要原理：利用红外线在不同颜色的物体表面具有不同的反射强度的特点，通过不断向地面发射红外光，当红外光遇到白色纸质地板时发生漫反射，反射光被接收管接收；如果遇到黑线则红外光被吸收，接收管接收不到红外光。

可探测范围：4-16毫米•应用场景：巡线机器人、光学编码器和物体计数等

连线 ：vcc连3.3v ，gnd接gdn，sig接gpio

实验:测量转速

可以用相邻两次检测到黑线的时间之差作为周期

用转的圈数除周期

得到代码如下

```
import time
import math
from gpiozero import LineSensor

sensor = LineSensor(21)
cnt = 0
Start_time = time.time()
def count_rpm():
    global cnt , Start_time
    cnt = cnt + 1
    T = time.time() - Start_time
    print("rpm = %lf"%(cnt/T))
sensor.when_no_line = count_rpm
while True:
    pass
```

# 超声波传感器

主要功能：检测物体距离

主要原理：其原理是利用声波在遇到障碍物反射接收，利用声波在空气中传播的速度（340 m/s）计算的得出

测量距离：2--450 cm

应用场景：测量、避障小车，无人驾驶等领域

元件型号：HCSR04

然后用H-S得到水位

代码如下

```
import gpiozero
from gpiozero import DistanceSensor,LED
from time import sleep
sensor = DistanceSensor(21,20,max_distance=1,threshold_distance=0.05)
led=LED(5)
sensor.when_in_range =led.on
sensor.when_out_of_range=led.off
while True:
    print('Distance to nearest object is',0.16-sensor.distance,'m')
    sleep(0.2)
```
