## 充值

trade_wechat_pay_recharge

表名 **ont_trade_wechat_pay_recharge_di****21** 属性**5** 分类

微信个人用户从绑定的**同名银行卡**向支付账户（零钱）充值。属 Bank→C 入金，充值发起人与资金收款人为同一人（本人的卡 → 本人的零钱余额）。

### 流水筛选口径

Filter Criteria

数据来源

|用途 / 分类|表|说明|
|---|---|---|
|实体构建主表|`dil_trd_usr_total_bankroll_list_dd`（绝影个人流水表）|实体构建主表|
|辅助筛选|`dil_trd_cft_usr_fxq_marking_dd`（打标流水表）|辅助筛选|

筛选条件

|#|筛选条件|字段|说明|
|---|---|---|---|
|1|`ffxq_mark LIKE '%10-014%'`|打标流水表.ffxq_mark|场景打标：10-014 C端充值（WX）|
|2|`SUBSTRING(ftrans_code, 1, 8) IN ('CZ009-01')`|打标流水表.ftrans_code|二次筛选：仅用户常规充值|
|3|`ftype = 1`|打标流水表.ftype|方向限定：入账（充值为资金流入）|

口径说明

**涵盖范围**：

- 打标口径 `10-014 C端充值（WX）`，除普通（零钱）充值外，还包含大量中间流水，例如：零钱+提现充值、零钱+打款验证充值、零钱+销户充值、提额支付退款充值、提额支付开户打款验证充值、零钱通微众快赎到余额、零钱通开户打款验证充值、零钱+充值到儿童手表附属账户、AI 附属账户充值、零钱通腾安快赎到余额等

**剔除范围**：

- 组合兑出（`CZ009-02`、`CZ009-03`）明确不纳入本实体

参考代码

SELECT jy.*
FROM (
    -- 打标流水：C 端充值（WX）
    SELECT
        concat(nvl(flistid, ''), '-', nvl(ftarget_uid, ''), '-', nvl(fbkid, ''), '-', nvl(fvs_listid, ''), '-', nvl(fpay_time, '')) AS join_key
    FROM dil_base::dil_trd_cft_usr_fxq_marking_dd partition (par_20260611) t1
    WHERE ffxq_mark LIKE '%10-014%'
      AND SUBSTRING(ftrans_code, 1, 8) IN ('CZ009-01')
      AND ftype = 1
) mk
JOIN (
    -- 绝影个人流水
    SELECT
        t2.*,
        concat(nvl(flistid, ''), '-', nvl(ftarget_uid, ''), '-', nvl(fbkid, ''), '-', nvl(fvs_listid, ''), '-', nvl(fpay_time, '')) AS join_key
    FROM dil_base::dil_trd_usr_total_bankroll_list_dd partition (par_20260611) t2
) jy
  ON mk.join_key = jy.join_key
