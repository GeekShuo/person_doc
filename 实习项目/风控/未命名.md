## 1. 整体情况

### 1.1 业务概述

AI智能审单系统用于自动化审核调证文书和警官证的有效性，是调证业务的核心风控环节。系统每日处理约**40万**请求，通过多层策略实现自动化拦截。

### 1.2 图像质量分布与模糊挑战

从总体流量来看，**约30%的图像存在不同程度的模糊问题**，这是影响后续识别准确率的关键因素：

```javascript
    总体流量中的图像质量分布
    
    ┌────────────────────────────────────────────────────────────────┐
    │                                                                │
    │   清晰图像 (70%)              模糊图像 (30%)                   │
    │   ████████████████████████    ██████████                       │
    │                               │                                │
    │                    ┌──────────┴──────────┐                     │
    │                    │                     │                     │
    │                    ▼                     ▼                     │
    │         ┌─────────────────┐   ┌─────────────────┐             │
    │         │   明确模糊(10%)  │   │  临界模糊(20%)   │             │
    │         │   ███████████   │   │  ███████████████ │             │
    │         │                 │   │                  │             │
    │         │  → 直接拒单     │   │  → 核心增益区    │             │
    │         │  → 策略明确     │   │  → 模型能力关键  │             │
    │         └─────────────────┘   └─────────────────┘             │
    │                                                                │
    └────────────────────────────────────────────────────────────────┘
```

|图像类别|占比|处理策略|业务影响|
|---|---|---|---|
|**清晰图像**|70%|正常流转后续识别|识别准确率高|
|**明确模糊**|10%|直接拒单，要求重新提交|策略清晰，无争议|
|**临界模糊**|20%|**核心增益区**|模型识别能力决定拦截增量|

> **核心挑战**：临界模糊（20%）是模型能力的关键战场。
> 
> - 若模型识别能力强：可准确识别问题文书并拒单，**提升拦截量**
>     
> - 若模型识别能力弱：无法识别导致只能放过，**拦截增益流失**  
>       
>     **优化目标**：提升模型对临界模糊图像的识别能力，将更多不合规文书准确识别并拦截，**增加有效拒单量**。
>

为实现从"放过模糊"到"直接拒单"的目标，清晰度模型经历了多版本迭代：

|版本|特征数|训练样本|AUC|测试准确率|独立测试集错误数|说明|
|---|---|---|---|---|---|---|
|**v1（现有）**|29|175|-|97%|-|基础版本，模糊文书放过|
|v3|57|1,186|0.9972|98%|-|+账号检测特征|
|v4_all|57|1,439|0.9979|98%|7|+生成模糊样本|
|v5|57|1,139|0.9984|99%|1|清洗训练数据|
|**v6_clip（目标）**|**569**|**1,139**|**0.9994**|**99%**|**0**|**+CLIP特征，得分更平滑**|

> **指标说明**：模糊Precision=判为模糊的准确率，模糊Recall=真正模糊被检出的比例

**CLIP特征带来的关键提升：**

|指标|V5 (无CLIP)|V6 (有CLIP)|提升效果|
|---|---|---|---|
|得分分离度|9.53|**14.16**|+49%，区分度更好|
|Precision=99.9%时召回率|92.9%|**98.7%**|+5.8%，漏检更少|
|Precision=99.9%时漏检率|7.1%|**1.3%**|**降低82%**|

> **解读**：如果要求"识别为模糊的准确率达到99.9%"（即几乎不会误判清晰为模糊），V5会漏掉7.1%的真正模糊样本，而V6只漏掉1.3%。

> - 部分清晰图片有效期区域被遮挡或反光  
>       
>     **多模态错误原因**：
>     
> - 个别日期识别错误（如`03.16`识别成`05.16`）
>     

##### 四、大模型优势与缺点

**优势**：

|优势项|表现|
|---|---|
|警官证姓名识别|**100%准确**，端到端识别无需规则|
|警官证有效期|**88.9%准确**，可自动判断是否过期|
|维护成本|一个模型+一条Prompt，无需维护多个模块|
|泛化能力|对新场景无需重训练，调整Prompt即可|

**缺点**：

|缺点项|表现|影响|
|---|---|---|
|清晰度判断弱|准确率仅66.7%（文书）/ 47.2%（警官证）|需ML模型前置过滤|
|长账号字符错误|长串账号容易出现字符顺序错误（如bc↔cb）|需后验校验|
|幻觉问题|看不清时会编造账号|需可信度检测|
|账号匹配准确率低|最高52%（full模式）|需结合传统OCR|

##### 五、后续优化方向

基于评估结果，推荐采用**大模型+OCR+后验**的混合方案：

> **为什么需要后验？** 大模型的核心问题是**不知道自己不知道**——即使看不清也会给出高置信度的错误答案（幻觉）。因此必须通过传统OCR进行后验校验，检测大模型输出的可靠性。

**实验验证：VL模型logprobs无法区分清晰度**

|方案|清晰样本置信度|模糊样本置信度|差异|能否区分清晰度|
|---|---|---|---|---|
|VL日期token概率|98.1%|98.7%|-0.6%|❌ 不能|
|**OCR置信度**|**96.9%**|**83.8%**|**+13.1%**|✅ 能|
|VL只输出有效期|99.48%|99.85%|-0.36%|❌ 不能|

> **实验结论**：即使输入模糊图片，VL模型输出的token概率依然高达98%+，无法通过logprobs判断输入质量。这证明了大模型确实"不知道自己不知道"，清晰度预筛选必须依赖OCR置信度等外部特征。

## 4. 微调优化方案

### 4.1 当前难点问题分析

|问题类型|具体表现|影响范围|可微调解决|
|---|---|---|---|
